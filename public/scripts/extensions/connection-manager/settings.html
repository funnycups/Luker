Connection Profile

Applies to both text and image generation. Retries on network errors and rate-limit / server errors. Streaming responses are not retried after the stream begins.
Main-chat only. Fires on output cap or safety cutoff. Stops if the last round produced no new content. Counter resets on user input, chat switch, or a normal-finish reply.

Claude Prompt Caching

Only effective when the prompt prefix is stable across requests (no in-chat lorebook injections or random macros). Cache writes cost 1.25× base (5m) or 2× base (1h); reads cost 0.1×.
Prompt post-processing is set to Single user message, which collapses every turn into one message. Prompt caching cannot reuse any prefix across requests in this mode — every request is a cache write with no read. Switch to None or Merge consecutive roles for caching to take effect. Prompt post-processing is set to Strict or Semi-strict, which folds every system message after the first into a user turn. Prompt caching still works on the first user message's tail, but the dedicated system-prompt cache breakpoint is unavailable. None or Merge consecutive roles gives the best cache coverage.

OpenRouter Gemini Prompt Caching

Only applied when OpenRouter routes to a Gemini model that supports caching. Same prefix-stability caveat as Claude caching.
Embedding profiles are used by Vector Storage and Memory Graph for text embeddings. They are not active chat connections.
Rerank profiles are used to re-score candidates after vector retrieval. They are not active chat connections.
