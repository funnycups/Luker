features:
  - icon: 🧠
    title: 記憶圖
    details: 角色能夠真正記住劇情。每一場戲都會被提取成帶類型的節點（角色、地點、事件、劇情線），每次回覆前由召回環節選出最相關的記憶並注入上下文。
  - icon: 🎭
    title: 多Agent編排
    details: 每則回覆開始撰寫之前，agent 團隊會先完成場景規劃——壓縮上下文、草擬走向、審校方案。五種執行模式，從固定流水線到整支導演團隊。
  - icon: 🧩
    title: 技能
    details: 可重用的知識包，agent 按需讀取，用來代替一份龐大的系統提示詞。相容 Anthropic Claude Skills 格式，並且能隨角色卡和預設一起分發。
  - icon: ✨
    title: 角色卡編輯助手
    details: 透過對話修改角色卡和世界書。每一批改動都以 diff 形式供你逐條批准；帶 CardApp 的角色卡直接進入完整的工作台。
  - icon: 🔍
    title: 搜尋外掛
    details: 角色可以在對話中途聯網搜尋。DuckDuckGo、SearXNG、Brave 任選——既可以作為模型自行呼叫的工具，也可以作為預請求 agent，在生成前自動搜尋並將結果寫入世界書。
  - icon: 📱
    title: Android 應用
    details: 後端完全在應用內執行，一支手機同時充當伺服端和介面。安裝 APK 即可使用——不需要 Termux、不需要手動安裝 Node、不需要連接埠轉送。
