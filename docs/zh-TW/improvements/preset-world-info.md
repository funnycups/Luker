# 預設關聯世界書

預設關聯世界書是 Luker 引入的改進，允許你將特定的世界書與預設綁定。切換預設時，關聯的世界書會自動啟用。

## 使用場景

不同的角色扮演場景往往需要不同的預設參數和世界觀設定。例如：

- **奇幻場景**：高溫度 + 奇幻世界書（魔法體系、種族設定等）
- **現代都市**：中等溫度 + 現代世界書（城市地標、社會規則等）
- **科幻場景**：低溫度 + 科幻世界書（星際設定、科技體系等）

透過預設關聯世界書，你可以將這些組合打包——切換預設時，對應的世界書自動啟用，無需手動切換。

## 如何使用

1. 在預設編輯介面中，找到「關聯世界書」設定
2. 選擇要與目前預設綁定的世界書
3. 儲存預設

之後每次切換到這個預設時，關聯的世界書會自動啟用。切換到其他預設時，不會全域自動停用你手動啟用的世界書。

::: tip
預設關聯世界書不會影響角色卡自帶的世界書。角色卡的世界書始終生效，預設關聯的世界書是額外疊加的。
:::

## 與手動啟用的區別

世界書有兩種啟用方式：手動啟用和預設關聯啟用。

- **手動啟用**的世界書始終保持啟用狀態，不受預設切換影響
- **預設關聯啟用**的世界書會在選中對應預設時自動啟用

兩種方式互不干擾。如果你希望某個世界書在所有預設下都生效，直接手動啟用即可；如果只想在特定場景下使用，透過預設關聯更為方便。

## 與其他功能的配合

- **[角色卡綁定預設](/zh-TW/improvements/card-bound-presets)**：角色卡可以推薦預設，預設又關聯世界書，形成「角色卡 → 預設 → 世界書」的完整鏈路
- **[預設解耦](/zh-TW/improvements/preset-decoupling)**：預設關聯世界書建立在預設解耦的基礎上，連線設定和預設獨立管理
