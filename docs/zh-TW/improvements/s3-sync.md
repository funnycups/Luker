# S3 同步

使用相容 S3 的儲存桶作為加密同步中心，裝置可以透過不同網路連線。同步排程、類別、待處理選擇、聊天分支與撤銷操作參閱[同步概覽](./sync)。

## 準備條件

- 升級準備共享資料的 Luker 安裝。
- 新增後端前，在儲存服務中建立儲存桶，準備相容的端點、區域與路徑樣式設定。
- 允許憑證讀取、寫入所選位置的物件，並刪除設定檢查產生的臨時物件。儲存服務必須支援條件寫入。
- 加入同步的裝置使用相同儲存桶與正規化前綴。不相關的資料使用獨立的儲存位置。
- 優先透過 HTTPS 存取 Luker 伺服端與儲存服務。多使用者安裝中的私有端點還需要管理員允許[私有位址存取](/zh-TW/guide/configuration#sync-private-addresses)。

## 新增儲存

開啟**使用者設定 → 帳號 → 備份與還原 → 同步 → 開啟同步**，選擇**新增 S3 後端**。

| 欄位 | 填寫內容 |
| --- | --- |
| **後端名稱** | 目前連線的名稱，例如 Shared archive。 |
| **要同步的類別：** | 共享的資料，參閱[類別與敏感資料](./sync#類別與敏感資料)。 |
| **S3 端點** | 服務提供者的 HTTP 或 HTTPS 端點。優先使用 HTTPS，不要在 URL 中填寫憑證。 |
| **區域：** | 儲存服務要求的區域。 |
| **儲存桶** | 已存在的儲存桶名稱。 |
| **前綴** | 儲存桶內的獨立位置，例如 `seraphina/`；留空時使用儲存桶根位置。 |
| **使用路徑樣式請求** | 根據儲存服務的位址要求設定。 |
| **傳送不帶引號的 ETag** | 服務支援條件寫入但拒絕 If-Match 中帶引號的 ETag 時啟用。 |
| **存取金鑰 ID**、**秘密存取金鑰** | 可以存取該位置的憑證組合。 |
| **加密通行片語** | 新建同步位置時使用的片語，或加入已有位置時使用的原片語。 |

**前綴**會移除開頭與結尾的斜線，`/seraphina/` 與 `seraphina` 表示相同位置。允許空前綴。內部空路徑區段、`.` 或 `..` 路徑區段、反斜線與控制字元會被拒絕。

![新增 S3 後端表單，顯示連線欄位、類別與隱藏的敏感值](/images/sync/s3-form.png)

點擊**儲存**。設定期間會透過臨時物件檢查條件寫入相容性。忽略必要寫入條件的服務不受支援。設定還會檢查 If-Match 中的目前 ETag 能否被接受；服務只拒絕帶引號的 ETag 時，錯誤提示會指向「傳送不帶引號的 ETag」。驗證失敗、儲存桶不存在與連線失敗會分別提示，不視為不支援條件寫入。

設定完成後，後端顯示在**同步後端**中，並啟動同步。[活動與檢查](./sync#活動與檢查)說明了如何查看同步狀態與待處理事項。

## 從其他裝置加入

在準備加入的裝置上選擇**新增 S3 後端**，填寫已有的端點、區域、儲存桶、正規化前綴、憑證與**相同的加密通行片語**。選擇所需類別後點擊**儲存**。加入時使用該表單的片語欄位，不會另外自動彈出片語視窗。片語錯誤時會提示失敗，修正表單後再次儲存。

![加入裝置的新增 S3 表單，使用已有儲存位置與片語欄位](/images/sync/s3-second-device-passphrase.png)

妥善儲存片語。遺失片語後，新設定無法還原儲存桶中的加密資料。無法還原時，使用裝置上仍可獲得的本機資料，在全新且為空的儲存桶或前綴下開始同步。移除後端或使用其他儲存位置不會解密舊資料；保留已有加密中繼資料。

## 加密與憑證

設定時，瀏覽器會將填寫的憑證與片語傳送至**自己的 Luker 伺服端**。伺服端在上傳前加密同步資料。儲存桶中的 `head` 與 `packs/` 內容經過加密，`keyinfo.json` 儲存公開的加密中繼資料，不包含片語。

伺服端儲存衍生金鑰以供自動同步，不儲存片語，因此一般同步不會反覆要求輸入。後端清單與狀態回應不會向瀏覽器回傳已儲存的憑證或衍生金鑰。

儲存桶內容加密不能保護透過 HTTP 傳輸的端點憑證。優先透過 HTTPS 保護瀏覽器至 Luker、Luker 至儲存服務的連線。

## 編輯、移除與解鎖

### 編輯連線設定

在後端條目上點擊**編輯**。憑證欄位與**加密通行片語**均留空時，保留已儲存的憑證與加密金鑰。替換憑證時需同時填寫存取金鑰 ID 與秘密存取金鑰，缺少內容會被拒絕。

修改端點、區域、路徑樣式、ETag 引號選項或憑證後，Luker 會驗證能否存取原有的遠端加密身分，再儲存設定。修改端點仍需連線相同的加密儲存位置。填寫片語僅驗證該位置的原片語，不會修改保護資料的片語。

**儲存桶**與**前綴**為唯讀。如需使用其他位置，先**移除**後端，再**新增 S3 後端**。此操作會建立不同的本機後端與同步歷史，不會遷移舊後端。**移除**不會改變遠端儲存桶資料或其他裝置。

### 修復已儲存的金鑰

錯誤提示需要使用片語解鎖時，選擇**解鎖**。僅當已有本機金鑰識別碼有效且與遠端相符時，解鎖才能修復已儲存的加密金鑰。

本機識別碼缺失、無效或遠端識別碼已經改變時，按照錯誤提示**移除**並**新增 S3 後端**。解鎖不能接受其他身分或輪換加密金鑰。加密中繼資料缺失或無效時，需要使用有效副本還原，不要透過刪除或覆寫中繼資料強制設定。

## 故障處理與平台支援

| 提示的問題 | 處理方式 |
| --- | --- |
| 片語與儲存桶及前綴不相符 | 檢查儲存位置，並使用原片語。 |
| 驗證失敗 | 檢查憑證組合與儲存桶權限。 |
| 找不到儲存桶 | 確認設定的端點中存在該儲存桶。 |
| 無法存取端點 | 恢復網路或儲存服務，檢查端點與區域。 |
| 服務不支援條件寫入 | 使用相容的儲存服務。 |
| 服務拒絕 If-Match 中帶引號的 ETag | 啟用**傳送不帶引號的 ETag**後重新儲存。 |
| 禁止連線私有位址 | 請管理員檢查[私有位址策略](/zh-TW/guide/configuration#sync-private-addresses)。 |
| 不支援加密格式 | 更新 Luker 後再次同步。 |
| 同步資料缺失或無效 | 使用有效副本還原儲存桶同步資料後再次同步，參閱[還原說明](./sync#撤銷與還原)。 |

支援在桌面端、Android 與 HarmonyOS 使用 S3 同步。保持 Luker 伺服端執行並能夠存取儲存服務。自動重試遵循[正常同步觸發條件](./sync#自動同步與排程)。

不支援修改加密通行片語、輪換金鑰或自動壓縮同步歷史。首次同步會下載已儲存的歷史，儲存桶用量會隨歷史累積增長。
