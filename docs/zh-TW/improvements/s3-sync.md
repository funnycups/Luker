# S3 同步

S3 同步把 Luker 資料存入共享的加密儲存桶，讓不同網路中的裝置使用同一份資料。同步內容在上傳前完成加密。

同步計畫、類別、衝突選擇、聊天分支與復原操作參閱[同步概覽](./sync)。

## 準備條件

- 升級所有要共享資料的 Luker 安裝。
- 在儲存服務中建立儲存桶，記錄端點、區域與路徑樣式要求。
- 憑證需要能讀寫所選位置，並能刪除設定檢查產生的暫存物件。儲存服務需支援條件寫入，避免並行修改互相覆蓋。
- 加入同步的裝置使用相同儲存桶與正規化前綴。無關資料使用獨立位置。
- 瀏覽器到 Luker、Luker 到儲存服務的連線均優先使用 HTTPS。多使用者安裝連接私有端點時，還需管理員允許[私有位址存取](/zh-TW/guide/configuration#sync-private-addresses)。

## 新增儲存

開啟**使用者設定 → 帳戶 → 備份與還原 → 同步 → 開啟同步**，選擇**新增 S3 後端**。

| 欄位 | 填寫內容 |
| --- | --- |
| **後端名稱** | 目前連線的名稱，例如 Shared archive。 |
| **要同步的類別** | 要共享的資料，參閱[類別與敏感資料](./sync#類別與敏感資料)。 |
| **S3 端點** | 服務提供方的 HTTP 或 HTTPS 端點。優先使用 HTTPS，不要在 URL 中填寫憑證。 |
| **區域** | 儲存服務要求的區域。 |
| **儲存桶** | 既有的儲存桶名稱。 |
| **前綴** | 儲存桶內的位置，例如 `seraphina/`；留空時使用桶根。 |
| **使用路徑樣式請求** | 依儲存服務的位址要求設定。 |
| **傳送不帶引號的 ETag** | 服務支援條件寫入但拒絕 If-Match 中帶引號的 ETag 時啟用。 |
| **存取金鑰 ID**、**秘密存取金鑰** | 可存取該位置的憑證組合。 |
| **加密口令** | 建立新同步位置時設定的口令，或加入既有位置時使用的原口令。 |

**前綴**開頭與結尾的斜線會被忽略，`/seraphina/` 與 `seraphina` 表示同一位置。允許空前綴。內部空路徑段、`.` 或 `..` 路徑段、反斜線與控制字元會被拒絕。

![新增 S3 後端表單，顯示連線欄位、類別與隱藏的敏感值](/images/sync/s3-form.png)

點擊**儲存**。設定期間會用暫存物件檢查條件寫入支援；忽略必要寫入條件的服務無法使用。設定還會檢查 If-Match 中的目前 ETag 能否被接受；服務只拒絕帶引號的 ETag 時，錯誤提示會指向「傳送不帶引號的 ETag」。驗證失敗、儲存桶不存在與連線失敗會分別提示，不會被誤判為相容性問題。

設定完成後，後端出現在**同步後端**中並開始同步。狀態與待處理事項見[活動與檢查](./sync#活動與檢查)。

## 從其他裝置加入

在加入的裝置上選擇**新增 S3 後端**，填寫既有的端點、區域、儲存桶、正規化前綴、憑證與**相同的加密口令**。選擇要共享的類別後點擊**儲存**。加入時使用表單中的口令欄位，不會另外彈出口令視窗。口令錯誤會被拒絕，修正後再次儲存即可。

![加入裝置的新增 S3 表單，使用既有儲存位置與口令欄位](/images/sync/s3-second-device-passphrase.png)

妥善保存口令。沒有口令時，新安裝無法復原儲存桶中的加密資料。無法復原時，從裝置上仍可取得的資料出發，使用全新且為空的儲存桶或前綴。移除後端或改用其他位置不會解密舊資料，既有加密資料應保持不變。

## 加密與憑證

設定時，瀏覽器把憑證與口令傳送到你自己的 Luker 伺服器。伺服器在上傳前加密同步資料，儲存桶中只有加密內容，以及一份不含口令的公開中繼資料。

伺服器保存解鎖自動同步所需的金鑰材料，不保存口令，因此例行同步不會反覆要求輸入。後端列表與狀態回應不會向瀏覽器傳回憑證或金鑰材料。

儲存桶加密不能保護透過 HTTP 傳輸的端點憑證。瀏覽器到 Luker、Luker 到儲存服務的連線均應在可用時使用 HTTPS。

## 編輯、移除與解鎖

### 編輯連線設定

在後端項目上點擊**編輯**。憑證欄位與**加密口令**均留空時，保留已儲存的憑證與金鑰。替換憑證時需同時填寫存取金鑰 ID 與秘密存取金鑰，缺少內容會被拒絕。

修改端點、區域、路徑樣式、ETag 引號選項或憑證後，Luker 會確認新設定仍能存取既有的加密資料，再儲存。端點仍需指向同一加密位置。填寫口令只用於驗證該位置的原口令，不會變更保護資料的口令。

**儲存桶**與**前綴**為唯讀。如需使用其他位置，先**移除**後端，再重新新增。這會建立獨立的後端與同步歷史，不會遷移舊後端。**移除**不會變更儲存桶資料或其他裝置。

### 修復已儲存的金鑰

提示需要口令時，選擇**解鎖**。僅當本機金鑰記錄有效且與遠端資料相符時，解鎖才能修復已儲存的金鑰。

本機記錄缺失、損壞，或遠端資料已經更換加密身分時，依提示**移除**並重新新增後端。解鎖無法改用其他身分，也無法更換加密金鑰。加密中繼資料缺失或損壞時，應從有效副本復原，不要刪除或覆寫後強行設定。

## 故障處理

| 提示的問題 | 處理方式 |
| --- | --- |
| 口令與儲存桶及前綴不相符 | 檢查儲存位置，並使用原口令。 |
| 驗證失敗 | 檢查憑證組合與儲存桶權限。 |
| 找不到儲存桶 | 確認設定的端點中存在該儲存桶。 |
| 無法存取端點 | 復原網路或儲存服務，檢查端點與區域。 |
| 服務不支援條件寫入 | 使用相容的儲存服務。 |
| 服務拒絕 If-Match 中帶引號的 ETag | 啟用**傳送不帶引號的 ETag**後重新儲存。 |
| 禁止連接私有位址 | 請管理員檢查[私有位址策略](/zh-TW/guide/configuration#sync-private-addresses)。 |
| 不支援加密格式 | 更新 Luker 後再次同步。 |
| 同步資料缺失或無效 | 從有效副本復原儲存桶中的同步資料，再同步；參閱[復原說明](./sync#撤銷與還原)。 |

S3 同步支援桌面端、Android 與 HarmonyOS。保持 Luker 伺服器執行並能存取儲存服務。自動重試遵循[正常同步觸發條件](./sync#自動同步與排程)。

不支援修改加密口令、更換金鑰或自動壓縮同步歷史。首次同步會下載已儲存的歷史，儲存桶用量隨歷史累積成長。
