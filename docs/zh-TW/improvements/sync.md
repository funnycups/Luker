# 同步

透過配對的區域網路裝置或加密的 S3 儲存同步 Luker 資料。依後端選擇同步類別，使用統一的衝突處理、還原與同步排程。

## 開啟同步與選擇後端

開啟**使用者設定 → 帳號 → 備份與還原 → 同步 → 開啟同步**。選擇**同步後端**，查看連線、裝置名稱與同步排程。

![同步後端為空，顯示裝置名稱與同步排程](/images/sync/01-panel-empty.png)

| 連線方式 | 設定指南 |
| --- | --- |
| 直接連線能夠相互存取的 Luker 伺服端 | [區域網路同步](./lan-sync)。同步前升級兩端。 |
| 透過不同網路均可存取的加密儲存同步 | [S3 同步](./s3-sync)。裝置使用相同的儲存桶、前綴與加密通行片語。 |

如需將資料遷移至新安裝的環境，參閱[遷移指南](/zh-TW/guide/migration)。

**同步後端**顯示後端名稱、LAN 或 S3 類型、上次同步時間與錯誤。透過對應後端的**立即同步**、**撤銷上次同步**、**編輯**或**移除**執行操作。S3 後端還提供**解鎖**，用於修復已儲存的金鑰。

![已配對的區域網路後端，顯示上次同步時間與操作](/images/sync/06-backends-after-pair.png)

![同步面板同時顯示區域網路與 S3 後端](/images/sync/backend-list.png)

後端名稱用於在目前安裝中識別連線。**目前裝置名稱**用於標記後續修改的來源，顯示在版本卡片與聊天通知中。修改後選擇**儲存裝置名稱**；留空時使用主機名稱或個人資料名稱。修改名稱不會改變已有版本的來源標籤。歷史版本或通用來源顯示為 **Luker Sync**。

## 自動同步與排程

Luker 伺服端會在以下情況下啟動同步：

- 伺服端啟動。
- 本機寫入停止並達到設定的等待時間。
- 達到設定的輪詢間隔，接收其他裝置的修改。
- 收到已配對區域網路裝置的變更通知。
- 選擇**立即同步**。

在**同步排程**中填寫**最後一次編輯後等待多久同步，單位為秒**與**檢查其他裝置變更的間隔，單位為秒**，然後選擇**儲存同步排程**。預設在編輯停止後等待 **60 秒**，後端輪詢間隔為 **300 秒**。填寫正數。

只要 Luker 伺服端仍在執行，關閉瀏覽器後仍會執行同步。關閉應用程式並停止其伺服端後，同步也會停止。裝置離線或儲存服務無法使用時，後續正常觸發會再次嘗試；實際同步時間取決於連線與伺服端執行狀態。

可見的瀏覽器分頁會在載入時及使用期間檢查目前 Luker 伺服端的狀態。這些檢查用於更新介面，不會輪詢遠端後端或啟動同步。

### 活動與檢查

同步狀態入口顯示正在同步的後端名稱與不定進度列。點擊入口即可開啟**同步**。成功且沒有待處理事項時，入口收起；發生錯誤、狀態未知或存在未處理事項時，保留入口供使用者檢查。

![同步狀態入口顯示 Shared archive，下面顯示聊天與輸入框](/images/sync/sync-activity.png)

該入口不顯示百分比或耗時估計。觀察背景狀態不會自動開啟同步面板。使用面板中的**檢查同步問題**重新查看待處理選擇與通知。獨立的自動提醒仍會在載入頁面時顯示待處理事項，並在使用期間發現新事項時開啟同步問題頁。

## 待處理的選擇

不相容的修改需要使用者選擇時，同步會暫時保留可用版本，並在**同步問題**中列出檔案。暫存的資料可以繼續使用，但該選擇仍處於待處理狀態。來自不同後端的相同路徑會合併顯示，已套用的選擇會透過報告該路徑的後端傳播。

![同步警告提示檔案需要選擇版本](/images/sync/07-conflict-banner.png)

根據變更樹與**來自 … 的版本**判斷來源，不要根據卡片位置判斷本機或遠端。檔案按區塊列出修改，展開區塊可查看條目或欄位，開啟欄位後載入修改前後的值。預設分為參數、提示詞、提示詞順序與擴充。世界書按註解或內容首行列出條目。角色卡分為資料、內嵌世界書與擴充。聊天分為中繼資料與訊息。條目順序變化會標記為移動。值按需載入，超出首屏後使用**載入更多**繼續。金鑰檔案只顯示條目標籤與保留末尾四位的遮蔽值。與另一版本完全相同的版本會標記**與 … 相同**。只有來源版本與暫時保留的內容完全相同時，才會標記**使用中**。合併後的版本可以與來源版本均不相同，因此衝突不一定帶有此標記。**目前版本**不會顯示該標記。

![同步問題頁顯示來源版本、變更樹與目前版本](/images/sync/08-conflict-popup.png)

選擇**使用此版本**或**保留目前版本**，然後點擊**套用選擇**。需要選擇時，以整個檔案為單位處理。缺少的一側會標記為刪除，選擇後會刪除該檔案。只要仍有待處理事項，載入頁面時就會再次提醒，直至完成選擇或關閉相應通知。

![解決世界書衝突後顯示同步成功](/images/sync/09-resolved-success.png)

### 衝突後的修改

檔案在衝突發生後再次修改時，同步問題頁會比較目前資料與衝突發生時使用的版本，並顯示覆寫警告。**保留目前版本**會保留後續修改。選擇其他版本時，需要確認**覆寫**；選擇**取消**會保留目前資料與待處理選擇。被覆寫的版本仍儲存在同步歷史中。

![過期衝突顯示後續修改的目前內容與覆寫警告](/images/sync/conflict-stale.png)

![覆寫確認對話方塊，顯示覆寫與取消操作](/images/sync/conflict-stale-confirm.png)

其他裝置已解決的狀態，需要透過成功讀取確認。後端無法讀取時，對應選擇會保持未知狀態。如果出現**無法讀取部分待處理同步記錄。**，檢查受影響的後端，恢復連線或有效資料後再次檢查。讀取結果不完整時，缺少條目不代表已經解決。

**沒能更新的檔案**仍需處理。檢查列出的路徑、儲存存取權限與目標目錄結構，修正提示的問題後選擇**立即同步**。

### 自動合併

Luker 自動合併角色統計、群組與角色卡中相容的最近聊天和日期記錄，以及相容的圖片資料夾中繼資料。不相容的內容或資料夾修改仍需選擇版本。聊天的替代版本按照下文儲存為分支，不會全部轉為檔案選擇卡片。

預設啟用**設定**，衝突時仍需選擇整個檔案。在不同裝置上進行細小的設定修改也會產生衝突。依順序修改設定，同步後再修改另一台裝置。

## 聊天分支與還原的聊天

並行聊天修改產生替代版本時，Luker 會儲存聊天分支並顯示來源裝置。點擊**開啟分支**檢查內容，透過一般[聊天管理](/zh-TW/basics/chat-management)保留、合併或刪除所需內容。通知上的**關閉**僅關閉通知，不會刪除已儲存的分支。

![角色聊天通知，顯示開啟分支與關閉](/images/sync/chat-fork-notice.png)

![群聊分支通知，顯示來源裝置](/images/sync/group-chat-fork-notice.png)

裝置刪除聊天，而其他裝置仍在編輯時，同步會還原被保留的角色聊天或群聊，必要時同時還原所屬群組。點擊**開啟聊天**檢查保留的內容。如需繼續刪除，先停止其他裝置的相關編輯，再透過聊天或群組管理刪除，然後再次同步。

![還原角色聊天的通知，顯示刪除與保留內容的裝置](/images/sync/chat-restored-notice.png)

![還原群聊的通知，顯示開啟聊天與關閉](/images/sync/group-chat-restored-notice.png)

開啟操作要求目標角色或群組以及聊天仍然存在。目標缺失時，操作會被停用或提示開啟失敗。關閉還原通知不會刪除已還原的內容。

## 類別與敏感資料

新增後端時選擇類別，透過**編輯**調整。下表使用介面中的實際類別名稱。

| 選擇狀態 | 類別 |
| --- | --- |
| 預設啟用 | **角色卡**、**聊天與群組**、**世界書（Lorebook）**、**卡片應用**、**技能（Skills）** |
| 預設啟用 | **OpenAI 預設**、**NovelAI 預設**、**KoboldAI 預設**、**文本補全預設**、**指令範本**、**上下文範本**、**系統提示詞**、**推理範本** |
| 預設啟用 | **主題**、**可移動介面佈局**、**快速回覆**、**素材**、**背景**、**使用者設定頭像**、**使用者上傳檔案**、**ComfyUI 工作流程** |
| 預設啟用 | **使用者圖片**、**圖片中繼資料索引**、**向量快取**、**角色統計**、**設定** |
| 按需啟用 | **API 金鑰與憑證**、**擴充功能** |

**聊天與群組**包含角色聊天、群聊與群組。同時選擇**使用者圖片**與**圖片中繼資料索引**，保留圖片的資料夾歸屬。**設定**存在上述整個檔案衝突風險。啟用**擴充功能**前，檢查裝置之間的外掛程式碼與版本差異。

預設關閉**API 金鑰與憑證**。區域網路連線未使用 TLS 時，傳輸的資料及所選金鑰會以明文透過網路。S3 會在儲存前加密同步內容，但 HTTP 仍會暴露傳輸中的端點憑證。使用可信連線並優先選擇 HTTPS；儲存桶內容加密不能替代傳輸安全。

縮圖、本機圖片快取、自動聊天備份、儲存遷移歸檔、執行日誌、伺服端 cookie 金鑰與同步的本機狀態不屬於同步類別。

## 撤銷與還原

在對應後端選擇**撤銷上次同步**，還原上次同步引入的修改。撤銷會建立新的同步修改，其他裝置也會接收，同步歷史繼續保留。同步後再次編輯的檔案會保留較新的資料，並在結果中列出。

撤銷無法套用至本機時會提示錯誤；傳播失敗不代表其他裝置已經還原。恢復後端可用狀態後，選擇**立即同步**傳播已提交但尚未傳出的撤銷。已提交的撤銷會消耗其撤銷點，不應依賴相同撤銷點繼續保留。

重大資料修改前，可以單獨建立[完整 ZIP 備份](/zh-TW/features/user-settings-additions#備份、遷移與儲存)，用於還原。

### 讀取與儲存錯誤

提示「無法更新同步後端。目前顯示上次載入的設定。」時，會繼續顯示先前載入的後端。提示「無法讀取同步狀態。請檢查連線後重試。」時，會保留已知待處理資料，並標記狀態不確定。恢復連線、重新開啟同步或再次檢查後，再根據這些條目進行選擇。

錯誤指出私有同步設定無法讀取或已損壞時，請管理員恢復讀取權限，或使用有效備份還原提示的檔案，然後再修改同步設定。損壞的設定會提示錯誤，不會作為空白設定重新初始化。

目標檔案系統無法區分報告的名稱，或類別路徑經過符號連結時，請管理員在保留原始資料的前提下修正名稱或儲存目錄結構。同步不會自動重新命名或刪除來源資料。目標相容後再次嘗試；還原需要有效的保留副本或備份。

## 儲存模式與管理員策略

支援**檔案儲存、SQLite、MySQL 與 PostgreSQL**，也支援不同儲存模式之間同步。資料庫資料依資源或記錄同步，不會複製整個資料庫。資料庫連線由所屬 Luker 實例使用，對端不需要直接存取該資料庫伺服端。

區域網路同步要求伺服端能夠相互存取。S3 裝置只需存取相同的儲存服務，不要求位於同一區域網路。

多使用者安裝預設限制非管理員帳號向私有、環回與鏈路本地位址發起區域網路或 S3 連線。管理員及未啟用帳號的單使用者模式不受此限制。私有端點被阻擋時，請管理員檢查[私有位址策略](/zh-TW/guide/configuration#sync-private-addresses)。
