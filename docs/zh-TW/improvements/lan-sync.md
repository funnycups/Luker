# 區域網路同步

配對能夠相互存取的 Luker 伺服端，直接同步資料。自動同步、類別、版本選擇、聊天分支與撤銷操作參閱[同步概覽](./sync)。透過共享儲存跨網路同步，參閱 [S3 同步](./s3-sync)。

## 準備條件

- 同步前**升級兩端**，舊協定不再受支援。有效的已有配對會在升級時遷移，無需重新配對。
- 保持 Luker 伺服端執行，並允許相互存取。瀏覽器可以存取對端，不代表反向伺服端連線也已暢通。
- 在兩端啟用區域網路監聽，並透過防火牆與 IP 白名單放行伺服端連接埠。`listen`、監聽位址與存取保護參閱[基礎配置](/zh-TW/guide/configuration)。
- 在安裝環境中使用相同的帳號識別碼。顯示名稱不是帳號識別碼。
- 使用多使用者伺服端的非管理員帳號時，請管理員透過[私有位址策略](/zh-TW/guide/configuration#sync-private-addresses)允許存取私有目標。

使用對端能夠存取的位址，不要使用 `localhost` 或 `127.0.0.1`。未使用 TLS 時，傳輸的資料在網路中不加密；使用可信網路或 HTTPS 連線。

## 產生配對連結

在分享連結的裝置上，開啟**使用者設定 → 帳號 → 備份與還原 → 同步 → 開啟同步**，然後選擇**配對新裝置**。

填寫對端標籤，勾選**要同步的類別：**，點擊**產生配對連結**。預設類別與敏感資料選項參閱[類別說明](./sync#類別與敏感資料)。

![配對新裝置表單，填寫 Tablet 並選擇類別](/images/sync/02-pair-new-form-filled.png)

在**另一台裝置將使用的位址**中選擇可存取的位址。存在非環回位址時，Luker 會優先選擇；伺服端連線不同網路時，可以改選其他位址。點擊**複製連結**，私下傳送給準備配對的裝置。

![已產生的連結，顯示位址選擇與憑證儲存說明](/images/sync/03-pair-link-generated.png)

連結包含有效期為 **10 分鐘**的一次性配對碼。過期後點擊**重新產生**，產生新連結。反向連線檢查失敗後，修正連線仍可使用尚未過期的原連結。

## 接受配對連結

在接收連結的裝置上，開啟相同的同步面板，選擇**與已有裝置配對**，貼上**配對連結**。檢查**另一台裝置的基礎 URL**、**另一台裝置給出的識別碼**、**另一台裝置的標籤**與所選類別。將標籤設為該連線實際存取的裝置，例如 Desk。

僅在對端要求基本驗證時，填寫對端要求的使用者名稱與密碼，否則留空。配對後，填寫的憑證會儲存在目前接收裝置的 Luker 伺服端，用於後續同步。透過目前裝置後端條目上的**清除憑證**移除。

![已貼上配對連結，顯示對端欄位、選填憑證與配對並同步](/images/sync/04-pair-existing-pasted.png)

點擊**配對並同步**。裝置會交換所選資料，成功橫幅顯示已配對後端的名稱。警告橫幅表示存在需要檢查的事項，處理方式參閱[同步概覽](./sync#待處理的選擇)。

![配對後成功與 Desk 同步](/images/sync/05-pair-success-banner.png)

儲存的連線顯示在**同步後端**中。後續依正常觸發條件自動同步，也可按需選擇**立即同步**。

## 配對與連線問題

| 結果 | 處理方式 |
| --- | --- |
| `PEER_CALLBACK_UNREACHABLE`：對端無法反向連線 | 在接收連結的裝置上啟用區域網路監聽，檢查防火牆，再次使用仍有效的原連結。該錯誤表示配對失敗，不代表成功儲存配對。 |
| 提示已經配對，但首次同步失敗 | 連線已儲存。修正提示的原因後，在該後端選擇**立即同步**。 |
| `NO_BASE_URL`：尚不知道對端位址 | 從另一端發起同步，使其提供可存取的位址。 |
| `PEER_PROTOCOL_OUTDATED` | 升級對端 Luker 伺服端，然後再次同步。 |
| `PEER_FORGOTTEN`，或舊配對識別碼無效 | 移除受影響的本機連線，然後重新配對。有效配對的正常升級遷移不需要此操作。 |
| 驗證失敗 | 配對時檢查對端要求的基本驗證憑證。已儲存連線的憑證變更後，按照錯誤提示移除並重新配對。 |
| 帳號識別碼不相符 | 登入相同識別碼的帳號後，再接受連結。 |
| 私有位址被阻擋 | 請管理員檢查[私有位址策略](/zh-TW/guide/configuration#sync-private-addresses)。監聽與防火牆存取仍需單獨設定。 |
| `SYNC_BACKEND_MAINTENANCE` | 對端正在修改同步設定。等待完成後選擇**立即同步**，或等待後續正常觸發。 |
| 其他連線錯誤 | 檢查伺服端、所選位址、連接埠、路由、防火牆與白名單，然後再次同步。 |
