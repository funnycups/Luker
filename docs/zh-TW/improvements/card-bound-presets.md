# 角色卡繫結預設與人設

角色卡作者可以讓角色卡攜帶一個或多個推薦的聊天補全預設，以及一個預設人設（Persona），這樣卡在匯入後就能直接跑在作者設計的取樣與提示詞形態下。該功能構建在[預設解耦](/zh-TW/improvements/preset-decoupling)之上——連線欄位始終會被剝離，匯出的角色卡永遠不會帶 API key 或端點資訊。

## 角色卡攜帶推薦預設

一張角色卡可以內嵌任意多個聊天補全預設，每個預設有自己的名稱和內容。載入帶內嵌預設的角色時，Luker 會：

1. 在聊天補全預設選擇器頂部渲染一個「本卡內嵌」optgroup，列出該卡攜帶的所有預設。
2. 下方是「本地」組，展示你本地儲存的預設。
3. 若卡上標記了預設項，自動選中它。

「本卡內嵌」選項是執行時選項——不會新增到你的全域預設庫，也不會覆蓋同名的本地預設。切換到別的角色時，「本卡內嵌」組會從選擇器裡移除。

::: info 連線欄位永遠不會離開角色卡
每個存進角色卡的預設都會經過與「預設解耦」相同的欄位分類器過濾：API 端點、密鑰、模型、代理密碼等連線欄位在寫入時被剝離。載入「本卡內嵌」預設時只會套用取樣和提示詞結構相關的欄位，無法悄悄把你的請求路由到卡作者的端點。
:::

## 把當前預設繫結到角色

在角色頭像旁的角色管理下拉裡選「繫結當前對話補全預設」。Luker 會把當前選中的預設加入這張卡的內嵌集合，並設為該卡的預設。

- 卡上還沒有同名預設時，作為新槽加入。
- 卡上已經有同名預設時，Luker 會問你是否用當前設定覆蓋卡上那一份。

若當前選中的預設本身就是「本卡內嵌」選項，繫結會被擋下——這種情況沒有可提升的預設，Luker 會給出一條提示，而不是靜默無操作。

## 管理已繫結的預設

「管理已繫結的對話補全預設」為當前角色打開一個對話框，列出所有卡內嵌槽位。每一列提供：

- 「設為預設」——切換載入卡時 Luker 自動套用的槽位。
- 「覆蓋為當前」——用當前選中預設的內容替換該槽位的內容，槽位名保持不變。
- 「從本地更新」——用同名的本地預設覆蓋該槽位內容。當本地沒有同名預設時按鈕不可點。
- 「刪除」——刪除該槽位。若刪的是預設槽位，預設會被清空，直到你重新設定。

對話框底部的「從本地預設新增」控制項讓你挑一個本地預設加為新槽——同名槽已存在的會自動從下拉裡過濾掉。

## 一次性清空所有繫結預設

「清除已繫結的對話補全預設」會一次性清掉當前角色卡上的全部內嵌槽位，只需一次確認。當你想把角色卡還原成「無推薦」的乾淨狀態時用它。

## 直接編輯卡內嵌預設

當選中的預設是「本卡內嵌」槽位時，你在 Prompt Manager、取樣滑桿、提示詞分組、擴充套件開關等常規介面裡做的編輯，都作用在該角色的卡內嵌副本上，而不是你的本地預設庫。要提交這些編輯，點「更新預設設定檔」按鈕。同名的本地預設保持不變。

如果你想讓編輯變成一份獨立的本地預設，請用「另存新預設設定檔」，它會把內容以新名稱註冊進全域列表。

::: tip Prompt Manager 對卡內嵌預設的迭代是透明的
Prompt Manager、補全預設助手 (CPA)，以及任何最終走到「更新預設設定檔」的 AI 迭代流程，都通過同一個 dispatch。對卡內嵌預設的迭代會寫回該卡槽位，沒有額外的「提交到卡」步驟。
:::

## 編排器 agent 預設優先從卡上讀

多 Agent 編排 profile 裡，每個 agent 引用的聊天補全預設都是**按名稱**指向的。當載入了帶內嵌預設的角色卡時，agent 名稱解析規則：先查卡上的內嵌槽位，再查本地預設，最後回退到全域預設。這意味著一份隨卡匯出的編排 profile 是端到端可跑的：接收方無需再單獨匯入匹配的預設。

編排器抽屜裡的「儲存到角色卡覆寫」在持久化前會檢查引用的預設名稱。若有 agent 引用的預設還沒內嵌到卡上，Luker 會彈窗詢問：

- **全部內嵌**——把每個引用預設的本地內容嵌入卡裡，讓編排 profile 在匯出後依然自給自足。
- **僅儲存名稱**——儲存編排 profile 但不嵌入預設內容。接收方若沒有同名本地預設，該 agent 會走執行時預設回退。
- **取消**——中止儲存。

## 角色卡攜帶預設人設

一張角色卡可以繫結一個或多個推薦人設。打開卡時：

- 若你還沒選人設，Luker 會切到卡推薦的人設。
- 若你已選了人設，Luker 會提示當前人設與卡推薦的不一致，由你決定對齊還是保留自己的。

繫結的人設會隨角色卡一起匯出，接收方匯入後能看到同樣的推薦。

## 匯入匯出往返

繫結預設、預設人設、編排器覆寫都是角色卡資料的一部分。標準角色卡匯出（PNG 或 JSON）會一起帶走；標準匯入會一起還原。不需要額外的伴生檔案來散發。

## 依賴

角色卡繫結預設功能依賴[預設解耦](/zh-TW/improvements/preset-decoupling)。沒有解耦提供的欄位分類器，就無法在把預設嵌入角色卡時安全剝離連線欄位。
