# 正則規則作用範圍

一條正則規則可以應用在多個位置。正則編輯器將選擇拆分為兩組，兩組內的選項可以自由組合在同一條規則上。

## 影響條目

「影響條目」決定規則處理哪些內容。

- 「使用者輸入」「AI 輸出」「斜線命令」「世界資訊」「思考」將規則收窄到對應類型的訊息。規則僅對屬於已勾選位置的訊息生效。未勾選任何位置時，規則僅會被儲存；勾選「外掛回覆」的規則會執行。
- 「外掛請求」使規則處理進入外掛請求的文字：聊天樓層文字、外掛拼寫的訊息、世界資訊條目。使用外掛請求時，「影響條目」內至少需要勾選一個訊息類型。
- 「外掛回覆」使規則處理外掛請求回傳的助手正文，不使用訊息類型。
- 「最小深度」與「最大深度」按照訊息在聊天中的位置過濾規則處理的訊息。

## 其他選項 → 暫時性

「暫時性」決定規則是否僅作用於某一份文字而不改寫聊天檔案。

- 「僅修改聊天顯示」——規則改寫聊天介面顯示的內容。
- 「僅修改系統提示詞」——規則改寫主聊天傳送給模型的提示詞。
- 均未勾選，且未勾選「外掛請求」「外掛回覆」時，規則在訊息編輯或儲存時直接改寫聊天檔案。
- 「外掛請求」與「外掛回覆」不受「暫時性」影響。勾選「暫時性」內的選項不會關閉這兩個應用位置。

## 說明

- 規則僅在沒有任何作用範圍時改寫儲存的聊天檔案。勾選「外掛請求」或「外掛回覆」後，規則不會改寫儲存的聊天。規則處理儲存訊息時，訊息類型會收窄處理範圍。
- 正文中自訂的 CoT 標籤需要清除時，不勾選「暫時性」內的選項，也不勾選「外掛請求」「外掛回覆」：規則僅改寫一次儲存的訊息，聊天顯示與傳送給模型的提示詞讀取清理後的文字。訊息類型可收窄處理範圍。
- 清除自訂的 CoT 標籤時同時勾選「僅修改聊天顯示」與「僅修改系統提示詞」，只會帶來效能開銷。
- 自訂的 CoT 標籤需要保留為可摺疊區塊時，使用「進階格式化」→「推理格式」。
