# 正則規則作用範圍

一條正則規則可以套用在多個位置。正則編輯器把選項分成兩組，兩組內的選項可以自由組合在同一條規則上。

## 影響條目

| 選項 | 作用 |
|---|---|
| **使用者輸入**、**AI 輸出**、**斜線命令**、**世界資訊**、**思考** | 只處理對應類型的訊息。都不勾時，規則只儲存，不執行。 |
| **外掛請求** | 處理進入外掛請求的文字：聊天樓層、外掛拼寫的訊息、世界書條目。需要至少勾一個訊息類型。 |
| **外掛回覆** | 處理外掛請求回傳的助手正文。不看訊息類型。 |
| **最小深度**、**最大深度** | 按訊息在聊天中的位置過濾。 |

只勾**外掛回覆**的規則也會執行。

## 暫時性

| 選項 | 作用 |
|---|---|
| **僅修改聊天顯示** | 改寫聊天介面顯示的內容，不改聊天檔案。 |
| **僅修改系統提示詞** | 改寫傳送給模型的提示詞，不改聊天檔案。 |
| 都不勾，且沒勾**外掛請求**、**外掛回覆** | 在訊息編輯或儲存時改寫聊天檔案。 |

**外掛請求**與**外掛回覆**不受暫時性影響；勾選暫時性選項不會關掉它們。

## 說明

- 規則只在沒有任何作用範圍時改寫聊天檔案。勾了**外掛請求**或**外掛回覆**，規則就不改聊天檔案。處理儲存訊息時，訊息類型收窄範圍。
- 清除自訂思維鏈標籤：取消勾選全部四項。規則改寫一次儲存訊息，聊天介面與提示詞都讀取清理後的文字。
- 同時勾**僅修改聊天顯示**和**僅修改系統提示詞**只會多一遍處理，沒有額外效果。
- 想把思維鏈標籤保留成可摺疊區塊，用**進階格式化** → **推理格式**。
