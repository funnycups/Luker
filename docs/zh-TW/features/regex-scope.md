# 正則規則作用範圍

Luker 中每條正則規則都在一條通道內執行。正則編輯器裡的「影響條目」分組決定規則執行的通道，外掛通道則分為兩個方向。

## 通道

- **儲存的聊天歷史**——未勾選任何範圍選項的規則會在訊息編輯或儲存時改寫聊天檔案本身。
- **聊天顯示**——「僅修改聊天顯示」改寫聊天介面顯示的內容，不改動儲存的訊息，也從不影響傳送給模型的內容。
- **主出站提示詞**——「僅修改系統提示詞」改寫主聊天傳送的提示詞，不改動儲存的訊息。
- **外掛通道**——「僅修改插件訊息」改寫外掛驅動的 LLM 請求文字，以及這些請求回傳的文字。

## 位置

「使用者輸入」「AI 輸出」「斜線命令」「世界資訊」「推理」把規則收窄到對應類型的訊息。規則只在角色命中已勾選位置的訊息上執行。未勾選任何位置時，規則不在其中任何一類上執行。

## 外掛通道的方向

外掛通道分為兩個方向：

- 「僅修改插件訊息」與「僅修改系統提示詞」同選時，改寫進入外掛請求的文字：聊天樓層文字、外掛拼寫的訊息、世界資訊條目。
- 只勾選「僅修改插件訊息」時，改寫外掛請求回傳的助手正文。

兩個方向互不重疊，因此一條規則不會在同一段文字上執行兩次。工具呼叫內容從不被改寫；外掛請求回傳工具呼叫時，只有回應正文會被處理。

## 說明

- 勾選「僅修改插件訊息」時，「僅修改聊天顯示」會被停用，因為外掛通道從不改寫聊天顯示。
- 「最小深度」與「最大深度」按訊息在聊天中的位置過濾規則處理的訊息。
