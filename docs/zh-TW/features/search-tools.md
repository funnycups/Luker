# 搜尋外掛

搜尋外掛讓 AI 角色具備即時聯網搜尋能力。在對話過程中，AI 可以自動搜尋網路資訊並將結果融入回覆，讓角色的回答更準確、更有時效性。

搜尋外掛作為 Luker 的內建擴充功能提供，支援多種搜尋引擎後端。

## 支援的搜尋引擎

| 引擎 | 說明 | 是否需要 API Key |
|------|------|------------------|
| DuckDuckGo | 透過 DuckDuckGo Lite 進行搜尋 | 否 |
| SearXNG | 自架的元搜尋引擎 | 否（需自架實例） |
| Brave Search | Brave 提供的搜尋 API | 是 |

你可以在搜尋外掛設定中選擇使用哪個引擎，並設定對應的 API Key 或實例位址。

## 兩種工作模式

### 搜尋代理模式（Search Agent）

搜尋代理是搜尋外掛的核心模式。它使用一個獨立的 LLM Agent 來決定何時搜尋、搜尋什麼、以及如何處理搜尋結果：

1. 使用者發送訊息後，搜尋代理分析對話上下文，判斷是否需要搜尋
2. 如果需要，代理自動建構搜尋查詢並執行搜尋
3. 代理可以進一步存取搜尋結果中的網頁，擷取詳細內容
4. 最終將處理後的資訊注入到提示詞中，供主模型參考

搜尋代理透過[函式呼叫執行時](/zh-TW/improvements/function-call-runtime)框架實現工具呼叫能力，支援多輪搜尋和網頁存取。

搜尋代理可以使用與主對話不同的 LLM 預設和 API 連線，讓你可以用低成本模型處理搜尋決策，用高品質模型處理最終回覆。

### 世界書注入模式

搜尋結果也可以自動寫入世界書條目，透過世界書的關鍵詞匹配機制參與提示詞建構。這種模式適合需要持久化搜尋結果的場景。

相關設定項：

| 設定項 | 說明 |
|--------|------|
| `lorebookDepth` | 世界書條目的掃描深度 |
| `lorebookRole` | 世界書條目的注入角色 |
| `lorebookEntryOrder` | 世界書條目的排序 |

## 搜尋工具定義

搜尋外掛向系統註冊以下工具，供搜尋代理和其他外掛使用：

| 工具 | 說明 |
|------|------|
| `web_search` | 執行網路搜尋，回傳搜尋結果摘要 |
| `visit_url` | 存取指定 URL，擷取網頁內容 |

這些工具透過 `Luker.searchTools` 全域物件暴露，其他外掛可以查詢工具定義和可用性。

## 結果注入

搜尋結果的注入方式可以設定：

| 設定項 | 預設值 | 說明 |
|--------|--------|------|
| 注入位置 | `IN_CHAT` | 搜尋結果在提示詞中的插入位置 |
| 注入深度 | `1` | 搜尋結果的注入深度 |
| 注入角色 | `SYSTEM` | 搜尋結果以哪個角色身分注入 |

搜尋結果綁定到觸發搜尋的使用者訊息樓層。當使用者對同一樓層進行 swipe（滑動切換）時，系統會複用已有的搜尋結果，避免重複搜尋。

## 觸發條件

搜尋外掛支援以下生成類型的觸發：

- `normal`（普通生成）
- `continue`（繼續）
- `regenerate`（重新生成）
- `swipe`（滑動切換）
- `impersonate`（扮演）

你可以在設定中選擇哪些生成類型會觸發搜尋代理。

## 設定項

| 設定項 | 說明 |
|--------|------|
| 搜尋引擎 | 選擇使用的搜尋引擎（DuckDuckGo / SearXNG / Brave） |
| API Key | Brave Search 的 API Key |
| SearXNG 實例 URL | 自架 SearXNG 實例的位址 |
| 搜尋代理 API 預設 | 搜尋代理使用的 API 連線預設 |
| 搜尋代理預設 | 搜尋代理使用的 Chat Completion 預設 |
| 最大搜尋輪次 | 搜尋代理的最大工具呼叫輪次 |
| 搜尋結果數量 | 每次搜尋回傳的結果數量 |
| 網頁擷取最大字元數 | 存取網頁時擷取的最大字元數 |

## 與其他功能的整合

搜尋外掛與 Luker 的多個功能深度整合：

- **[角色卡編輯助手](/zh-TW/features/card-editor)**：Studio AI 可以使用搜尋工具查找參考資料來輔助角色卡編輯
- **[多 Agent 編排](/zh-TW/features/orchestrator)**：編排器的 Agent 節點可以呼叫搜尋工具
- **[記憶圖](/zh-TW/features/memory-graph)**：搜尋結果可以被記憶圖提取為知識節點
