# 自訂工具

自訂工具給編排器裡的 Agent 增加內建能力之外的操作：查詢外部服務、呼叫其他擴充功能的功能，或讀取你自己的資料來源。Loop、Spec、Agenda 和 Director 使用同一套工具定義，切換模式不會遺失。

## 工具來源

**其他擴充功能註冊的工具。** 記憶圖、搜尋外掛等在啟動時註冊自己的工具。它們會自動出現在編排編輯器的自訂工具清單中，新建編排時預設啟用。

**SillyTavern 外掛註冊的工具。** 如果某個外掛透過 SillyTavern 的函式呼叫系統提供工具，可以在編排編輯器裡選擇橋接，並指定它在本編排中是唯讀還是可寫。橋接後的工具出現在獨立的分組裡。

**為目前編排手寫的工具。** 前兩種來源無法滿足時，可以在編排編輯器裡新增一個工具。它隨編排儲存：全域編排中的工具全域生效，角色卡覆寫中的工具隨角色卡匯出。

## 新增工具

新增工具時需要填寫：

- **名稱**：供 Agent 呼叫，只能使用字母、數字和底線，且不能與既有工具重名。
- **顯示名稱**：在編排編輯器裡展示，方便你辨識。
- **描述**：告訴 Agent 這個工具做什麼、什麼時候使用。
- **模式**：唯讀工具沒有副作用；寫入工具會修改狀態，在模擬評審中預設跳過。
- **參數**：Agent 呼叫時需要提供的欄位。依表單填寫即可，不需要手寫結構描述。
- **執行內容**：工具實際執行的邏輯。需要編寫程式碼，屬於開發者功能，介面說明見[編排器工具 API](/zh-TW/development/extension-api/orchestrator-tools)。
- **模擬結果**：選填。為寫入工具提供一份不修改真實狀態的模擬回傳，讓迭代工作台在評審時看到接近真實的結構。

唯讀工具在模擬評審中始終真實執行；寫入工具只有在提供模擬結果時才會執行模擬版本，否則傳回預留位置並標記為未驗證。

## 啟用與停用

編排編輯器的自訂工具面板控制每個工具在本編排中是否提供給 Agent。取消勾選不會刪除定義，之後可以重新啟用。

節點、工作 Agent 或子代理可以個別覆寫工具開關。單一節點的覆寫優先於編排預設值。

## 安全

工具的執行內容在頁面環境中執行，權限與 Luker 自身模組相同：可以發起網路請求、修改全域狀態、讀取聊天內容。只使用你信任的程式碼。

匯入帶有自訂工具的角色卡時，Luker 會先列出每個工具的名稱、描述、模式和完整程式碼，再詢問是否匯入。你可以全部接收、只匯入角色卡而不啟用工具，或展開逐項檢查。

## 用 AI 修改工具

[AI 迭代工作台](/zh-TW/features/orchestrator/iteration-studio)可以讀取既有工具、檢查執行環境、在沙箱中試執行，並把新增或修改作為待審卡片提交。批准前不會寫入編排設定。

來自其他擴充功能的工具定義不能在工作室裡修改，只能切換啟用狀態；要改定義，需要回到註冊它的擴充功能。
