# 編排 AI 迭代

**工作台 → AI 迭代 → 編排**是客製多 Agent 編排方案的主要入口。無需手寫階段圖、調度提示詞或自訂工具程式碼，只需用自然語言描述目標，在**改動清單**中逐條審閱差異並套用。Spec、Agenda、Loop 和 Director 模式共用同一個工作區。

::: tip 優先用 AI 迭代
先用自然語言讓 AI 搭建或調整方案；需要精細微調時，隨時在**工作台 → 編排**（**流程** / **準備階段**）中直接修改。
:::

## 開啟入口

1. 開啟**工作台**（快速鍵 `Alt+W`、魔杖選單 → **工作台**或右下角入口）→ **AI 迭代** → **編排**。
2. 或在**工作台 → 編排**頂列點擊 **AI** 按鈕（也可在**準備階段**點 AI 按鈕）。
3. 排查單次執行或效能瓶頸時，在**執行面板**點擊**結果不滿意？AI 診斷**，或在**編排 → 執行**點擊**診斷這次執行**、在**統計**中點擊**根據統計診斷**。

![迭代視圖](/images/orchestrator/orch-iteration-studio.png)

在頂部選擇編輯範圍：**全域**修改所有角色共用的方案，**角色單獨的**修改目前角色卡的專屬方案（Agenda 模式下還可編輯目前聊天專用方案）。

## 描述你的需求

在輸入框中寫一句具體要求：

> 例：*「我希望 AI 在每次回覆前先回顧近期重要事件、保持人設一致性，並且不要輕易破規出戲。」*

![輸入框帶示例](/images/orchestrator/orch-iter-input.png)

傳送後，AI 會讀取目前編排方案，依需要查閱世界書或技能，並透過工具呼叫產生改動。只要這一輪呼叫了工具，AI 就會自動繼續下一輪，直到給出純文字總結時停止。

## 審閱與套用

AI 提出的修改會進入**改動清單**，支援檢視逐行差異對比。勾選需要保留的改動並點擊**套用所選**，或點擊**全部放棄**。開啟**自動套用**後會即時寫入，每條已套用的改動均可在**工作台 → 改動記錄**中單獨復原。

![待審批的改動](/images/orchestrator/orch-iter-diff-inline.png)

![並排差異詳情](/images/orchestrator/orch-iter-diff-side.png)

## 主要能力

- **全模式編輯**：增刪或調整 Spec 的階段與節點；調整 Agenda 的調度員提示詞與助手池；重寫 Loop 的系統提示詞、工具開關與上限；修改 Director 的主筆與子助手團隊。
- **執行與統計診斷**：直接讀取失敗或耗時過長的執行詳情，定位問題節點並給出或套用修改。
- **模擬測試**：基於目前聊天上下文與世界書啟用狀態試跑一次編排（不寫入真實聊天），並在模擬回顧彈窗中標註問題片段做根因修復。
- **角色卡世界書協同**：在角色作用域下檢查綁定世界書中干擾工具呼叫的格式強制條目，並以待審改動的形式提出溫和改寫。
- **編寫技能與自訂工具**：起草並掛載 `SKILL.md` 技能，或在沙箱試執行後建立自訂工具。
- **會話儲存**：不同目標與作用域的對話各自獨立儲存，隨時可回來繼續調整。

## 典型迭代過程（Spec 示例）

> **你：** *「AI 不要輕易出戲。」*
> **AI：**「在約束階段加一個檢查節點，攔截角色偏離和元評論，並啟用文風檢查。」你勾選並套用改動。
>
> **你：** *「讓它讀世界書，這樣它知道世界規則。」*
> **AI：**「在約束階段加一個世界書讀取節點，讓檢查節點看到當前啟用的世界規則。」你勾選並套用改動。
>
> **你：** *「模擬一個明顯出戲的輸入，看檢查節點真能攔住嗎？」*
> **AI：** 執行一次模擬執行，並傳回檢查節點的判定輸出。

## 角色卡世界書衝突處理

在角色卡作用域下調整編排時，AI 會對照該角色卡綁定的世界書，區分兩類格式規則：

- **過程強制類** —— 強制規定模型每輪必須依固定範本思考或輸出前綴，會干擾工具呼叫流程。AI 會剝離強制格式，保留作者原本關心的人設、話題或場景意圖。
- **最終輸出形態類** —— 規定最終回覆的格式或標籤（如結尾狀態欄、特定排版），AI 會明確限定其只作用於最終提交的正文，避免影響中間規劃與工具呼叫階段。

所有世界書調整同樣進入**改動清單**，由你勾選確認後才會寫入。全域作用域不會修改世界書。

## 用 AI 迭代編寫 Skill {#用工作台編寫-skill}

直接描述需要的寫作規範以及希望誰看到它：

> 幫我寫一條 skill，讓導演避開翻譯腔。別讓角色對話出現「當 X 的時候」這種句式，不要用「——」破折號分隔短句，「是嗎？」改成「是吧？」這種更在地化的語氣詞。讓導演模式下所有 agent 都看到。

AI 會起草 `SKILL.md`、產生安裝提案，並在同一份改動清單裡把該技能新增到對應助手的可見清單。

![工作台執行完成並安裝](/images/skills/iter-studio-05-after-llm-round.png)

完整步驟見[《用 skills 調教 RP 輸出》](/zh-TW/recipes/rp-skills-walkthrough)。

## 會話管理

不同目標、不同角色卡各自的對話記錄獨立儲存，切換角色或重新開啟工作台後可繼續上次討論。
