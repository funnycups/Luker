# 多 Agent 編排

精心鋪墊的場景仍可能被一則回覆破壞：跳過剛建立的節奏、忘記先前確立的世界規則、出戲總結，或倉促收尾本應留到後面的伏筆。一次生成要同時滿足人物一致性、上下文、世界規則、情節推進與文筆，很難每項都到位。

編排器在主模型動筆之前，先執行一組 Agent 完成準備工作：提取近期聊天中的關鍵狀態、確定目前生效的世界規則、規劃這一回合的推進方向並審校。產物取決於執行模式：多數模式輸出一份精簡的編排結果注入主模型的提示詞，Director 模式由編排器內的主筆直接寫出回覆正文。

**編排器自帶可用的預設 Spec 工作流，啟用即可執行。** 所有執行模式均可在**工作台 → 編排**中檢視和編輯，也可透過**工作台 → AI 迭代 → 編排**用自然語言調整。

::: info 它什麼時候觸發？
編排器在一般回覆、繼續、重新生成、滑動切換和扮演時執行，在世界書解析之後、主模型回覆之前。執行軌跡即時展示在執行面板懸浮窗與工作台的執行檢視中。
:::

## 快速開始（使用預設編排）

預設 Spec 已設定完成，啟用後即可執行。

### Step 0 —— 你需要先有什麼 {#step-0}

- 你的主對話已經能正常用 Chat Completion API 出回覆
- 當前對話至少有數輪聊天記錄

### Step 1 —— 啟用編排器 {#step-1}

開啟**工作台**（魔杖選單 → **工作台**、右下角入口、快速鍵 `Alt+W`，或**擴充功能 → 多代理程式編排 → 在工作台中開啟**），切換到左側的**編排**分頁，開啟**啟用編排**開關。

![編排器啟用開關](/images/orchestrator/orch-toggle.png)

### Step 2 —— 給各 Agent 選模型 {#step-2}

在**編排 → 設定**的預設 API 與預設區域，指定各 Agent 使用的連線設定與生成預設；也可以在**流程**檢視裡點選單一助手，單獨指定它的模型與預設。

::: tip 成本
編排器的每個節點都會產生模型呼叫。主對話使用高價模型時，可以為編排器選擇更小的模型；需要更高品質時，也可以為每位助手單獨指定連線與預設。
:::

### Step 3 —— 直接發一條訊息 {#step-3}

在主對話中傳送一則訊息，其他設定保持預設。主模型回覆之前，預設 Spec 工作流會在背景執行。

### Step 4 —— 查看執行過程 {#step-4}

執行開始時，懸浮**執行面板**會在桌面端自動開啟（窄螢幕上從底部升起）。面板即時更新輪次與進度；展開任意助手列，即可檢視思考過程、工具呼叫和回傳結果。

![編排器開始運行時的面板](/images/run-panel/01-panel-initial.png)

模型串流輸出時，面板在原地即時更新：

![串流過程：思考、文字與工具分節即時填充](/images/run-panel/02-panel-streaming.png)

展開任意工具呼叫，能看到它的傳入參數和回傳：

![工具呼叫展開——參數與結果](/images/run-panel/03-panel-tool-expanded.png)

窄螢幕下面板變成底部抽屜，可以上拉展開或下滑關閉：

![窄屏下的運行面板（抽屜佈局）](/images/run-panel/05-panel-drawer.png)

在執行面板中可以執行以下操作：

- 執行中點擊**停止**
- 點擊**檢視執行詳情**，跳轉到**工作台 → 編排 → 執行**查看完整泳道時間軸
- **匯出運行軌跡**為 JSON 檔案，便於分享或回報問題
- 執行結束後點擊**結果不滿意？AI 診斷**，直接帶入本次執行詳情跳轉到**工作台 → AI 迭代 → 編排**

執行面板選單中的**執行時自動開啟**預設開啟；也可以隨時從魔杖選單 → **執行面板**重新開啟。

至此編排器已啟用，接下來選擇執行模式：

- 需要固定、可重複的流程 → [Spec 模式](/zh-TW/features/orchestrator/spec)
- 只需要一次呼叫注入一段引導 → [單 Agent 模式](/zh-TW/features/orchestrator/single)
- 執行哪些 Agent 需要依中間結果決定 → [Agenda 模式](/zh-TW/features/orchestrator/agenda)
- 希望單一 Agent 反覆呼叫工具，自行判斷何時結束 → [Loop 模式](/zh-TW/features/orchestrator/loop)
- 希望由編排器內的團隊直接寫出正文 → [Director 模式](/zh-TW/features/orchestrator/director)

::: tip 定製入口
各模式的定製均可在**[工作台 AI 迭代](/zh-TW/features/orchestrator/iteration-studio)**中完成：用一句話描述目標，在**改動清單**裡逐條審閱後套用，並支援隨時復原。
:::

## 選你的執行模式

| 模式 | 工作台顯示名 | 是什麼 | 何時用 | 技能範圍 | 詳細文件 |
|---|---|---|---|---|---|
| **Spec**（預設） | **流程** | 固定的階段與節點流程 | 預設模式。需要可預期的流程 | 每個節點可個別選擇可見技能 | [Spec 模式](/zh-TW/features/orchestrator/spec) |
| **單 Agent** | **單助手** | 只有一個獨立節點的精簡流程 | 成本低、速度快。不需要多 Agent 協作 | 在該節點上選擇技能 | [單 Agent 模式](/zh-TW/features/orchestrator/single) |
| **Agenda** | **調度** | 調度員依情況動態派遣其他助手 | 流程無法預先固定 | 調度員與每個被派遣的助手分別選擇 | [Agenda 模式](/zh-TW/features/orchestrator/agenda) |
| **Loop** | **循環** | 單 Agent 在會話中反覆呼叫工具，自行判斷何時結束 | 探索性研究、動態決策 | 在研究員上選擇 | [Loop 模式](/zh-TW/features/orchestrator/loop) |
| **Director** | **導演** | 主筆帶子助手團隊探索上下文並創作正文 | 高品質長篇角色扮演 | 主筆與子助手分別選擇；出廠自帶預設技能 | [Director 模式](/zh-TW/features/orchestrator/director) |

在**編排**工作區頂列的模式選擇器中切換模式。在**準備階段**中，Spec 與 Agenda 支援互相複製助手清單。

::: info 技能範圍
所有模式都可以限制每個 Agent 能看到哪些技能。Director 在出廠設定中已繫結預設技能，其他模式的 Agent 預設可以看到全部已安裝技能。技能的作用方式見 [編排器整合](/zh-TW/features/skills/orchestrator-integration)。
:::

## 通用設定

這些設定位於**工作台 → 編排 → 設定**，在所有模式間共享。

### 結果注入

編排器的最終輸出會注入主模型的提示詞（Director 模式由主筆直接寫出正文，結果即正文）。

| 設定 | 預設 | 說明 |
|---|---|---|
| 注入位置 | `在聊天深度` | 編排結果在提示詞中的位置 |
| 注入深度 | `0` | 在該位置的深度 |
| 注入角色 | `System` | `System` / `User` / `Assistant` 之一 |
| 自訂指令 | 預設值為一句話 | 新增在編排結果之前 |

編排結果綁定到觸發編排的使用者訊息樓層。同一樓層切換分支時沿用現有結果；設定變更後重新套用最新結果。

### 角色卡綁定

在**編排 → 準備階段**（或在 **AI 迭代 → 編排**選擇角色卡作用域）可以把編排方案儲存到目前角色卡：

- 方案隨角色卡匯出，匯入者自動獲得推薦工作流
- 切換到這張卡時自動套用其工作流
- 透過**這張卡固定的模式**可以為角色卡鎖定執行模式（Spec / Agenda / Loop / Director 均支援）
- 點擊**清除這張卡上的預設**即可恢復使用全域方案

### 匯入匯出

在**編排 → 準備階段**頂部的方案列中，所有模式（Spec / Agenda / Loop / Director）均支援匯出或匯入 JSON，也可以透過儲存到全域或儲存到角色卡實現跨作用域複用。

### 通用設定參考

**編排 → 設定**集中管理預設 API 連線與生成預設、目前模式的執行上限、跨模式上限（參考的最近回合數、工具呼叫重試次數、每分鐘請求上限）、結果注入設定以及迭代 AI 設定。
