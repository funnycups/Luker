# 便箋

便箋讓 Agent 記錄它打算在以後兌現的劇情線索：已經埋下的伏筆、角色做出的承諾、提前寫好的章節大綱、推理劇情裡在調查之前就定好的真相。每則便箋屬於目前聊天。

## 與記憶圖的區別

| | 記憶圖 | 便箋 |
| --- | --- | --- |
| 回答什麼 | 已經發生了什麼：角色、地點、事件的客觀記錄 | Agent 接下來想讓什麼發生：已埋下但尚未兌現的線索 |
| 誰來寫 | 自動提取，使用者也可以整理 | Agent 在執行中自行開啟和關閉 |
| 何時使用 | 需要回憶既有事實 | 需要記住未來的承諾與伏筆 |

## 誰來維護

Agent 在執行中開啟和關閉便箋。你可以在便箋面板查看、編輯、關閉或永久刪除，但主要作者是 Agent。

想加入自己的劇情方向，用世界書條目或記憶圖的持久注入節點。便箋是 Agent 自己的工作台帳，不適合當作玩家側提示詞。

## 維護原則

便箋是真正的承諾，不是回合日記。未結清的便箋會一直佔用 Agent 的上下文；被瑣事污染的列表會分散它的注意力。

開啟要克制，關閉要積極。Director 的預設流程在起草前挑選本回合該兌現的便箋，起草後只關閉有明確文字證據的條目；沒有證據時不做任何操作。

## 便箋面板

面板位於編排器擴充功能中，作用域是目前聊天，分為兩個分頁：

- **未結清**：目前活躍的線索，每列可以關閉、編輯或刪除。
- **已關閉**：封存記錄，保留關閉原因。

| 操作 | 效果 |
| --- | --- |
| 關閉 | 填寫關閉原因，條目移入已關閉。 |
| 編輯 | 修改文字，狀態和編號保持不變。 |
| 永久刪除 | 從儲存中刪除，需要二次確認。與關閉不同，刪除不會留下記錄。 |

Agent 開啟或關閉便箋時，面板會即時重新整理；你在面板上的修改也會影響 Agent 下一回合看到的內容。

## 常見問題

### 可以手動開啟便箋，給 Agent 加劇情提示嗎

不推薦。需要設定劇情方向時，用世界書條目或記憶圖的持久注入節點。便箋留給 Agent 自己管理。

### 便箋跨聊天共享嗎

不共享。每個聊天有獨立的便箋，切換聊天後看到的是該聊天自己的清單。
