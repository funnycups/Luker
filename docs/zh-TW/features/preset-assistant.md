# 補全預設助手

補全預設助手用對話修改 Chat Completion 預設。它讀取目前預設，解釋參數、對比預設，並把改動做成可審閱的卡片。助手自身的 AI 呼叫使用目前的連線設定，不需要另外設定。

![補全預設助手對話框總覽](/images/preset-assistant/cpa-overview.png)

## 開啟

**擴充功能** → **聊天補全預設助手** → **開啟助手**。**新建預設**從空白預設開始。

頂欄顯示目標預設、助手呼叫用的 API 預設和提示詞預設，以及預設欄位的路徑提示。迭代 AI 的預設下拉框旁有問號按鈕，說明該槽位需要什麼類型的預設，並可以一鍵匯入內建預設。**參考預設**用於和另一個預設對比，差異會渲染成草稿。

直接用自然語言提問：

- 「temperature 和 top_p 有什麼區別？」
- 「我想讓回覆更有創意，應該調整哪些參數？」
- 「幫我對比一下目前預設和內建預設的區別」

助手按目前預設的實際參數回答。

## 能改什麼

- 生成參數：temperature、top_p、懲罰項等。
- 提示詞條目：措辭、順序和結構。

改動以差異卡片的形式返回。逐條批准或拒絕，批准的改動寫入目標預設。

## 編輯模式

**編輯模式**決定助手如何理解你的請求。

- **通用編輯**：按你的要求直接改。預設模式。
- **編排器適配**：用於下游是編排器主代理的預設。它會識別會干擾工具呼叫的強格式約束（強制思維鏈、輸出結構等），改寫成弱引導；把只在最終產物出現的指令限定到提交階段；停用編排器主流程已經重複注入的預留位置（角色卡、人設、世界書）。聊天歷史、越獄、文風、NSFW 和 RP 語態條目保持啟用。
- **僅保留破限**：用於下游是工具型 LLM 呼叫的預設，例如記憶圖整理或其他外掛。它保留越獄指令，停用塑造 RP 敘事文本的條目（文風、角色語態、輸出格式、敘事元規則）。條目本身留在預設裡，可以隨時重新啟用。

模式在會話建立時確定。切換模式會彈出確認並新開一個會話，舊會話留在歷史裡。

在 **編排器適配** 和 **僅保留破限** 模式下，助手預設建議派生一個新預設（原名加 `-orchestrator` / `-jailbreak` 後綴），改動作用在新預設上，原預設保持不動。要改原預設，直接告訴助手。

## 在編排器適配模式下抽取 Skills

適配預設時，助手會掃一遍寫作和輸出格式規則，把適合給編排器所有子代理共用的部分做成提案：

1. 在目前預設的作用域下建立 Skill，正文逐字照搬。
2. 從原提示詞條目裡刪掉這段文字。
3. 在原位置留一行指標，例如 `參考 Skill <skill-name>`，讓條目還能指向這條規則。

提案和其餘適配改動一起以差異卡片返回，逐條批准或拒絕。

只做局部小改（「這句收緊一下」「溫度調到 1.1」「修一下這個錯字」）、你明確說過別動 Skill、以及本次會話裡已經拒過的候選，都不會觸發抽取。

你也可以點名抽取某段文字、複用已安裝的 Skill，或者讓它查看、改名、移動、刪除某個 Skill。把 Skill 掛到某個子代理的可見列表在[編排器迭代工作台](/zh-TW/features/orchestrator/iteration-studio#用工作台編寫-skill)中完成。

派生出 `-orchestrator` 預設後，工具列會出現 **將 Skills 打包到此預設**。點開後進入 [Skill 管理](/zh-TW/features/skills/management) 的多選模式，選好 Skill，再點 **將所選打包進預設……**。其他使用者匯入這份預設時會看到標準的嵌入抽取對話框，Skill 自動安裝到他們的 `preset` 作用域。

::: tip 改過模式提示詞
如果在 *迭代系統提示詞（進階）* 裡改過 **模式追加 —— 編排器適配**，你的文本會覆寫預設值。點 **重置為預設** 恢復內建版本。
:::
