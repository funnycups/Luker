# 補全預設助手

補全預設助手在**工作台 → AI 迭代 → 預設設定檔**中透過對話修改 Chat Completion 預設。它讀取目前選中的預設，解釋參數、與參考預設對比，並將修改放進**改動清單**等待審閱後套用。

![補全預設助手對話框總覽](/images/preset-assistant/cpa-overview.png)

## 開啟

可透過以下任一方式開啟**預設設定檔**編輯：

- 點擊聊天補全預設工具列上的魔杖圖示按鈕。
- 開啟**工作台**（快速鍵 `Alt+W` 或魔杖選單 → **工作台**）→ **AI 迭代** → **預設設定檔**。
- 開啟**擴充功能 → 聊天補全預設助手 → 在工作台中開啟**（同面板還提供**新建預設**與**將 Skills 打包到此預設**）。

在**工作台 → 設定**中設定預設 AI 介面與生成預設，或單獨為**預設設定檔**覆寫連線與預設。

在**預設設定檔**迭代檢視頂部，可以切換**編輯模式**、選擇**與參考預設比較**來檢視與另一個預設的差異，或將目前預設另存為新預設。

直接用自然語言提問：

- 「temperature 和 top_p 有什麼區別？」
- 「我想讓回覆更有創意，應該調整哪些參數？」
- 「幫我對比一下目前預設和內建預設的區別」

## 能改什麼

- 生成參數：temperature、top_p、懲罰項等。
- 提示詞條目：措辭、條目順序與啟用狀態。

AI 提出的修改會以差異卡片進入**改動清單**，逐條勾選套用，並可在**改動記錄**中逐步復原。

## 編輯模式

**編輯模式**決定助手如何理解你的請求：

- **通用編輯**：依你的要求直接修改，預設模式。
- **編排器適配**：用於下游是編排器主代理的預設。它會把會干擾工具呼叫的強格式約束（強制思維鏈、輸出結構等）改寫成弱引導，把只在最終產物出現的指令限定到提交階段，並停用編排器主流程已經注入的預留位置（角色卡、人設、世界書）。聊天歷史、越獄、文風、NSFW 和 RP 語態條目保持啟用。
- **僅保留破限**：用於下游是工具型模型呼叫的預設，例如記憶圖整理或工作台任務。它保留越獄指令，停用塑造 RP 敘事文本的條目（文風、角色語態、輸出格式、敘事元規則）。條目本身留在預設裡，可以隨時重新啟用。

在**編排器適配**和**僅保留破限**模式下，助手預設建議派生新預設（原名加 `-orchestrator` / `-jailbreak` 後綴），原預設保持不動；若需要直接改原預設，可直接說明。

## 在編排器適配模式下抽取 Skills

適配預設時，助手會掃描寫作和輸出格式規則，把適合給編排器所有子代理共用的部分做成提案：

1. 在目前預設的作用域下建立 Skill，正文逐字照搬。
2. 從原提示詞條目裡刪掉這段文字。
3. 在原位置留一行指標，例如 `參考 Skill <skill-name>`，讓條目繼續指向這條規則。

提案和其餘適配改動一起以差異卡片回傳，逐條批准或拒絕。局部小改、明確說過不動 Skill、以及本輪已拒絕的候選會跳過抽取。

也可以點名抽取某段文字、複用已安裝的 Skill，或者讓助手查看、改名、移動、刪除某個 Skill。把 Skill 掛到某個子代理的可見列表在[編排 AI 迭代](/zh-TW/features/orchestrator/iteration-studio#用工作台編寫-skill)中完成。

派生出 `-orchestrator` 預設後，點擊**擴充功能 → 聊天補全預設助手 → 將 Skills 打包到此預設**，即可開啟已篩選至目前預設作用域的 [Skill 管理](/zh-TW/features/skills/management)，便於檢視或補充匯出時附帶的 Skill。
