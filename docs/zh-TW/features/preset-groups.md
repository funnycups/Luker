# 預設分組

預設一多，扁平下拉列表就不好找。預設分組把預設收進命名分組，在下拉中以分組標題與成員展示。

![預設分組](/images/presets/preset-groups.png)

## 管理分組

在預設下拉裡右鍵：

- **新增預設分組**：輸入組名，選中的預設直接進組。
- **移入分組**：把當前預設挪到某個分組。
- **從預設分組移出**：回到未分組狀態。

分組標題上有新建子分組、重新命名、刪除三個按鈕。刪除分組後，成員回到未分組狀態。分組可以巢狀，子分組縮排在父分組下面。

分組按 API 類型分開儲存。切換 API 類型時，下拉顯示該類型的分組。

預設改名後，分組裡的名字跟著變；預設刪除後，自動從分組移除。

## 顯示

點分組標題折疊或展開分組。未分組預設留在列表頂層。
