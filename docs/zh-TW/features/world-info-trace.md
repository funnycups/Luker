# 世界書啟用鏈路追蹤

記錄世界書條目從匹配到注入的過程，用來查條目為什麼被啟用，或者為什麼沒被啟用。

## 記錄什麼

- **觸發關鍵詞** —— 觸發啟用的關鍵詞或關鍵詞組合。
- **匹配位置** —— 匹配到關鍵詞的訊息。
- **掃描深度** —— 當時生效的掃描深度。
- **啟用方式** —— 關鍵詞匹配、常駐、機率啟用等。
- **注入位置** —— 條目最終進入提示詞的位置。

## 查看

世界書編輯器中，每個條目右上角有一個追蹤圖示，點擊後顯示該條目最近一次掃描的過程：

![世界書啟用追蹤彈窗](/images/world-info-trace/wi-trace-popup.png)

彈窗頂部是條目的範圍、最近啟用時間和原因。下面按時間倒序列出掃描記錄，啟用的標紅，未啟用的標灰。據此調整關鍵詞或掃描深度。
