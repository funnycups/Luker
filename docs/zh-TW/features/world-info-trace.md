# 世界書啟動鏈路追蹤

世界書啟動鏈路追蹤是 Luker 引入的除錯功能，幫助你理解世界書條目為什麼被啟動（或沒有被啟動）。

## 解決的問題

當世界書設定變得複雜時（大量條目、多層關鍵詞、不同的掃描深度），使用者經常遇到這樣的困惑：

- 為什麼某個條目沒有被啟動？
- 是哪個關鍵詞觸發了這個條目？
- 條目是在哪條訊息中被匹配到的？
- 掃描深度設定是否合理？

啟動鏈路追蹤記錄了每個條目從匹配到注入的完整過程，讓這些問題一目了然。

## 追蹤資訊

對於每個被啟動的世界書條目，追蹤記錄包含：

- **觸發關鍵詞**：哪個關鍵詞（或關鍵詞組合）觸發了啟動
- **匹配位置**：在哪條訊息中匹配到了關鍵詞
- **掃描深度**：當前的掃描深度設定
- **啟動方式**：關鍵詞匹配、constant（始終啟動）、機率啟動等
- **注入位置**：條目最終被注入到提示詞的哪個位置

## 使用方式

在世界書編輯器裡，每條條目右上角都有一個 fa-route 圖示按鈕，點開就是這條條目最近一次掃描的啟動追蹤：

![世界書啟動追蹤彈窗](/images/world-info-trace/wi-trace-popup.png)

彈窗頂部展示該條目的範圍、最近啟動時間和啟動原因；下方按時間倒序列出最近的掃描記錄，已啟動的掃描標紅，未啟動的標灰。這樣你能立刻看出條目是被哪條訊息裡哪個關鍵詞觸發的、掃描深度是否足夠，從而最佳化關鍵詞或掃描深度設定。
