# 圖像生成與 AI 插圖

Luker 內建的**圖像生成**擴充功能統一了本機與雲端生圖後端、跨後端角色與畫風參考圖協定、雙 agent 協作的**AI 插圖**、全域共享的**角色庫**，以及嵌入[工作台](/zh-TW/features/workbench)的互動式**畫室**。

## 連線設定與生圖預設

開啟**擴充功能 → 圖像生成**，選擇**生圖預設**與**來源**。

- **綁定連線設定** —— **Google AI**、**OpenAI**、**OpenRouter**、**xAI (Grok)**、**Z.AI**、**NanoGPT**、**Chutes**、**Electron Hub**、**AI/ML API**、**Pollinations** 與 **OpenAI 相容多模態對話生圖**支援在**連線設定**下拉選單中直接沿用既有連線設定檔的端點網址、金鑰與代理設定，也支援在面板內點擊 **API 金鑰**單獨設定憑證。
- **失效即時報錯** —— 所綁定的**連線設定**被刪除後，發起生圖會直接提示設定缺失錯誤，重新選擇有效連線設定或改用獨立金鑰後即可恢復。
- **生圖預設切換** —— **生圖預設**完整儲存生圖來源、模型、解析度、取樣參數、連線設定綁定以及畫風參考圖清單，支援一鍵切換。

## 參考圖與畫風參考

在**畫風與氛圍參考**區域點擊**新增畫風參考**，可將本機參考圖片或 `.naiv4vibe` 檔案綁定至目前**生圖預設**。來自全域**角色庫**的角色參考圖與**基於此圖修改**傳入的底圖會依目前後端自動路由：

| 生圖後端 | 支援的參考圖能力 |
| --- | --- |
| **Google AI** Gemini 生圖模型 | 角色參考圖、畫風參考圖、基於底圖修改與動態畫幅比例 |
| **OpenAI 相容多模態對話生圖**與 **OpenRouter** | 多模態角色參考圖、畫風參考圖與底圖修改輸入 |
| **OpenAI** 與 **xAI (Grok)** | 在支援圖像編輯的模型上透過多部分表單攜帶參考圖生成與修改 |
| **NovelAI Diffusion** | V4.5 角色參考圖與還原度控制、V3 與 V4 氛圍轉移及 `.naiv4vibe` 匯入、V4 多角色分區提示詞與座標控制 |
| **ComfyUI** | 自動上傳參考圖並填充工作流中的 `%ref_image%` 與 `%ref_image_1%` 編號佔位符，未傳入參考圖時自動裁剪空置參考節點支路 |
| **Stable Diffusion Web UI** 與 **SD.Next** | 透過圖生圖介面執行基於底圖的局部或整體修改 |

## AI 插圖

在**擴充功能 → 圖像生成**底部展開 **AI 插圖**，勾選**啟用 AI 插圖**。開啟**自動為助手訊息配圖**後會在收到新回覆時自動配圖；也可在魔杖選單點擊**為最後一則訊息生成插圖**，或在單則訊息選單點擊 **AI 插圖**手動觸發。

### 角色一致性與自動探索

為訊息生成插圖時，插圖 agent 依角色類型協同處理外貌設定與參考圖：

- **生圖模型已知的經典同人角色** —— 當生圖模型本身已準確認識該同人角色時，插圖 agent 直接生成提示詞並生圖，略過聯網探索與搜圖步驟。
- **尚未歸檔的生圖陌生同人角色** —— 當場景出現生圖模型不熟悉、且尚未建檔的公開作品角色時，插圖 agent 呼叫**角色建檔 Agent** 讀取角色卡、關聯世界書、公開角色資料庫及[搜尋外掛](/zh-TW/features/search-tools)圖片檢索結果，將核實後的外貌標籤、服裝方案與參考圖寫入全域**角色庫**。若探索模型具備多模態識圖能力，可在**角色建檔 Agent** 抽屜中勾選**開啟多模態視覺審閱下載的候選參考圖**。
- **已歸檔角色** —— 命中全域**角色庫**的角色直接沿用已儲存的核心外貌標籤、服裝方案與本機參考圖。

正文中的內聯插圖標籤在傳送給主對話模型前會自動剝離，外掛上下文讀取歷史樓層時則保留插圖描述以維持前後畫面連貫。

### 正文插圖互動操作

點擊訊息正文中的任意插圖可開啟操作列：

- **重新生成**或**編輯提示詞** —— 基於目前錨點生成新圖片並記入版本歷史樹。
- **基於此圖修改** —— 輸入**修改指令**，在支援底圖修改的後端上將目前插圖作為底圖執行局部或整體調整。
- **鎖定插圖**與**取消鎖定** —— 鎖定單張插圖後，對整則訊息重新執行配圖時保留已鎖定插圖的位置與記錄。
- **切換至此版本** —— 在歷史版本清單中一鍵將正文顯示的插圖切換至任意歷史版本。

## 工作台圖像生成工作區

在**擴充功能 → 圖像生成**中點擊**在工作台中開啟**、在魔杖選單點擊**畫室**，或在[工作台](/zh-TW/features/workbench)左側欄切換至**圖像生成**：

- **畫室** —— 對話式自由生圖與基於底圖修改的工作區，支援開啟**多模態審閱**、**從這裡分支**、會話畫廊單圖重新生成以及跨重啟儲存會話歷史。
- **角色庫** —— 集中管理全域共享的角色外貌標籤、服裝方案與本機參考圖：
  - **AI 建檔**與**AI 調整檔案** —— 開啟對話視窗，透過互動對話建立或微調角色檔案。頂列提供**讀取設定來源**下拉選單，預設維持**不讀取角色卡**，依需求選擇指定角色卡或目前使用者人設。建檔 AI 可檢索公開圖源、下載候選參考圖、呼叫圖像生成製作候選立繪，並向右側**可編輯角色檔案草稿**提交局部變更，遇手動修改衝突時顯示選項供確認。點擊**確認儲存至角色庫**後將保留的候選圖固化為正式參考圖並記入工作台**改動記錄**支援復原；點擊**取消**則清理本次會話的暫存圖片。
  - **手動編輯** —— 點擊**新增角色檔案**直接填寫名稱、標籤、描述、服裝並上傳本機參考圖。
- **執行軌跡** —— 即時檢視插圖與角色探索的輪次軌跡、提示詞與錯誤報告，支援**匯出執行 JSON** 或點擊 **AI 診斷**跳轉至工作台 **AI 迭代**定位問題。

## 使用 AI 迭代 ComfyUI 工作流

當生圖**來源**設為 **ComfyUI** 時，點擊 **ComfyUI 工作流**下拉選單旁的**使用 AI 迭代工作流**，或在[工作台](/zh-TW/features/workbench)的 **AI 迭代**中選擇**圖像生成**：

- **即時查詢已安裝節點** —— 迭代 AI 按需檢索目前連線的 ComfyUI 實例，核實本機已安裝的自訂節點類型、必填與可選輸入參數、可用模型與 LoRA 檔名以及輸出槽位序號。
- **自動接入範本節點與調校拓撲** —— 可直接要求 AI 基於既有 API 格式工作流複製新副本、插入 `%lora_name%` 動態串聯範本節點、依據本機節點接入 `%ref_image%` 或 `%ref_image_1%` 參考圖槽位，以及調整取樣、放大參數與自訂佔位符映射。
- **草稿測試生成與差異復原** —— AI 可直接將工作流草稿傳送至 ComfyUI 執行測試生成並在預覽欄顯示結果，節點報錯時自動依據異常訊息修正連線。所有節點級變更均匯入**改動清單**供逐項勾選套用，套用後可在**改動記錄**中一鍵復原。
