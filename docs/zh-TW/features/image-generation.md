# 圖像生成與 AI 插圖

**圖像生成**擴充功能統一了本機與雲端生圖後端、跨後端角色與畫風參考圖協定、雙 agent 協作的 **AI 插圖**、全域共享的**角色庫**，以及嵌入[工作台](/zh-TW/features/workbench)的互動式**畫室**。

## 連線設定與生圖預設

開啟**擴充功能 → 圖像生成**，選擇**生圖預設**與**來源**。

- **綁定連線設定** —— **Google AI**、**OpenAI**、**OpenRouter**、**xAI (Grok)**、**Z.AI**、**NanoGPT**、**Chutes**、**Electron Hub**、**AI/ML API**、**Pollinations** 與 **OpenAI 相容多模態對話生圖**支援在**連線設定**下拉選單中直接沿用既有連線設定檔的端點網址、金鑰與代理設定，也支援在面板內點擊 **API 金鑰**單獨設定憑證。
- **失效即時報錯** —— 所綁定的**連線設定**被刪除後，發起生圖會直接提示設定缺失錯誤，重新選擇有效連線設定或改用獨立金鑰後即可恢復。
- **生圖預設切換** —— **生圖預設**完整儲存生圖來源、模型、解析度、取樣參數、連線設定綁定、參考與圖生圖開關以及畫風參考圖清單，支援一鍵切換。

## 參考與圖生圖

在**參考與圖生圖**區域，每個**生圖預設**可獨立控制以下參考圖與底圖編輯開關：

- **啟用角色參考** —— 控制 **AI 插圖**與**畫室**是否接入全域**角色庫**。開啟後可透過**傳遞方式**指定角色資料供給形式：
  - **僅文字說明** —— 將角色庫中儲存的純文字**角色說明**與適用的 Danbooru 角色名 tag 融入提示詞，不附帶角色參考圖。
  - **僅參考圖** —— 附帶角色庫中儲存的參考圖，不在提示詞中展開角色庫外貌描述。
  - **文字說明與參考圖** —— 同時結合角色庫純文字**角色說明**編寫提示詞並附帶對應**參考圖**。
- **允許圖生圖編輯（基於既有圖片修改）** —— 控制聊天正文插圖的**基於此圖修改**按鈕與**畫室**的**設為底圖**操作是否開啟。
- **啟用畫風與氛圍參考** —— 控制發起圖像生成時是否合併傳送目前預設儲存的畫風參考圖片或 `.naiv4vibe` 檔案。點擊**新增畫風參考**上傳檔案時會自動開啟該開關；關閉開關後會保留已上傳的畫風參考清單並置灰顯示，生成期間不傳送。

開關下方的即時衝突提示列會在已開啟的開關與目前所選**來源**、**模型**或 **ComfyUI 工作流**不相容時立即顯示具體原因，例如工作流缺少 `%ref_image%` 參考圖節點、所選後端或模型不支援圖片輸入、畫風參考超出 NovelAI 數量上限，或畫風參考佔滿全部共享槽位。在正文插圖點擊**重新生成**或**修改提示詞**、或在**畫室**畫廊點擊**重新生成**時，若舊記錄附帶了目前預設已關閉類型的參考圖，系統會略過已關閉類型並彈出提示。

透過 `/imagine` 斜線指令或開發者介面顯式傳入參考圖時，校驗以目前後端與工作流的底層協定支援為準：

| 生圖後端 | 支援的參考圖協定能力 |
| --- | --- |
| **Google AI** Gemini 生圖模型 | 角色參考圖、畫風參考圖、基於底圖修改與動態畫幅比例 |
| **OpenAI 相容多模態對話生圖**與 **OpenRouter** | 多模態角色參考圖、畫風參考圖與底圖修改輸入 |
| **OpenAI** 與 **xAI (Grok)** | 在支援圖像編輯的模型上透過多部分表單攜帶參考圖生成與修改 |
| **NovelAI Diffusion** | V4.5 角色參考圖與還原度控制、V3 與 V4 氛圍轉移及 `.naiv4vibe` 匯入、V4 多角色分區提示詞與座標控制 |
| **ComfyUI** | 自動上傳參考圖並填充工作流中的 `%ref_image%` 與 `%ref_image_1%` 編號佔位符，未傳入參考圖時自動裁剪空置參考節點支路 |
| **Stable Diffusion Web UI** 與 **SD.Next** | 透過圖生圖介面執行基於底圖的局部或整體修改 |

## AI 插圖

在**擴充功能 → 圖像生成**底部展開 **AI 插圖**，勾選**啟用 AI 插圖**。開啟**自動為助手訊息配圖**後會在收到新回覆時自動配圖；也可在魔杖選單點擊**為最後一則訊息生成插圖**，或在單則訊息選單點擊 **AI 插圖**手動觸發。

### 角色一致性與自動探索

開啟**啟用角色參考**後，插圖 agent 依角色熟悉程度與建檔狀態協同處理角色外貌與參考圖：

- **生圖模型已知的經典同人角色** —— 當生圖模型本身已準確認識該同人角色時，插圖 agent 直接生成提示詞並執行圖像生成，略過聯網探索與搜圖步驟。
- **尚未歸檔的生圖陌生同人角色** —— 當場景出現生圖模型不熟悉且尚未建檔的公開作品角色時，插圖 agent 呼叫**角色建檔 agent** 檢索公開角色資料庫、[搜尋外掛](/zh-TW/features/search-tools)圖片結果及任務指定的設定來源，將核實後的純文字**角色說明**、適用的 Danbooru 角色名 tag 與附帶說明的**參考圖**寫入全域**角色庫**。若建檔所用模型具備識圖能力，可在**角色建檔**抽屜中勾選**允許建檔 agent 識圖檢查候選參考圖**。
- **已歸檔角色** —— 命中全域**角色庫**的角色依目前預設選擇的**傳遞方式**供給純文字**角色說明**或本機**參考圖**。

關閉**啟用角色參考**時，**AI 插圖**直接依據目前對話、角色卡與世界書內容生成提示詞，不讀取或檢索全域**角色庫**。

正文中的內聯插圖標籤在傳送給主對話模型前會自動剝離，外掛上下文讀取歷史樓層時則保留插圖描述以維持前後畫面連貫。

### 正文插圖互動操作

點擊訊息正文中的任意插圖可開啟操作列：

- **重新生成**或**修改提示詞** —— 基於目前錨點生成新圖片並記入版本歷史樹。
- **基於此圖修改** —— 開啟**允許圖生圖編輯（基於既有圖片修改）**後顯示，輸入**修改指令**可在支援底圖修改的後端上將目前插圖作為底圖執行局部或整體調整。
- **鎖定插圖**與**取消鎖定** —— 鎖定單張插圖後，對整則訊息重新執行配圖時保留已鎖定插圖的位置與記錄。
- **切換至此版本** —— 在歷史版本清單中一鍵將正文顯示的插圖切換至任意歷史版本。

## 工作台圖像生成工作區

在**擴充功能 → 圖像生成**中點擊**在工作台中開啟**、在魔杖選單點擊**畫室**，或在[工作台](/zh-TW/features/workbench)左側欄切換至**圖像生成**：

- **畫室** —— 對話式自由生圖與基於底圖修改的工作區，支援開啟**多模態審閱**、**從這裡分支**、會話畫廊單圖重新生成與在開啟圖生圖編輯時可用的**設為底圖**。支援在輸入框透過**新增圖片**、貼上或拖曳附帶圖片供畫室 AI 識圖反推提示詞或直接用作參考圖與底圖；分支時獨立複製附件，刪除會話時自動清理。
- **角色庫** —— 集中管理全域共享的角色視覺檔案，包含**角色標準名稱**、**所屬原作或企劃**、統一填寫外貌與服飾及適用 Danbooru 角色名 tag 的純文字**角色說明**，以及附帶**參考圖說明**的**參考圖**網格：
  - **AI 建檔**與**AI 調整檔案** —— 開啟對話視窗，透過互動對話建立或調整角色檔案。頂列提供**讀取設定來源**下拉選單，預設維持**不讀取角色卡**，依需求選擇指定角色卡或目前使用者人設。輸入框支援透過**新增圖片**、貼上或拖曳附帶角色圖，建檔 AI 可直接識圖反推外貌描述或將其收入**參考圖**，也可以按需檢視右側草稿中已上傳的本機圖與檔案原有參考圖。建檔 AI 可檢索公開圖源與 Danbooru 角色名 tag、下載候選參考圖、呼叫圖像生成製作候選立繪，並向右側**可編輯角色檔案草稿**提交局部變更，遇手動修改衝突時顯示選項供確認。點擊**確認儲存至角色庫**後將保留的候選圖固化為正式參考圖並記入工作台**改動記錄**支援復原；點擊**取消**則清理本次工作階段的暫存圖片。
  - **手動編輯** —— 點擊**新增角色檔案**直接填寫純文字**角色說明**，並透過**上傳本機參考圖**加入附帶**參考圖說明**的本機圖片。
- **執行軌跡** —— 即時檢視插圖與角色探索的輪次軌跡、提示詞與錯誤報告，支援**匯出執行 JSON** 或點擊 **AI 診斷**跳轉至工作台 **AI 迭代**定位問題。

## 使用 AI 迭代 ComfyUI 工作流

當生圖**來源**設為 **ComfyUI** 時，點擊 **ComfyUI 工作流**下拉選單旁的**使用 AI 迭代工作流**，或在[工作台](/zh-TW/features/workbench)的 **AI 迭代**中選擇**圖像生成**：

- **即時查詢已安裝節點** —— 迭代 AI 按需檢索目前連線的 ComfyUI 實例，核實本機已安裝的自訂節點類型、必填與可選輸入參數、可用模型與 LoRA 檔名以及輸出槽位序號。
- **自動接入範本節點與調校拓撲** —— 可直接要求 AI 基於既有 API 格式工作流複製新副本、插入 `%lora_name%` 動態串聯範本節點、依據本機節點接入 `%ref_image%` 或 `%ref_image_1%` 參考圖槽位，以及調整取樣、放大參數與自訂佔位符映射。
- **草稿測試生成與差異復原** —— AI 可直接將工作流草稿傳送至 ComfyUI 執行測試生成並在預覽欄顯示結果，節點報錯時自動依據異常訊息修正連線。所有節點級變更均匯入**改動清單**供逐項勾選套用，套用後可在**改動記錄**中一鍵復原。

## 在工作台中模擬提示詞

在[工作台](/zh-TW/features/workbench)的 **AI 迭代**中選擇**圖像生成**，可在套用改動前直接測試尚未儲存的插圖與角色建檔提示詞：

- **插圖與角色建檔模擬** —— 迭代 AI 可基於目前草稿在隔離沙箱中執行正文插圖、背景角色探索或對話式角色建檔，並開啟**模擬回顧**視窗顯示生成結果、候選圖片、完整提示詞與工具呼叫軌跡。
- **批註與重新生成閉環** —— 開啟**批註模式**可在輸出與軌跡文字上選取批註，點擊**重新生成**可基於原始輸入快照發起全新嘗試；點擊**提交並繼續**後將審閱文字與批註傳回迭代 AI 供後續修改，關閉模擬回顧時自動清理暫存圖片。
