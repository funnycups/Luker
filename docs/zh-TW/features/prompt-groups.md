# 提示詞分組

提示詞管理器裡可以把條目收進命名分組，分組以可折疊的標題展示。

![提示詞分組](/images/presets/prompt-groups.png)

## 分組能做什麼

- **折疊**：點分組標題展開或收起整組。
- **批量開關**：分組標題上的開關一次啟用或停用組內所有條目。
- **Token 統計**：分組標題顯示組內已啟用條目的 Token 總數。
- **拖曳**：拖動分組標題，組內條目一起移動。

分組只影響管理器的展示，提示詞順序不變。

## 管理分組

在提示詞管理器頂部點 **批量編輯**，選中連續的至少兩個條目，再點 **建立分組**。

分組標題上有重新命名、建立子分組、取消分組三個按鈕。取消分組會解散分組，條目留在原位。分組可以巢狀，子分組縮排在父分組下面。

分組隨預設儲存，切換預設時跟著切換。
