# 記憶圖

長對話裡，早期發生的事、關係變化和世界規則會逐漸落出上下文視窗。記憶圖在背景把對話中的關鍵事實整理成帶類型的記憶節點，並在需要時召回注入提示詞，讓角色在數百輪後依然保持連貫記憶。

記憶圖適合長篇角色扮演、連載劇情和需要穩定設定的世界。

## 工作原理

記憶圖在背景執行三項工作。

**提取**：AI 回覆後，記憶圖檢查本輪對話，把值得保留的事實記錄為節點。預設涵蓋四類內容：角色（身分、關係、目標、關鍵物品）、地點（控制者、危險程度、狀態）、事件與劇情線。類型與紀錄欄位可以全域或依角色卡客製。

**召回**：傳送訊息後，記憶圖從既有節點中選出與目前場景相關的內容注入提示詞。預設由模型判斷相關性，也可以改用 RAG 向量召回。

**壓縮**：事件累積較多時，舊事件自動合併為更高層的摘要。細節保留在圖譜中，可以展開查看，也會在相關時再次被召回。

提取可以內建執行，也可以交給[多 Agent 編排](/zh-TW/features/orchestrator/)中的記憶整理助手。

## 開始使用

1. 開啟**工作台**（魔杖選單 → **工作台**、右下角入口、快速鍵 `Alt+W`，或**擴充功能 → 記憶 → 在工作台中開啟**），切換到左側的**記憶圖**分頁。
2. 在**記憶圖 → 設定**中啟用記憶圖。
3. 選擇提取和召回使用的連線設定與聊天補全預設；欄位下方的操作可匯入內建的 `plugin-only` 示例，或開啟預設工作台從現有預設派生。提取屬於結構化整理，小模型即可勝任。
4. 正常聊天，之後在工作台的**記憶圖**分頁中檢視產生結果。

## 工作台中的視圖

工作台內的**記憶圖**工作區提供五個視圖：

- **圖譜** —— 提供關係網與時間軸兩種互動版面，支援節點與關係篩選、檢視注入文字與節點詳細資料欄。
- **時間軸** —— 依摘要層級組織的故事時間軸視圖。
- **資料表** —— 依表列出節點，支援行內按兩下直接修改欄位。
- **記憶結構** —— 編輯記憶類型、紀錄欄位、提取規則、常駐注入開關、內建範本、匯入匯出，以及**標籤過濾**（在提取和召回讀取 AI 回覆前剝離思維鏈、狀態欄等區塊）。
- **設定** —— 設定提取節奏與視窗、LLM 或 RAG 向量召回、自動合併壓縮、token 統計追蹤與迭代 AI 預設。

## 檢視與用 AI 修改

在**資料表**或**圖譜**詳細資料欄中可以直接修改欄位、標題和關係，改動儲存於目前聊天。

需要批次修正時，切換到**工作台 → AI 迭代**並選擇：

- **記憶圖** —— 用自然語言修復目前聊天的圖譜，例如合併重複角色節點、修正過時的地點狀態、補充節點間關係。
- **記憶結構** —— 用自然語言增刪或調整記憶類型、紀錄欄位、提取規則與注入設定，支援全域或僅目前角色生效。

AI 提出的修改會進入**改動清單**顯示前後差異，勾選後套用，並在**改動記錄**中支援逐步復原。

![使用 AI 迭代修復記憶圖節點](/images/memory-graph/memory-ai-revise-proposal.png)

## 讓記憶結構配合你的世界

在**記憶圖 → 記憶結構**或 **AI 迭代 → 記憶結構**中，可以依題材新增自訂類型和紀錄欄位（例如魔法體系、勢力、案件線索），或直接套用內建範本。

![記憶結構編輯器](/images/memory-graph/memory-schema-editor.png)

自訂結構可以設為所有角色共用，也可以僅對目前角色卡生效並隨角色卡匯出。每種類型都可以設定專屬的提取說明與提取間隔。

### 常駐注入

世界法則、核心角色設定和重要主線需要每輪都出現在提示詞中。為對應類型開啟**一直讓 AI 看到**後，其節點會隨每輪回覆常駐注入。設定常駐注入最大回溯樓層數後，更早的節點會退回按需召回候選池。

## 常見問題

### 記憶出現錯誤或重複

在**工作台 → AI 迭代 → 記憶圖**中用自然語言描述問題，由 AI 合併重複節點、刪除條目或調整關係。

### 編輯或刪除訊息後，記憶會怎樣

記憶圖隨聊天歷史同步回復。編輯、刪除訊息或切換分支時，記憶自動回到受影響訊息之前的狀態。

### 換裝置或分享給他人

在**記憶圖 → 設定**中匯出 JSON，再在目標聊天匯入。匯入時可選擇保留原樓層號、綁定到最新樓層或綁定到指定樓層。

### 同一樓層重新生成會重複召回嗎

同一樓層的分支切換與重新生成會沿用上一次召回結果，保持上下文一致並避免重複呼叫模型。

## RAG 向量召回

RAG 召回使用向量檢索。先在 API 連線面板的「嵌入」索引標籤建立嵌入設定並選擇模型與連線，再回到**記憶圖 → 設定**選取該設定並建立向量索引，隨後即可切換到 RAG 召回。
