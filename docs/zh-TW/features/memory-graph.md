# 記憶圖

長對話裡，上下文視窗會被截斷，早期發生的事、關係變化和世界規則逐漸遺失，角色開始「失憶」。記憶圖在背景把對話中的關鍵資訊整理成記憶節點，在需要時召回並注入提示詞，讓角色在幾百輪後仍能記得同一件事。

記憶圖適合長篇角色扮演、連載劇情和需要穩定設定的世界。短對話或一次性場景不必開啟。

## 工作原理

記憶圖在背景做三件事。

**提取**：AI 回覆後，記憶圖檢查本輪對話，把值得保留的資訊建構為節點。預設涵蓋四類內容：角色的身分、關係、目標與隨身物品，地點的控制者與危險程度，發生過的重要事件，以及持續推進的主線。類型與欄位可以依角色卡調整。

**召回**：你傳送訊息後，記憶圖從既有節點中選出與目前場景相關的內容，注入提示詞。預設由 LLM 判斷相關性，也可以改用向量檢索。

**壓縮**：事件累積過多時，舊事件向上合併為更高層的總結。細節保留在圖中，可以展開查看，也會在相關時再次被召回。

提取可以內建執行，也可以交給多 Agent 編排中的記憶整理 agent。

## 開始使用

1. 開啟 **擴充功能 → 記憶**，啟用記憶圖。
2. 在同一面板選擇召回與提取使用的 API 連線和聊天補全預設。預設下拉框旁的問號按鈕說明該槽位需要什麼類型的預設，並可以一鍵匯入內建預設。記憶圖不必與主對話共用模型，提取屬於結構化整理，小模型即可勝任。
3. 正常聊天。經過若干輪對話後開啟記憶面板查看結果。

面板有三個檢視：圖檢視顯示節點與關係，節點檢視依類型列出內容，召回檢視顯示最近一次注入提示詞的內容。

## 查看與修改記憶

節點檢視可以直接編輯欄位、標題和關係，改動儲存在目前聊天中。

需要批次修正時，使用 AI 改圖。入口有兩處：

- 圖檢視器工具列的機器人按鈕
- 記憶面板 → **進階** → **AI 改圖**

用自然語言說明問題，例如「Eileen 和 Elena 是同一個人，合併重複節點」「主角已經離開北境，更新地點狀態」。工作台會讀取目前記憶圖，必要時查閱聊天記錄和世界書，再把改動列為可審閱的卡片。批准後寫入，拒絕則丟棄，已套用的改動可以回復。工作階段依聊天儲存，關閉後再開啟仍能繼續。

首次使用前，在**進階**區域選擇迭代 AI 的 API 連線與提示詞預設。想替換內建指令，編輯**圖修改提示詞**。

## 讓記憶圖配合你的世界

預設類型涵蓋常見角色扮演，奇幻、科幻、懸疑等題材通常需要自己的結構。在記憶面板的**進階**區域點**開啟記憶圖設定**，可以新增類型與欄位。

例如：

- 魔法體系：名稱、來源、限制
- 派系：名稱、領袖、目標
- 案件線索：線索內容、指向對象、可信度

自訂類型隨角色卡儲存和匯出。每種類型可以寫提取指令，說明這類資訊該怎麼記錄；也可以設定提取頻率，讓變化緩慢的類型隔若干輪更新一次。

也可以用自然語言讓 AI 設定。開啟 **進階** → **AI 設定記憶圖**，描述想要的類型、欄位或提取規則，工作台會列出可改項目並逐項確認。

### 讓規則始終留在提示詞裡

世界法則、角色不可違背的設定、敘事禁忌不該依賴召回。把對應類型設為**持久注入**後，這類節點每輪都會出現在提示詞中。持久注入的節點不再進入召回池，避免重複佔用上下文。

## 常見問題

### 記憶出現錯誤或重複

把問題描述給 AI 改圖，由它合併重複節點、刪除條目、修改欄位與關係。

### 編輯或刪除訊息後，記憶會怎樣

記憶圖會隨聊天歷史回復。編輯、刪除訊息或切換 swipe 時，記憶回到受影響訊息之前的狀態。

### 換裝置或分享給他人

在記憶面板匯出 JSON，再在目標聊天匯入。匯入時可以選擇保留原樓層號、綁定到最新樓層或指定樓層。把長期對話的記憶匯入一個空聊天，可以從第 0 樓繼續使用既有的世界觀與人物關係。

### 同一樓層重新生成會重複召回嗎

不會。同一樓層的 swipe 與重新生成會重複使用上次召回結果，保持上下文一致，也避免重複呼叫。

## 設定

設定面板依用途分組：

- **提取**：啟用、提取間隔、提取使用的模型。提取間隔設為 2 表示每兩次 AI 回覆提取一次，成本減半。
- **召回**：LLM 召回或 RAG 召回、召回數量、注入位置與深度。RAG 召回需要先設定嵌入設定檔；啟用重排或查詢改寫可以提升效果，但會增加呼叫與延遲。
- **壓縮**：自動壓縮開關與壓縮頻率。事件較多時開啟。
- **持久注入**：依節點類型設定。適合世界規則與角色核心設定。
- **進階**：AI 改圖與 AI 設定使用的預設、匯入匯出、向量索引重建。

RAG 召回使用向量檢索。啟用前需要準備嵌入設定：在 API 連線設定面板的「嵌入」索引標籤新建設定，選擇嵌入模型與連線，然後回到記憶面板選取該設定並建立向量索引。索引完成後即可切換到 RAG 召回。
