# 角色卡編輯助手

角色卡編輯助手是 Luker 內建的 AI 輔助編輯工具，讓你可以用自然語言指令來修改角色卡設定和世界書條目。每次 AI 做出的修改都會以差異對比的形式展示，由你逐項審批後才會生效——確保角色卡始終在你的掌控之中。

## 兩種編輯方式

### 普通編輯彈窗

在角色卡編輯介面中，你可以直接編輯角色卡的各個欄位（描述、性格、場景設定等）。這是最基礎的編輯方式，適合快速的手動修改。

你可以編輯的欄位包括：

- **角色名稱** — 角色的顯示名稱
- **角色描述** — 角色的外貌、背景、身分等詳細描述
- **性格摘要** — 角色性格特徵的簡要概括
- **場景設定** — 故事發生的場景和背景
- **首條訊息** — 角色的開場白
- **示例對話** — 展示角色說話風格的示例
- **系統提示詞** — 角色卡級別的系統指令
- **越權提示詞（Jailbreak）** — 角色卡級別的越權指令
- **創作者備註** — 給其他使用者的使用說明
- **備選首條訊息** — 多個可選的開場白

### Studio 面板

Studio 是角色卡編輯助手的核心功能——一個獨立於主聊天區域的 AI 對話面板，專門用於角色卡編輯。你可以像和 AI 聊天一樣，用自然語言描述你想要的修改，AI 會理解你的意圖並自動執行。

**典型使用流程：**

1. 在角色卡編輯介面打開 Studio 面板
2. 用自然語言描述你想要的修改，例如：
   - 「把角色的性格改得更內向一些」
   - 「新增一個關於角色家鄉的世界書條目」
   - 「把首條訊息改成在雨天的咖啡館相遇」
   - 「給角色增加一個寵物貓的設定」
3. AI 解析你的指令並執行修改
4. 系統展示修改前後的差異對比，等待你審批
5. 確認後修改生效

**會話管理：**

- Studio 支援多個編輯會話，你可以建立、切換和刪除會話
- 每個角色最多保留 **24** 個會話，超出後最早的會話將被自動清理
- 會話內容會持久化儲存，關閉面板後重新開啟不會遺失

## Studio 的編輯能力

Studio AI 可以透過以下 7 種操作來編輯角色卡和世界書：

| 操作 | 說明 |
|------|------|
| 修改角色設定 | 更新角色卡的文字欄位：名稱、描述、性格、場景、首條訊息、示例對話、系統提示詞、越權提示詞、創作者備註、備選首條訊息 |
| 設定主世界書 | 設定或清除角色卡綁定的主世界書，可自動建立不存在的世界書 |
| 建立/更新世界書條目 | 建立新的世界書條目或更新已有條目的內容、關鍵詞、注入位置等屬性 |
| 刪除世界書條目 | 刪除指定的世界書條目 |
| 列出世界書條目 | 查看當前角色卡關聯世界書的所有條目概覽 |
| 查詢世界書條目 | 按條件查詢世界書條目，取得符合條件的條目詳情 |
| 模擬提示詞組裝 | 模擬當前角色卡設定下的提示詞組裝結果，幫助 AI 理解各欄位在最終提示詞中的實際效果 |

::: tip 模擬提示詞組裝
「模擬提示詞組裝」是一個特別實用的功能。AI 可以透過它查看角色卡各欄位在最終傳送給 LLM 的提示詞中的實際位置和效果，從而做出更精準的編輯建議。例如，AI 可以發現某個設定被放在了不太理想的位置，並建議調整。
:::

## 修改審批

每次 AI 執行修改後，系統會產生修改前後的行級差異對比視圖，清晰展示哪些內容被新增、刪除或修改。

- **逐條審批**：你可以逐一審查每個修改操作
- **批准或拒絕**：對每個修改獨立決定是否接受
- 拒絕的修改會被撤銷，不會影響角色卡資料

這個機制確保 AI 的所有修改都在你的控制之下，不會出現意外的資料變更。

## 操作歷史與回滾

每次成功執行的操作都會被記錄到操作日誌中，包含以下資訊：

- 唯一操作 ID
- 操作類型（如修改角色欄位、建立/更新/刪除世界書條目、設定主世界書等）
- 完整的操作參數
- 來源標記（AI 工具呼叫或手動操作）
- 時間戳

日誌上限為 **120 條**，超出後最早的記錄將被自動裁剪。

你可以在操作歷史中對任意一條記錄執行回滾，將角色卡或世界書恢復到該操作之前的狀態。

**回滾限制：**

- 回滾操作本身也會被記錄為一條日誌
- 不支援對回滾記錄再次回滾（即不能「撤銷回滾」）
- 你也可以刪除單條歷史記錄，或清空所有歷史

## 與搜尋外掛的整合

角色卡編輯助手會自動偵測[搜尋外掛](/zh-TW/features/search-tools)是否可用。如果搜尋外掛已啟用，Studio AI 會額外獲得聯網搜尋和網頁存取能力——你可以讓 AI 搜尋相關資料來輔助角色卡編輯，例如「幫我搜尋一下中世紀騎士的裝備，然後更新角色描述」。

這意味著 AI 在編輯角色卡時可以：

- 搜尋網路取得角色相關的參考資料
- 存取網頁擷取詳細資訊
- 基於搜尋結果完善角色設定

例如，你可以告訴 AI「搜尋一下維多利亞時代的服飾風格，然後更新角色的外貌描述」，AI 會先搜尋相關資料，再據此修改角色卡。

如果搜尋外掛不可用，編輯助手會正常運作，只是不具備網路搜尋能力。

## 世界書同步

當你替換或更新角色卡時，角色卡關聯的世界書可能也需要相應更新。角色卡編輯助手提供了智慧的世界書同步機制：

- 系統會在角色卡被替換時自動偵測世界書變更
- 同步過程可以設定獨立的 LLM 預設和 API 預設
- 透過 `replaceLorebookSyncEnabled` 設定項控制是否啟用同步功能

::: tip 設定建議
如果你經常從外部匯入更新版本的角色卡，建議開啟世界書同步功能，避免世界書資料與角色卡版本不一致。
:::
