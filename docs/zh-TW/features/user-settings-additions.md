# 使用者設定新增功能

Luker 保留了 SillyTavern 的**使用者設定**面板原貌，熟悉的設定位於原來的位置。在此基礎上，Luker 增加了自己的條目：頂列新增若干按鈕，**帳號**中提供完整的備份與遷移工具，以及一組 Luker 獨有的開關。面板頂部還會顯示 Luker 版本與對應的 SillyTavern 相容版本。

面板從頂列的**使用者設定**入口開啟。本頁介紹這些新增項；面板其餘部分與 SillyTavern 的文件一致。

## 日誌、請求檢查器與診斷

頂列新增三個排查入口：

- **日誌** —— 開啟日誌檢視器並選擇來源：**後端**（有權限讀取伺服端日誌時顯示）或**前端**。可依時間範圍與最大筆數篩選、搜尋、複製、清空、手動重新整理，並可保持自動重新整理。伺服端日誌保存在記憶體中，伺服器重啟後即清空。
- **請求檢查器** —— 開啟[請求檢查器](/zh-TW/improvements/request-inspector)：每一次生成請求的生命週期與 token 用量，圖像生成和向量嵌入 / 重排呼叫也包含在內。
- **診斷** —— 開啟診斷選單：
  - **匯出除錯日誌** —— 下載一份用於排查的打包報告 `luker-debug-<timestamp>.json`，內含前端日誌、效能標記、裝置與視口資訊，以及伺服端日誌、[請求檢查器](/zh-TW/improvements/request-inspector)緩衝區與執行時資訊。在 Android 應用裡，這個條目會改為呼叫應用原生的診斷匯出。
  - **下載效能報告** —— 儲存一份來自瀏覽器 JS Self-Profiling API 的取樣快照。該條目僅在瀏覽器端顯示；Chrome 與 Edge 支援這項 API。
  - **啟用 JS 自我取樣分析（實驗性）** —— 僅在瀏覽器端顯示。在頁面載入時盡早啟動瀏覽器的 JS Self-Profiling API，並持續取樣直到你將其關閉。開關保持開啟時，下載報告後會自動繼續取樣。
  - **前端除錯日誌** —— 讓所有層級的主控台日誌進入瀏覽器主控台。無論開關狀態如何，主控台輸出均會寫入記憶體緩衝區。
  - **Android 偵錯記錄** —— 僅 Android 應用。把額外的診斷資訊（主控台輸出、堆積取樣、渲染標記、WebView 崩潰）記入崩潰報告使用的原生除錯軌跡。下次應用重啟後生效。
  - **擷取記憶體快照**與**開始效能錄製** —— 管理員在支援該功能的應用程式中會看到這兩個條目。前者儲存一份堆積快照；後者開始效能錄製，選單條目變為**停止效能錄製**，停止時儲存錄製結果。

日誌檢視器與前端日誌緩衝區的更多細節見[日誌系統](/zh-TW/features/logging)。

## 沉浸模式

**進入沉浸模式**會隱藏介面裝飾，並在瀏覽器允許的範圍內進入全螢幕，適合在不被介面干擾的情況下閱讀長回覆。退出方式包括：同一個按鈕、螢幕上的退出控制項、`Esc` 鍵，或在 Android 應用中使用返回手勢。Luker 會記住你上次是否處於沉浸模式，並在下次恢復。

**介面主題**下還有一個相關開關：

- **沉浸模式下保留頂部欄** —— 在沉浸模式開啟時保持頂部欄可見，而不是隱藏它。適合在閱讀時仍需存取選單的情境。

## 備份、遷移與儲存

頂列的**帳號**按鈕會開啟一個彈窗，其中 Luker 新增的條目包括：

- **備份與還原** —— 目錄層級的備份管理器。先選擇要包含的**資料類別**：**設定**、**API 金鑰 / 機密**、**角色 / 頭像**、**聊天 / 群組**、**世界書**、**預設 / 介面佈局**、**資產 / 檔案**、**使用者擴充套件**、**全域擴充套件（僅管理員）**以及**向量索引**。**全選**、**使用預設選項**與**清除**可一次設定整份選擇，這份選擇對下載、還原與區域網路遷移均生效。

  然後要麼**下載備份 ZIP**，要麼用**選擇 ZIP** + **還原備份**還原，並二選一還原模式：**增量更新**寫入備份中的檔案、其餘檔案原樣保留；**覆蓋更新**則先清空所選類別再還原。如果 ZIP 來自另一套儲存引擎的伺服器，Luker 會辨識出跨模式還原，並要求你提供一個臨時資料庫連線，供它在還原過程中中轉。

- **區域網遷移** —— 一次性遷移到全新裝置：在舊裝置上**建立遷移連結**，再到新裝置上貼上並點擊**從連結遷移**。遷移連結有效期很短，且僅可使用一次。所選的還原模式同樣適用於從遷移連結匯入。長期使用不同裝置時，使用[同步](/zh-TW/improvements/sync)，透過[區域網路配對](/zh-TW/improvements/lan-sync)或[加密 S3 儲存](/zh-TW/improvements/s3-sync)交換資料。

- **同步** —— 開啟**使用者設定 → 帳號 → 備份與還原 → 同步 → 開啟同步**。[同步概覽](/zh-TW/improvements/sync)介紹自動同步、類別、待處理選擇、聊天分支與撤銷，區域網路與 S3 指南說明設定方式。

- **儲存審查**與**瀏覽器儲存** —— 從兩個視角查看資料的實際位置。[儲存審查](/zh-TW/features/storage-inspector)依類別拆解伺服端資料目錄，並配有配額條；敏感內容僅顯示體積，且不提供任何刪除操作。**瀏覽器儲存**則檢查目前瀏覽器的 `localStorage`、`sessionStorage`、IndexedDB 與 Cache Storage，並且可以刪除單一鍵、物件倉庫、資料庫與快取。

- **資料目錄** —— 桌面版應用程式顯示 Luker 存放聊天、備份、外掛與擴充的位置。點擊**變更**會把資料遷移到另一個目錄並重新啟動 Luker，或改用既有的 Luker 資料目錄；目錄需要可寫入並有足夠的可用空間。啟動時目錄無法使用，Luker 會提示重試、重新選擇目錄或結束。詳見[變更資料目錄](/zh-TW/guide/desktop#變更資料目錄)。

## 後台生成與通知

生成轉入背景時，以下兩項設定影響行為。

- **行動端後台保活**（在 **介面主題** 下）—— 讓 AI 請求在應用或瀏覽器轉入背景後繼續執行。在 Android 與鴻蒙應用中，它只是一個開關，由原生層維持請求存活。在手機瀏覽器中，啟用它會彈出選擇框：

  - **子母畫面** —— 螢幕上多一個懸浮小視窗，顯示目前角色、生成狀態與串流回覆，不會打斷正在播放的音樂。點擊小視窗回到 Luker 會關閉它；生成期間可透過 **恢復子母畫面** 重新開啟。主畫面網頁應用不提供此選項。
  - **音訊** —— 一個無聲的媒體工作階段，只在訊息生成期間生效，生成結束後很快退出；執行期間其他音樂或影片應用會被暫停。

  兩個選擇均會被記住。桌面端會整列隱藏，因為桌面端不存在此問題。

- **回覆完成通知**與**通知內容**（在**其他**下）—— 當 Luker 處於背景時顯示系統通知。生成開始時先顯示進度通知，隨後由結果通知取代；生成失敗時還會顯示失敗通知。**通知內容**決定通知是**僅狀態**還是**包含訊息內容**。頁面處於焦點時通知會被抑制。

## 外部連結

- **外部連結以系統瀏覽器開啟**（在 **介面主題** 下）—— 僅在桌面應用、Android 與鴻蒙應用中顯示，預設開啟。關閉後，一般第三方連結會在 Luker 視窗內開啟。要求獨立視窗的連結仍以應用內浮層視窗開啟，第三方授權流程可以完成。在瀏覽器中該列隱藏；iOS 應用始終以系統瀏覽器開啟外部連結。

## 聊天渲染與離開頁面

- **延遲載入訊息媒體** —— 預設開啟。聊天中的圖片與影片只在接近視口時才載入，使包含大量媒體內容的長聊天保持較低的渲染開銷。外掛如需某個元素立即載入，可針對該元素單獨退出此策略。
- **方向鍵切換回覆** —— 預設開啟，僅桌面版顯示。關閉後左右方向鍵不再切換最後一則回覆。
- **離開頁面確認** —— 關閉或重新整理頁面前給出提醒。**僅在有風險時**（預設）會在生成進行中、存在未提交的訊息編輯、或輸入框中仍有未送出文字時提醒；**從未**與**總是**則覆蓋這一判斷。
