# 使用者設定新增功能

Luker 保留了 SillyTavern 的**使用者設定**面板原貌——熟悉的設定仍位於原來的位置。在此基礎上，Luker 增加了自己的條目：頂列新增若干按鈕，**帳號**中提供完整的備份與遷移工具，以及一組 Luker 獨有的開關。

面板從頂列的**使用者設定**圖示開啟。本頁介紹這些新增項；面板其餘部分與 SillyTavern 的文件一致。

## 日誌、除錯匯出與請求檢查器

面板頂端的三個按鈕：

- **日誌** —— 開啟日誌檢視器並選擇來源：**後端**（有權限讀取伺服端日誌時顯示）或**前端**。可依時間範圍與最大筆數篩選、搜尋、複製、清空，並可保持自動重新整理。伺服端日誌保存在記憶體中，伺服器重啟後即清空。
- **匯出除錯日誌** —— 下載一份用於排查的打包報告 `luker-debug-<timestamp>.json`，內含前端日誌、效能標記、裝置與視口資訊，以及伺服端日誌、[請求檢查器](/zh-TW/improvements/request-inspector)緩衝區與執行時資訊。在 Android 應用裡，這個按鈕會改為呼叫應用原生的診斷匯出。
- **請求檢查器** —— 開啟[請求檢查器](/zh-TW/improvements/request-inspector)：每一次生成請求的生命週期與 token 用量，圖像生成和向量嵌入 / 重排呼叫也包含在內。

日誌檢視器與前端日誌緩衝區的更多細節見[日誌系統](/zh-TW/features/logging)。

## 沉浸模式

**進入沉浸模式**會隱藏介面裝飾，並在瀏覽器允許的範圍內進入全螢幕，適合在不被介面干擾的情況下閱讀長回覆。退出方式有四種：同一個按鈕、螢幕上的退出控制項、`Esc` 鍵，或在 Android 應用中使用返回手勢。Luker 會記住你上次是否處於沉浸模式，並在下次恢復。

**介面主題**下還有一個相關開關：

- **沉浸模式下保留頂部欄** —— 在沉浸模式開啟時保持頂部欄可見，而不是隱藏它。適合在閱讀時仍需存取選單的情境。

## 備份、遷移與儲存

頂端的**帳號**按鈕會開啟一個彈窗，其中的條目包括：

- **備份與還原** —— 目錄層級的備份管理器。先選擇要包含的**資料類別**：**設定**、**API 金鑰 / 機密**、**角色 / 頭像**、**聊天 / 群組**、**世界書**、**預設 / 介面佈局**、**資產 / 檔案**、**使用者擴充套件**、**全域擴充套件（僅管理員）**以及**向量索引**。**全選**、**使用預設選項**與**清空**可一次設定整份選擇，這份選擇對底下所有操作都生效。

  然後要麼**下載備份 ZIP**，要麼用**選擇 ZIP** + **還原備份**還原，並二選一還原模式：**增量更新**寫入備份中的檔案、其餘檔案原樣保留；**覆蓋更新**則先清空所選類別再還原。如果 ZIP 來自另一套儲存引擎的伺服器，Luker 會辨識出跨模式還原，並要求你提供一個臨時資料庫連線，供它在還原過程中中轉。

- **區域網遷移** —— 一次性遷移到全新裝置：在舊裝置上**建立遷移連結**，再到新裝置上貼上並點擊**從連結遷移**。遷移連結有效期很短，且僅可使用一次。如果兩台裝置要長期並用，[區域網路同步](/zh-TW/improvements/lan-sync)更合適：它是雙向增量的，只傳輸發生變化的部分。

- **儲存審查**與**瀏覽器儲存** —— 從兩個視角查看資料的實際位置。[儲存審查](/zh-TW/features/storage-inspector)依類別拆解伺服端資料目錄，並配有配額條；敏感內容僅顯示體積，且不提供任何刪除操作。**瀏覽器儲存**則檢查目前瀏覽器的 `localStorage`、`sessionStorage`、IndexedDB 與 Cache Storage，並且可以刪除單一鍵、物件倉庫、資料庫與快取。

## 行動端保活

在手機上使用 Luker 時，有兩個設定值得注意。

- **行動端後台保活**（在 **介面主題** 下）—— 讓 AI 請求在應用或瀏覽器轉入背景後繼續執行。在 Android 上它只是一個開關，直接要求原生層維持請求存活。在手機瀏覽器中，啟用它會彈出選擇框：

  - **子母畫面** —— 螢幕上多一個懸浮小視窗，不會打斷正在播放的音樂。
  - **音訊** —— 一個無聲的媒體工作階段，只在訊息生成期間生效，生成結束後很快退出；執行期間其他音樂或影片應用會被暫停。

  兩個選擇都會被記住。桌面端會整列隱藏，因為桌面端不存在此問題。

- **回覆完成通知**與**通知內容**（在**其他**下）—— 當 Luker 處於背景時，訊息生成完成後會彈出系統通知。**通知內容**決定通知是**僅狀態**還是**包含訊息內容**，這樣無需切回應用即可查看回覆內容。頁面處於焦點時通知會被抑制。

## 聊天渲染與離開頁面

**聊天／訊息處理**下的兩個小改進：

- **延遲載入訊息媒體** —— 預設開啟。聊天中的圖片與影片只在接近視口時才載入，使包含大量媒體內容的長聊天保持較低的渲染開銷。外掛如需某個元素立即載入，可針對該元素單獨退出此策略。
- **離開頁面確認** —— 關閉或重新整理頁面前給出提醒。**僅在有風險時**（預設）會在生成進行中、存在未提交的訊息編輯、或輸入框中仍有未送出文字時提醒；**從未**與**總是**則覆蓋這一判斷。

## 診斷開關

需要提供證據而不只是描述問題時：

- **前端除錯日誌** —— 把全部前端主控台輸出鏡像到瀏覽器主控台，便於排查。無論開關狀態如何，前端日誌都會寫入記憶體緩衝區；這個開關決定有多少內容會到達主控台。
- **Android 偵錯記錄** —— 僅 Android 應用。把額外的診斷資訊（主控台輸出、堆積取樣、渲染標記、WebView 崩潰）記入崩潰報告使用的原生除錯軌跡。下次應用重啟後生效。
- **啟用 JS 自我取樣分析（實驗性）**與**下載效能報告** —— 在頁面載入時盡早啟動瀏覽器的 JS Self-Profiling API，並持續取樣直到你將其關閉。下載按鈕會儲存一份取樣快照；如果開關仍處於開啟狀態，下載完成後會自動繼續取樣。這一對功能僅限 Chrome 與 Edge——Safari 與 Firefox 不支援該 API。
