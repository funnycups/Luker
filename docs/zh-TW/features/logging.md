# 日誌系統

Luker 記錄伺服器端與瀏覽器端的日誌，在**使用者設定 → 日誌**中查看。

## 後端日誌

服務啟動後，Luker 收集伺服器端的控制台輸出，保存在固定大小的記憶體緩衝區中，寫滿後丟棄最舊的項目。每筆記錄帶時間戳與層級。

在日誌管理員中把來源切到**後端**，即可依時間或筆數篩選、搜尋、複製與清空。伺服器端日誌對管理員可見。

緩衝區位於記憶體，服務重新啟動後清空。需要長期保留時，把控制台輸出重新導向到檔案。

## 前端日誌

瀏覽器端同樣收集控制台輸出，未處理的錯誤與 Promise 拒絕也會記錄。

預設只有 `error` 層級輸出到瀏覽器控制台。在**診斷**選單啟用**前端除錯日誌**後，所有層級都會輸出。該開關控制瀏覽器控制台的輸出範圍，日誌管理員始終記錄所有層級。

## 匯出

在**診斷**選單選擇**匯出除錯日誌**，下載包含前端日誌、效能標記、裝置與視口資訊、伺服器端日誌和請求檢查器記錄的 JSON 檔案。回報問題時附帶該檔案。

::: warning
日誌和請求檢查器記錄可能包含 API 金鑰等敏感內容。分享前檢查。
:::

## 常見排查

- **API 連線失敗** —— 後端日誌中有錯誤資訊；檢查位址和金鑰。
- **生成中斷** —— 前端日誌，或[請求檢查器](/zh-TW/improvements/request-inspector)中的請求生命週期。
- **擴充功能報錯** —— 前端日誌記錄擴充功能執行時的錯誤。
