# Build a CardApp from Scratch

CardApp Studio builds a complete card from a plain-language brief: you describe the result, Studio proposes each change, and writes it after you confirm. Both walkthroughs produce a card you can chat with, covering Memory Graph, multi-agent orchestration, a card-specific world book and a panel that follows the conversation.

| Example | Genre | What it sets up | Start here if |
| --- | --- | --- | --- |
| [Isekai Survival Log](/features/card-editor/walkthrough/isekai) | Western low-magic survival RP | A top status bar for day, stamina, hunger and mood, plus a world book and optional scene illustrations | You want a working CardApp quickly |
| [Victorian Case File](/features/card-editor/walkthrough/victorian) | 1888 London detective card | Memory graph node types, multi-agent orchestration, a card-specific world book, and a panel driven by case-state entries | You want to see memory and orchestration work together |

Both follow the same sequence: Studio proposes, you confirm, Studio writes, and every edit is shown for review. The Victorian walkthrough also uses Memory Graph and multi-agent orchestration.
