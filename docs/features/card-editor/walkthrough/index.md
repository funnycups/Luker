# Build a CardApp from Scratch

This section walks through real-genre cards to show **how to drive CardApp Studio end-to-end** — no code from you; just steer Studio in plain language to design schemas, loops, world books, and CardApp panels.

Two examples, pick by genre and complexity:

| Example | Genre | Covered capabilities | Good for |
| --- | --- | --- | --- |
| [Isekai Survival Log](/features/card-editor/walkthrough/isekai) | Western low-magic isekai survival RP | Top status bar (Day / Stamina / Hunger / Mood) + World Info + scene illustrations (optional) | Quickest path to a runnable CardApp |
| [Victorian Case File](/features/card-editor/walkthrough/victorian) | 1888 London Holmes-style detective card | Derived memory-graph schema + orchestrator loop (draft → critique → revise) + card-specific world book + variable-driven CardApp panel | Seeing schema / loop / variable-driven UI cooperate end-to-end |

Both examples follow the same playbook — Studio proposes, you nod, Studio lands; every tool call shows a diff for approval. They differ in which capability layers they exercise.

New to Studio? Start with [Isekai Survival Log](/features/card-editor/walkthrough/isekai). Want to see the full stack on one card? See [Victorian Case File](/features/card-editor/walkthrough/victorian).
