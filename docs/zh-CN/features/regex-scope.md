# 正则规则作用范围

Luker 中每条正则规则都在一条通道内运行。正则编辑器里的「作用范围」分组决定规则运行的通道，插件通道则分为两个方向。

## 通道

- **存储的聊天历史**——未勾选任何范围选项的规则会在消息编辑或保存时改写聊天文件本身。
- **聊天显示**——「仅格式显示」改写聊天界面显示的内容，不改动存储的消息，也从不影响发送给模型的内容。
- **主出站提示词**——「仅格式提示词」改写主聊天发送的提示词，不改动存储的消息。
- **插件通道**——「仅对插件消息生效」改写插件驱动的 LLM 请求文本，以及这些请求返回的文本。

## 位置

「用户输入」「AI输出」「快捷命令」「世界信息」「推理」把规则收窄到对应类型的消息。规则只在角色命中已勾选位置的消息上运行。未勾选任何位置时，规则不在其中任何一类上运行。

## 插件通道的方向

插件通道分为两个方向：

- 「仅对插件消息生效」与「仅格式提示词」同选时，改写进入插件请求的文本：聊天楼层文本、插件拼写的消息、世界信息条目。
- 只勾选「仅对插件消息生效」时，改写插件请求返回的助手正文。

两个方向互不重叠，因此一条规则不会在同一段文本上运行两次。工具调用内容从不被改写；插件请求返回工具调用时，只有响应正文会被处理。

## 说明

- 勾选「仅对插件消息生效」时，「仅格式显示」会被禁用，因为插件通道从不改写聊天显示。
- 「最小深度」与「最大深度」按消息在聊天中的位置过滤规则处理的消息。
