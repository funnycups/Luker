# 正则规则作用范围

一条正则规则可以应用在多个位置。正则编辑器将选择拆分为两组，两组内的选项可以自由组合在同一条规则上。

## 作用范围

「作用范围」决定规则处理哪些内容。

- 「用户输入」「AI输出」「快捷命令」「世界信息」「思考」将规则收窄到对应类型的消息。规则仅对属于已勾选位置的消息生效。未勾选任何位置时，规则仅被保存；勾选「插件回复」的规则会执行。
- 「插件请求」使规则处理进入插件请求的文本：聊天楼层文本、插件拼写的消息、世界信息条目。使用插件请求时，「作用范围」内至少需要勾选一个消息类型。
- 「插件回复」使规则处理插件请求返回的助手正文，不使用消息类型。
- 「最小深度」与「最大深度」按照消息在聊天中的位置过滤规则处理的消息。

## 其他选项 → 短暂

「短暂」决定规则是否仅作用于某一份文本而不改写聊天文件。

- 「仅格式显示」——规则改写聊天界面显示的内容。
- 「仅格式提示词」——规则改写主聊天发送给模型的提示词。
- 均未勾选，且未勾选「插件请求」「插件回复」时，规则在消息编辑或保存时直接改写聊天文件。
- 「插件请求」与「插件回复」不受「短暂」影响。勾选「短暂」内的选项不会关闭这两个应用点。

## 说明

- 规则仅在没有任何作用范围时改写存储的聊天文件。勾选「插件请求」或「插件回复」后，规则不会改写存储的聊天。规则处理存储消息时，消息类型会收窄处理范围。
- 正文中自定义的 CoT 标签需要清除时，不勾选「短暂」内的选项，也不勾选「插件请求」「插件回复」：规则仅改写一次存储的消息，聊天显示与发送给模型的提示词读取清理后的文本。消息类型可收窄处理范围。
- 清除自定义的 CoT 标签时同时勾选「仅格式显示」与「仅格式提示词」，只会带来性能开销。
- 自定义的 CoT 标签需要保留为可折叠区块时，使用「高级格式化设置」→「推理内容格式化」。
