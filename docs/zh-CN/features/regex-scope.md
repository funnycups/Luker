# 正则规则作用范围

一条正则规则可以应用在多个位置。正则编辑器把选项分成两组，两组内的选项可以自由组合在同一条规则上。

## 作用范围

| 选项 | 作用 |
|---|---|
| **用户输入**、**AI 输出**、**快捷命令**、**世界信息**、**思考** | 只处理对应类型的消息。都不勾时，规则只保存，不执行。 |
| **插件请求** | 处理进入插件请求的文本：聊天楼层、插件拼写的消息、世界书条目。需要至少勾一个消息类型。 |
| **插件回复** | 处理插件请求返回的助手正文。不看消息类型。 |
| **最小深度**、**最大深度** | 按消息在聊天中的位置过滤。 |

只勾**插件回复**的规则也会执行。

## 短暂

| 选项 | 作用 |
|---|---|
| **仅格式显示** | 改写聊天界面显示的内容，不改聊天文件。 |
| **仅格式提示词** | 改写发给模型的提示词，不改聊天文件。 |
| 都不勾，且没勾**插件请求**、**插件回复** | 在消息编辑或保存时改写聊天文件。 |

**插件请求**与**插件回复**不受短暂影响；勾选短暂选项不会关掉它们。

## 说明

- 规则只在没有任何作用范围时改写聊天文件。勾了**插件请求**或**插件回复**，规则就不改聊天文件。处理存储消息时，消息类型收窄范围。
- 清除自定义思维链标签：取消勾选全部四项。规则改写一次存储消息，聊天界面与提示词都读取清理后的文本。
- 同时勾**仅格式显示**和**仅格式提示词**只会多一遍处理，没有额外效果。
- 想把思维链标签保留成可折叠区块，用**高级格式化设置** → **推理内容格式化**。
