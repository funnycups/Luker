# 用户设置新增功能

Luker 保留了 SillyTavern 的**用户设置**面板原貌——熟悉的设置仍位于原来的位置。在此基础上，Luker 增加了自己的条目：顶行新增若干按钮，**帐户**中提供完整的备份与迁移工具，以及一组 Luker 独有的开关。

面板从顶栏的**用户设置**图标打开。本页介绍这些新增项；面板的其余部分与 SillyTavern 的文档一致。

## 日志、调试导出与请求检查器

面板顶行的三个按钮：

- **日志** —— 打开日志查看器并选择来源：**后端**（有权限读取服务端日志时显示）或**前端**。可按时间范围与最大条数过滤、搜索、复制、清空，并可保持自动刷新。服务端日志保存在内存中，服务器重启后即清空。
- **导出调试日志** —— 下载一份用于排查的打包报告 `luker-debug-<timestamp>.json`，内含前端日志、性能标记、设备与视口信息，以及服务端日志、[请求检查器](/zh-CN/improvements/request-inspector)缓冲区和运行时信息。在 Android 应用里，这个按钮会改为调用应用原生的诊断导出。
- **请求检查器** —— 打开[请求检查器](/zh-CN/improvements/request-inspector)：每一次生成请求的生命周期与 token 用量，图像生成和向量嵌入 / 重排调用也包含在内。

日志查看器和前端日志缓冲区的更多细节见[日志系统](/zh-CN/features/logging)。

## 沉浸模式

**进入沉浸模式**会隐藏界面装饰，并在浏览器允许的范围内进入全屏，适合在不被界面干扰的情况下阅读长回复。退出方式有四种：同一个按钮、屏幕上的退出控件、`Esc` 键，或在 Android 应用中使用返回手势。Luker 会记住你上次是否处于沉浸模式，并在下次恢复。

**UI主题**下还有一个相关开关：

- **沉浸模式下保留顶部栏** —— 在沉浸模式开启时保持顶部栏可见，而不是隐藏它。适合在阅读时仍需访问菜单的场景。

## 备份、迁移与存储

顶行的**帐户**按钮会打开一个弹窗，其中的条目包括：

- **备份与恢复** —— 目录级的备份管理器。先选择要包含的**数据类别**：**设置**、**API 密钥 / 机密**、**角色 / 头像**、**聊天 / 群组**、**世界书**、**预设 / 界面布局**、**资产 / 文件**、**用户扩展**、**全局扩展（仅管理员）**以及**向量索引**。**全选**、**使用默认选择**和**清空**可一次设置整个选择，该选择对下方所有操作均生效。

  然后要么**下载备份 ZIP**，要么用**选择 ZIP** + **恢复备份**还原，并二选一恢复模式：**增量更新**写入备份中的文件、其余文件原样保留；**覆盖更新**则先清空所选类别再还原。如果 ZIP 来自另一套存储引擎的服务器，Luker 会识别出跨模式恢复，并要求你提供一个临时数据库连接，供它在恢复过程中中转。

- **局域网迁移** —— 一次性迁移到全新设备：在旧设备上**创建迁移链接**，再到新设备上粘贴并点击**从链接迁移**。迁移链接有效期很短，且仅可使用一次。如果两台设备要长期并用，[局域网同步](/zh-CN/improvements/lan-sync)更合适——它是双向增量的，只传输发生变化的部分。

- **存储审查**与**浏览器存储** —— 从两个视角查看数据的实际位置。[存储审查](/zh-CN/features/storage-inspector)按类别拆解服务端数据目录，并配有配额条；敏感内容仅显示体积，且不提供任何删除操作。**浏览器存储**则检查当前浏览器的 `localStorage`、`sessionStorage`、IndexedDB 和 Cache Storage，并且可以删除单个键、对象仓库、数据库和缓存。

## 移动端保活

在手机上使用 Luker 时，有两个设置值得注意。

- **移动端后台保活**（在 **UI主题** 下）—— 让 AI 请求在应用或浏览器转入后台后继续运行。在 Android 上它只是一个开关，直接要求原生层维持请求存活。在手机浏览器中，启用它会弹出选择框：

  - **画中画** —— 屏幕上多一个悬浮小窗，不会打断正在播放的音乐。
  - **音频** —— 一个无声的媒体会话，只在消息生成期间生效，生成结束后很快退出；运行期间其他音乐或视频应用会被暂停。

  两个选择都会被记住。桌面端会整行隐藏，因为桌面端不存在此问题。

- **回复完成通知**和**通知内容**（在**杂项**下）—— 当 Luker 处于后台时，消息生成完成后会弹出系统通知。**通知内容**决定通知是**仅状态**还是**包含消息内容**，这样无需切回应用即可查看回复内容。页面处于焦点时通知会被抑制。

## 聊天渲染与离开页面

**聊天/消息处理**下的两个小改进：

- **懒加载消息媒体** —— 默认开启。聊天中的图片和视频只在接近视口时才加载，使包含大量媒体内容的长聊天保持较低的渲染开销。插件如需某个元素立即加载，可针对该元素单独退出此策略。
- **离开页面确认** —— 关闭或刷新页面前给出提醒。**仅在有风险时**（默认）会在生成进行中、存在未提交的消息编辑、或输入框中仍有未发送文字时提醒；**从未**和**永远**则覆盖这一判断。

## 诊断开关

需要提供证据而不只是描述问题时：

- **前端调试日志** —— 把全部前端控制台输出镜像到浏览器控制台，便于排查。无论开关状态如何，前端日志都会写入内存缓冲区；这个开关决定有多少内容会到达控制台。
- **Android 调试记录** —— 仅 Android 应用。把额外的诊断信息（控制台输出、堆采样、渲染标记、WebView 崩溃）记入崩溃报告使用的原生调试轨迹。下次应用重启后生效。
- **启用 JS 自采样分析（实验性）**与**下载性能报告** —— 在页面加载时尽早启动浏览器的 JS Self-Profiling API，并持续采样直到你将其关闭。下载按钮会保存一份采样快照；如果开关仍处于开启状态，下载完成后会自动继续采样。这一对功能仅限 Chrome 和 Edge——Safari 与 Firefox 不支持该 API。
