# 用户设置新增功能

Luker 保留 SillyTavern 的**用户设置**面板原貌，熟悉的设置位于原来的位置。在此基础上，Luker 增加了自己的条目：顶行新增若干按钮，**帐户**中提供完整的备份与迁移工具，以及一组 Luker 独有的开关。面板顶部还会显示 Luker 版本与对应的 SillyTavern 兼容版本。

面板从顶栏的**用户设置**入口打开。本页介绍这些新增项；面板的其余部分与 SillyTavern 的文档一致。

## 日志、请求检查器与诊断

顶行新增三个排查入口：

- **日志** —— 打开日志查看器并选择来源：**后端**（有权限读取服务端日志时显示）或**前端**。可按时间范围与最大条数过滤、搜索、复制、清空、手动刷新，并可保持自动刷新。服务端日志保存在内存中，服务器重启后即清空。
- **请求检查器** —— 打开[请求检查器](/zh-CN/improvements/request-inspector)：每一次生成请求的生命周期与 token 用量，图像生成和向量嵌入 / 重排调用也包含在内。
- **诊断** —— 打开诊断菜单：
  - **导出调试日志** —— 下载一份用于排查的打包报告 `luker-debug-<timestamp>.json`，内含前端日志、性能标记、设备与视口信息，以及服务端日志、[请求检查器](/zh-CN/improvements/request-inspector)缓冲区和运行时信息。在 Android 应用里，这个条目会改为调用应用原生的诊断导出。
  - **下载性能报告** —— 保存一份来自浏览器 JS Self-Profiling API 的采样快照。该条目仅在浏览器端显示；Chrome 与 Edge 支持这一 API。
  - **启用 JS 自采样分析（实验性）** —— 仅在浏览器端显示。在页面加载时尽早启动浏览器的 JS Self-Profiling API，并持续采样直到你将其关闭。开关保持开启时，下载报告后会自动继续采样。
  - **前端调试日志** —— 让所有级别的控制台日志进入浏览器控制台。无论开关状态如何，控制台输出均会写入内存缓冲区。
  - **Android 调试记录** —— 仅 Android 应用。把额外的诊断信息（控制台输出、堆采样、渲染标记、WebView 崩溃）记入崩溃报告使用的原生调试轨迹。下次应用重启后生效。
  - **抓取内存快照**与**开始性能录制** —— 管理员在支持该功能的应用中会看到这两个条目。前者保存一份堆快照；后者开始性能录制，菜单条目变为**停止性能录制**，停止时保存录制结果。

日志查看器和前端日志缓冲区的更多细节见[日志系统](/zh-CN/features/logging)。

## 沉浸模式

**进入沉浸模式**会隐藏界面装饰，并在浏览器允许的范围内进入全屏，适合在不被界面干扰的情况下阅读长回复。退出方式包括：同一个按钮、屏幕上的退出控件、`Esc` 键，或在 Android 应用中使用返回手势。Luker 会记住你上次是否处于沉浸模式，并在下次恢复。

**UI主题**下还有一个相关开关：

- **沉浸模式下保留顶部栏** —— 沉浸模式开启时保持顶部栏可见，适合阅读时仍需访问菜单的场景。

## 备份、迁移与存储

顶行的**帐户**按钮会打开一个弹窗，其中 Luker 新增的条目包括：

- **备份与恢复** —— 目录级的备份管理器。先选择要包含的**数据类别**：**设置**、**API 密钥 / 机密**、**角色 / 头像**、**聊天 / 群组**、**世界书**、**预设 / 界面布局**、**资产 / 文件**、**用户扩展**、**全局扩展（仅管理员）**以及**向量索引**。**全选**、**使用默认选择**和**清空**可一次设置整个选择，该选择对下载、恢复与局域网迁移均生效。

  然后要么**下载备份 ZIP**，要么用**选择 ZIP** + **恢复备份**还原，并二选一恢复模式：**增量更新**写入备份中的文件、其余文件原样保留；**覆盖更新**则先清空所选类别再还原。如果 ZIP 来自另一套存储引擎的服务器，Luker 会识别出跨模式恢复，并要求你提供一个临时数据库连接，供它在恢复过程中中转。

- **局域网迁移** —— 一次性迁移到全新设备：在旧设备上**创建迁移链接**，再到新设备上粘贴并点击**从链接迁移**。迁移链接有效期很短，且仅可使用一次。所选的恢复模式同样适用于从迁移链接导入。长期使用不同设备时，使用[同步](/zh-CN/improvements/sync)，通过[局域网配对](/zh-CN/improvements/lan-sync)或[加密 S3 存储](/zh-CN/improvements/s3-sync)交换数据。

- **同步** —— 打开**用户设置 → 帐户 → 备份与恢复 → 同步 → 打开同步**。[同步概览](/zh-CN/improvements/sync)介绍自动同步、类别、待处理选择、聊天分支与撤销，局域网与 S3 指南说明配置方式。

- **存储审查**与**浏览器存储** —— 从两个视角查看数据的实际位置。[存储审查](/zh-CN/features/storage-inspector)按类别拆解服务端数据目录，并配有配额条；敏感内容仅显示体积，且不提供任何删除操作。**浏览器存储**则检查当前浏览器的 `localStorage`、`sessionStorage`、IndexedDB 和 Cache Storage，并且可以删除单个键、对象仓库、数据库和缓存。

## 后台生成与通知

生成转入后台时，以下两项设置影响行为。

- **移动端后台保活**（在 **UI主题** 下）—— 让 AI 请求在应用或浏览器转入后台后继续运行。在 Android 与鸿蒙应用中，它只是一个开关，由原生层维持请求存活。在手机浏览器中，启用它会弹出选择框：

  - **画中画** —— 屏幕上多一个悬浮小窗，显示当前角色、生成状态与流式回复，不会打断正在播放的音乐。点击小窗回到 Luker 会关闭它；生成期间可通过 **恢复画中画** 重新开启。主屏幕网页应用不提供此选项。
  - **音频** —— 一个无声的媒体会话，只在消息生成期间生效，生成结束后很快退出；运行期间其他音乐或视频应用会被暂停。

  两个选择均会被记住。桌面端会整行隐藏，因为桌面端不存在此问题。

- **回复完成通知**和**通知内容**（在**杂项**下）—— 当 Luker 处于后台时显示系统通知。生成开始时先显示进度通知，随后由结果通知取代；生成失败时还会显示失败通知。**通知内容**决定通知是**仅状态**还是**包含消息内容**。页面处于焦点时通知会被抑制。

## 外部链接

- **外部链接用系统浏览器打开**（在 **UI主题** 下）—— 仅在桌面应用、Android 与鸿蒙应用中显示，默认开启。关闭后，普通第三方链接会在 Luker 窗口内打开。请求独立窗口的链接仍以应用内浮层窗口打开，第三方授权流程可以完成。在浏览器中该行隐藏；iOS 应用始终用系统浏览器打开外部链接。

## 聊天渲染与离开页面

- **懒加载消息媒体** —— 默认开启。聊天中的图片和视频只在接近视口时才加载，使包含大量媒体内容的长聊天保持较低的渲染开销。插件如需某个元素立即加载，可针对该元素单独退出此策略。
- **方向键刷新回复** —— 默认开启，仅桌面端显示。关闭后左右方向键不再刷新最后一条回复。
- **离开页面确认** —— 关闭或刷新页面前给出提醒。**仅在有风险时**（默认）会在生成进行中、存在未提交的消息编辑、或输入框中仍有未发送文字时提醒；**从未**和**永远**则覆盖这一判断。
