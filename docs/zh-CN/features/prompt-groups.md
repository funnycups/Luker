# 提示词分组

提示词管理器里可以把条目收进命名分组，分组以可折叠的标题展示。

![提示词分组](/images/presets/prompt-groups.png)

## 分组能做什么

- **折叠**：点分组标题展开或收起整组。
- **批量开关**：分组标题上的开关一次启用或禁用组内所有条目。
- **Token 统计**：分组标题显示组内已启用条目的 Token 总数。
- **拖拽**：拖动分组标题，组内条目一起移动。

分组只影响管理器的展示，提示词顺序不变。

## 管理分组

在提示词管理器顶部点 **批量编辑**，选中连续的至少两个条目，再点 **创建分组**。

分组标题上有重命名、创建子分组、取消分组三个按钮。取消分组会解散分组，条目留在原位。分组可以嵌套，子分组缩进在父分组下面。

分组随预设保存，切换预设时跟着切换。
