# 补全预设助手

补全预设助手在**工作台 → AI 迭代 → 预设**中通过对话修改 Chat Completion 预设。它读取当前选中的预设，解释参数、与参考预设对比，并将修改放进**改动清单**等待审阅后应用。

![补全预设助手对话框总览](/images/preset-assistant/cpa-overview.png)

## 打开

可通过以下任一方式打开**预设**编辑：

- 点击聊天补全预设工具栏上的魔杖图标按钮。
- 打开**工作台**（快捷键 `Alt+W` 或魔杖菜单 → **工作台**）→ **AI 迭代** → **预设**。
- 打开**扩展 → 聊天补全预设助手 → 在工作台中打开**（同面板还提供**新建预设**与**将 Skills 打包到此预设**）。

在**工作台 → 设置**中配置默认 AI 接口与生成预设，或单独为**预设**覆盖连接与预设。

在**预设**迭代视图顶部，可以切换**编辑模式**、选择**与参考预设比较**来查看与另一个预设的差异，或将当前预设另存为新预设。

直接用自然语言提问：

- 「temperature 和 top_p 有什么区别？」
- 「我想让回复更有创意，应该调整哪些参数？」
- 「帮我对比一下当前预设和默认预设的区别」

## 能改什么

- 生成参数：temperature、top_p、惩罚项等。
- 提示词条目：措辞、条目顺序与启用状态。

AI 提出的修改会以差异卡片进入**改动清单**，逐条勾选应用，并可在**改动记录**中逐步撤销。

## 编辑模式

**编辑模式**决定助手如何理解你的请求：

- **通用编辑**：按你的要求直接修改，默认模式。
- **编排器适配**：用于下游是编排器主代理的预设。它会把会干扰工具调用的强格式约束（强制思维链、输出结构等）改写成弱引导，把只在最终产物出现的指令限定到提交阶段，并禁用编排器主流程已经注入的占位符（角色卡、人设、世界书）。聊天历史、越狱、文风、NSFW 和 RP 语态条目保持启用。
- **仅保留破限**：用于下游是工具型模型调用的预设，例如记忆图整理或工作台任务。它保留越狱指令，禁用塑造 RP 叙事文本的条目（文风、角色语态、输出格式、叙事元规则）。条目本身留在预设里，可以随时重新启用。

在**编排器适配**和**仅保留破限**模式下，助手默认建议派生新预设（原名加 `-orchestrator` / `-jailbreak` 后缀），原预设保持不动；若需要直接改原预设，可直接说明。

## 在编排器适配模式下抽取 Skills

适配预设时，助手会扫描写作和输出格式规则，把适合给编排器所有子代理共用的部分做成提案：

1. 在当前预设的作用域下创建 Skill，正文逐字照搬。
2. 从原提示词条目里删掉这段文字。
3. 在原位置留一行指针，例如 `参考 skill <skill-name>`，让条目继续指向这条规则。

提案和其余适配改动一起以差异卡片返回，逐条批准或拒绝。局部小改、明确说过不动 Skill、以及本轮已拒绝的候选会跳过抽取。

也可以点名抽取某段文字、复用已安装的 Skill，或者让助手查看、改名、移动、删除某个 Skill。把 Skill 挂到某个子代理的可见列表在[编排 AI 迭代](/zh-CN/features/orchestrator/iteration-studio#用工作台编写-skill)中完成。

派生出 `-orchestrator` 预设后，点击**扩展 → 聊天补全预设助手 → 将 Skills 打包到此预设**，即可进入 [Skill 管理](/zh-CN/features/skills/management)的多选模式，把所选 Skill 打包进预设以便导出分享。
