# 补全预设助手

补全预设助手用对话修改 Chat Completion 预设。它读取当前预设，解释参数、对比预设，并把改动做成可审阅的卡片。助手自身的 AI 调用使用当前连接配置，不需要另外配置。

![补全预设助手对话框总览](/images/preset-assistant/cpa-overview.png)

## 打开

**扩展** → **聊天补全预设助手** → **打开助手**。**新建预设**从空白预设开始。

顶栏显示目标预设、助手调用用的 API 预设和提示词预设，以及预设字段的路径提示。迭代 AI 的预设下拉框旁有问号按钮，说明该槽位需要什么类型的预设，并可以一键导入内置预设。**参考预设**用于和另一个预设对比，差异会渲染成草稿。

直接用自然语言提问：

- 「temperature 和 top_p 有什么区别？」
- 「我想让回复更有创意，应该调整哪些参数？」
- 「帮我对比一下当前预设和默认预设的区别」

助手按当前预设的实际参数回答。

## 能改什么

- 生成参数：temperature、top_p、惩罚项等。
- 提示词条目：措辞、顺序和结构。

改动以 diff 卡片的形式返回。逐条批准或拒绝，批准的改动写入目标预设。

## 编辑模式

**编辑模式**决定助手如何理解你的请求。

- **通用编辑**：按你的要求直接改。默认模式。
- **编排器适配**：用于下游是编排器主代理的预设。它会识别会干扰工具调用的强格式约束（强制思维链、输出结构等），改写成弱引导；把只在最终产物出现的指令限定到提交阶段；禁用编排器主流程已经重复注入的占位符（角色卡、人设、世界书）。聊天历史、越狱、文风、NSFW 和 RP 语态条目保持启用。
- **仅保留破限**：用于下游是工具型模型调用的预设，例如记忆图整理或其他插件。它保留越狱指令，禁用塑造 RP 叙事文本的条目（文风、角色语态、输出格式、叙事元规则）。条目本身留在预设里，可以随时重新启用。

模式在会话创建时确定。切换模式会弹出确认并新开一个会话，旧会话留在历史里。

在 **编排器适配** 和 **仅保留破限** 模式下，助手默认建议派生一个新预设（原名加 `-orchestrator` / `-jailbreak` 后缀），改动作用在新预设上，原预设保持不动。要改原预设，直接告诉助手。

## 在编排器适配模式下抽取 Skills

适配预设时，助手会扫一遍写作和输出格式规则，把适合给编排器所有子代理共用的部分做成提案：

1. 在当前预设的作用域下创建 skill，正文逐字照搬。
2. 从原提示词条目里删掉这段文字。
3. 在原位置留一行指针，例如 `参考 skill <skill-name>`，让条目还能指向这条规则。

提案和其余适配改动一起以 diff 卡片返回，逐条批准或拒绝。

只做局部小改（「这句收紧一下」「温度调到 1.1」「修一下这个错字」）、你明确说过别动 skill、以及本次会话里已经拒过的候选，都不会触发抽取。

你也可以点名抽取某段文字、复用已安装的 Skill，或者让它查看、改名、移动、删除某个 Skill。把 Skill 挂到某个子代理的可见列表在[编排器迭代工作台](/zh-CN/features/orchestrator/iteration-studio#用工作台编写-skill)中完成。

派生出 `-orchestrator` 预设后，工具栏会出现 **将 Skills 打包到此预设**。点开后进入 [Skill 管理](/zh-CN/features/skills/management) 的多选模式，选好 skill，再点 **把所选打包进预设……**。其他用户导入这份预设时会看到标准的嵌入抽取对话框，Skill 自动安装到他们的 `preset` 作用域。

::: tip 改过模式提示词
如果在 *迭代系统提示词（高级）* 里改过 **模式追加 —— 编排器适配**，你的文本会覆盖默认值。点 **重置为默认** 恢复内置版本。
:::
