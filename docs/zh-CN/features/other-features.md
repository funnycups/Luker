# 其他功能

## 世界书激活链路追踪

记录世界书条目从匹配到注入的链路，用来调试复杂的世界书配置。详见[世界书激活链路追踪](/zh-CN/features/world-info-trace)。

## 角色卡绑定人设

角色卡可以携带推荐人设并随卡导出。打开角色卡时，还没选人设就切到推荐人设；当前人设与推荐不一致时，先问你是否切换。详见[角色卡绑定预设与人设](/zh-CN/improvements/card-bound-presets)。

## 聊天工具面板

聊天界面里的工具面板，放着当前聊天的常用工具，对话时随时可用。

## 弹窗更新器

有新版本时，通过弹窗完成更新流程。它识别 Docker 部署，给出对应的更新步骤。

## 图像生成增强

通过 WebSocket 连接 ComfyUI，替代 HTTP 轮询；连接断开后自动重连。

## 插件注册正则

插件可以把正则规则注册进正则处理流程。详见[插件注册正则](/zh-CN/features/regex-provider)。

## 引导配置导入

首次设置时可以导入已有的应用设置和扩展配置，用于从其他实例迁移，或在新设备上恢复环境。
