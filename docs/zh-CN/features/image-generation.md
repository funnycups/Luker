# 图像生成与 AI 插图

Luker 内置的**图像生成**扩展统一了本地与云端生图后端、跨后端角色与画风参考图协议、双 agent 协作的**AI 插图**、全局共享的**角色库**，以及嵌入[工作台](/zh-CN/features/workbench)的交互式**画室**。

## 连接配置与生图预设

打开**扩展 → 图像生成**，选择**生图预设**与**源**。

- **绑定连接配置** —— **Google AI**、**OpenAI**、**OpenRouter**、**xAI (Grok)**、**Z.AI**、**NanoGPT**、**Chutes**、**Electron Hub**、**AI/ML API**、**Pollinations** 与 **OpenAI 兼容多模态对话生图**支持在**连接配置**下拉框中直接复用已有连接配置的接口地址、密钥与代理设置，也支持在面板内点击 **API 密钥**单独配置凭据。
- **失效即时报错** —— 所绑定的**连接配置**被删除后，发起生图会直接提示配置缺失错误，重新选择有效连接配置或改用独立密钥后即可恢复。
- **生图预设切换** —— **生图预设**完整保存生图源、模型、分辨率、采样参数、连接配置绑定以及画风参考图列表，支持一键切换。

## 参考图与画风参考

在**画风与氛围参考**区域点击**添加画风参考**，可将本地参考图片或 `.naiv4vibe` 文件绑定至当前**生图预设**。来自全局**角色库**的角色参考图与**基于此图修改**传入的底图会按当前后端自动路由：

| 生图后端 | 支持的参考图能力 |
| --- | --- |
| **Google AI** Gemini 生图模型 | 角色参考图、画风参考图、基于底图修改与动态画幅比例 |
| **OpenAI 兼容多模态对话生图**与 **OpenRouter** | 多模态角色参考图、画风参考图与底图修改输入 |
| **OpenAI** 与 **xAI (Grok)** | 在支持图像编辑的模型上通过多部分表单携带参考图生成与修改 |
| **NovelAI Diffusion** | V4.5 角色参考图与还原度控制、V3 与 V4 氛围转移及 `.naiv4vibe` 导入、V4 多角色分区提示词与坐标控制 |
| **ComfyUI** | 自动上传参考图并填充工作流中的 `%ref_image%` 与 `%ref_image_1%` 编号占位符，未传入参考图时自动裁剪空置参考节点支路 |
| **Stable Diffusion Web UI** 与 **SD.Next** | 通过图生图接口执行基于底图的局部或整体修改 |

## AI 插图

在**扩展 → 图像生成**底部展开 **AI 插图**，勾选**启用 AI 插图**。开启**自动为助手消息配图**后会在收到新回复时自动配图；也可在魔杖菜单点击**为最后一条消息生成插图**，或在单条消息菜单点击 **AI 插图**手动触发。

### 角色一致性与自动探索

为消息生成插图时，插图 agent 按角色类型协同处理外貌设定与参考图：

- **生图模型已知的经典同人角色** —— 当生图模型本身已准确认识该同人角色时，插图 agent 直接生成提示词并执行图像生成，跳过联网探索与搜图步骤。
- **尚未归档的生图陌生同人角色** —— 当场景出现生图模型不熟悉、且尚未建档的公开作品角色时，插图 agent 调用**角色视觉探索 Agent** 读取角色卡、关联世界书、公开角色资料库及[搜索插件](/zh-CN/features/search-tools)图片检索结果，将核实后的外貌标签、服装方案与参考图写入全局**角色库**。若探索模型具备多模态识图能力，可在**角色视觉探索 Agent** 抽屉中勾选**开启多模态视觉审阅下载的候选参考图**。
- **已归档角色** —— 命中全局**角色库**的角色直接复用已保存的核心外貌标签、服装方案与本地参考图。

正文中的内联插图标签在发送给主对话模型前会自动剥离，插件上下文读取历史楼层时则保留插图描述以维持前后画面连贯。

### 正文插图交互操作

点击消息正文中的任意插图可打开操作栏：

- **重新生成**或**编辑提示词** —— 基于当前锚点生成新图片并记入版本历史树。
- **基于此图修改** —— 输入**修改指令**，在支持底图修改的后端上将当前插图作为底图执行局部或整体调整。
- **锁定插图**与**取消锁定** —— 锁定单张插图后，对整条消息重新执行配图时保留已锁定插图的位置与记录。
- **切换至此版本** —— 在历史版本列表中一键将正文展示的插图切换至任意历史版本。

## 工作台图像生成工作区

在**扩展 → 图像生成**中点击**在工作台中打开**、在魔杖菜单点击**图像迭代工作台**，或在[工作台](/zh-CN/features/workbench)左侧栏切换至**图像生成**：

- **画室** —— 多轮对话式生图工作区，支持切换**自由画图**与**角色定妆**模式，提供**从此处分支会话**、会话画廊单图重新生成以及跨重启会话状态持久化。
- **角色库** —— 集中管理全局共享的角色外貌标签、服装方案、角色卡立绘差分绑定与本地参考图。顶部提供当次建档方式切换：
  - **同人探索** —— 输入角色名或线索并点击**开始探索建档**，自动检索公开作品设定与参考图归档入库。
  - **原创定妆** —— 点击**前往画室定妆**进入**画室**的**角色定妆**模式，由 AI 读取当前角色卡与绑定世界书设定，经多轮生图微调立绘后生成待审阅卡片；点击**应用至全局角色库**即可将选定立绘固化为全局角色参考图，并支持在工作台**改动记录**中一键撤销。
- **运行轨迹** —— 实时查看插图与角色探索的轮次轨迹、提示词与错误报告，支持**导出运行 JSON** 或点击 **AI 诊断**跳转至工作台 **AI 迭代**定位问题。

## 使用 AI 迭代 ComfyUI 工作流

当生图**源**设为 **ComfyUI** 时，点击 **ComfyUI 工作流**下拉框旁的**使用 AI 迭代工作流**，或在[工作台](/zh-CN/features/workbench)的 **AI 迭代**中选择**图像生成**：

- **实时查询已安装节点** —— 迭代 AI 按需检索当前连接的 ComfyUI 实例，核实本机已安装的自定义节点类型、必填与可选输入参数、可用模型与 LoRA 文件名以及输出槽位序号。
- **自动接入模板节点与调优拓扑** —— 可直接要求 AI 基于现有 API 格式工作流克隆新副本、插入 `%lora_name%` 动态串联模板节点、依据本机节点接入 `%ref_image%` 或 `%ref_image_1%` 参考图槽位，以及调整采样、放大参数与自定义占位符映射。
- **草稿测试生成与差异撤销** —— AI 可直接将工作流草稿发送至 ComfyUI 执行测试生成并在预览栏展示结果，节点报错时自动根据异常信息修正连线。所有节点级变更均汇入**改动清单**供逐项勾选应用，应用后可在**改动记录**中一键撤销。
