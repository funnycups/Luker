# 图像生成与 AI 插图

**图像生成**扩展统一了本地与云端生图后端、跨后端角色与画风参考图协议、双 agent 协作的 **AI 插图**、全局共享的**角色库**，以及嵌入[工作台](/zh-CN/features/workbench)的交互式**画室**。

## 连接配置与生图预设

打开**扩展 → 图像生成**，选择**生图预设**与**源**。

- **绑定连接配置** —— **Google AI**、**OpenAI**、**OpenRouter**、**xAI (Grok)**、**Z.AI**、**NanoGPT**、**Chutes**、**Electron Hub**、**AI/ML API**、**Pollinations** 与 **OpenAI 兼容多模态对话生图**支持在**连接配置**下拉框中直接复用已有连接配置的接口地址、密钥与代理设置，也支持在面板内点击 **API 密钥**单独配置凭据。
- **失效即时报错** —— 所绑定的**连接配置**被删除后，发起生图会直接提示配置缺失错误，重新选择有效连接配置或改用独立密钥后即可恢复。
- **生图预设切换** —— **生图预设**完整保存生图源、模型、分辨率、采样参数、连接配置绑定、参考与图生图开关以及画风参考图列表，支持一键切换。

## 参考与图生图

在**参考与图生图**区域，每个**生图预设**可独立控制以下参考图与底图编辑开关：

- **启用角色参考** —— 控制 **AI 插图**与**画室**是否接入全局**角色库**。开启后可通过**传递方式**指定角色资料供给形式：
  - **仅文字说明** —— 将角色库中保存的外貌标签、文字说明与服装设定融入提示词，不附带角色参考图。
  - **仅参考图** —— 附带角色库中保存的参考图，不在提示词中展开角色库外貌描述。
  - **文字说明与参考图** —— 同时结合角色库外貌与服装设定编写提示词并附带角色参考图。
- **允许图生图编辑（基于已有图片修改）** —— 控制聊天正文插图的**基于此图修改**按钮与**画室**的**设为底图**操作是否开启。
- **启用画风与氛围参考** —— 控制发起图像生成时是否合并发送当前预设保存的画风参考图片或 `.naiv4vibe` 文件。点击**添加画风参考**上传文件时会自动开启该开关；关闭开关后会保留已上传的画风参考列表并置灰展示，生成期间不发送。

开关下方的实时冲突提示条会在已开启的开关与当前所选**源**、**模型**或 **ComfyUI 工作流**不兼容时立即显示具体原因，例如工作流缺少 `%ref_image%` 参考图节点、所选后端或模型不支持图片输入、画风参考超出 NovelAI 数量上限，或画风参考占满全部共享槽位。在正文插图点击**重新生成**或**修改提示词**、或在**画室**画廊点击**重新生成**时，若旧记录附带了当前预设已关闭类型的参考图，系统会跳过已关闭类型并弹出提示。

通过 `/imagine` 斜杠命令或开发者接口显式传入参考图时，校验以当前后端与工作流的底层协议支持为准：

| 生图后端 | 支持的参考图协议能力 |
| --- | --- |
| **Google AI** Gemini 生图模型 | 角色参考图、画风参考图、基于底图修改与动态画幅比例 |
| **OpenAI 兼容多模态对话生图**与 **OpenRouter** | 多模态角色参考图、画风参考图与底图修改输入 |
| **OpenAI** 与 **xAI (Grok)** | 在支持图像编辑的模型上通过多部分表单携带参考图生成与修改 |
| **NovelAI Diffusion** | V4.5 角色参考图与还原度控制、V3 与 V4 氛围转移及 `.naiv4vibe` 导入、V4 多角色分区提示词与坐标控制 |
| **ComfyUI** | 自动上传参考图并填充工作流中的 `%ref_image%` 与 `%ref_image_1%` 编号占位符，未传入参考图时自动裁剪空置参考节点支路 |
| **Stable Diffusion Web UI** 与 **SD.Next** | 通过图生图接口执行基于底图的局部或整体修改 |

## AI 插图

在**扩展 → 图像生成**底部展开 **AI 插图**，勾选**启用 AI 插图**。开启**自动为助手消息配图**后会在收到新回复时自动配图；也可在魔杖菜单点击**为最后一条消息生成插图**，或在单条消息菜单点击 **AI 插图**手动触发。

### 角色一致性与自动探索

开启**启用角色参考**后，插图 agent 按角色熟悉程度与建档状态协同处理角色外貌与参考图：

- **生图模型已知的经典同人角色** —— 当生图模型本身已准确认识该同人角色时，插图 agent 直接生成提示词并执行图像生成，跳过联网探索与搜图步骤。
- **尚未归档的生图陌生同人角色** —— 当场景出现生图模型不熟悉且尚未建档的公开作品角色时，插图 agent 调用**角色建档 Agent** 读取角色卡、关联世界书、公开角色资料库及[搜索插件](/zh-CN/features/search-tools)图片检索结果，将核实后的外貌标签、服装方案与参考图写入全局**角色库**。若探索模型具备多模态识图能力，可在**角色建档 Agent** 抽屉中勾选**开启多模态视觉审阅下载的候选参考图**。
- **已归档角色** —— 命中全局**角色库**的角色会按当前预设选择的**传递方式**供给外貌与服装设定或本地参考图。

关闭**启用角色参考**时，**AI 插图**直接依据当前对话、角色卡与世界书内容生成提示词，不读取或检索全局**角色库**。

正文中的内联插图标签在发送给主对话模型前会自动剥离，插件上下文读取历史楼层时则保留插图描述以维持前后画面连贯。

### 正文插图交互操作

点击消息正文中的任意插图可打开操作栏：

- **重新生成**或**修改提示词** —— 基于当前锚点生成新图片并记入版本历史树。
- **基于此图修改** —— 开启**允许图生图编辑（基于已有图片修改）**后显示，输入**修改指令**可在支持底图修改的后端上将当前插图作为底图执行局部或整体调整。
- **锁定插图**与**取消锁定** —— 锁定单张插图后，对整条消息重新执行配图时保留已锁定插图的位置与记录。
- **切换至此版本** —— 在历史版本列表中一键将正文展示的插图切换至任意历史版本。

## 工作台图像生成工作区

在**扩展 → 图像生成**中点击**在工作台中打开**、在魔杖菜单点击**画室**，或在[工作台](/zh-CN/features/workbench)左侧栏切换至**图像生成**：

- **画室** —— 对话式自由生图与基于底图修改的工作区，支持开启**多模态审阅**、**从这里分支**、会话画廊单图重新生成、在开启图生图编辑时可用的**设为底图**，以及跨重启保存会话历史。
- **角色库** —— 集中管理全局共享的角色外貌标签、服装方案与本地参考图：
  - **AI 建档**与**AI 调整档案** —— 打开对话弹窗，通过交互对话创建或微调角色档案。顶栏提供**读取设定来源**下拉框，默认保持**不读取角色卡**，按需选择指定角色卡或当前用户人设。建档 AI 可检索公开图源、下载候选参考图、调用图像生成制作候选立绘，并向右侧**可编辑角色档案草稿**提交局部变更，遇手动修改冲突时展示选项供确认。点击**确认保存至角色库**后将保留的候选图固化为正式参考图并记入工作台**改动记录**支持撤销；点击**取消**则清理本次会话的临时图片。
  - **手动编辑** —— 点击**新建角色档案**直接填写名称、标签、描述、服装并上传本地参考图。
- **运行轨迹** —— 实时查看插图与角色探索的轮次轨迹、提示词与错误报告，支持**导出运行 JSON** 或点击 **AI 诊断**跳转至工作台 **AI 迭代**定位问题。

## 使用 AI 迭代 ComfyUI 工作流

当生图**源**设为 **ComfyUI** 时，点击 **ComfyUI 工作流**下拉框旁的**使用 AI 迭代工作流**，或在[工作台](/zh-CN/features/workbench)的 **AI 迭代**中选择**图像生成**：

- **实时查询已安装节点** —— 迭代 AI 按需检索当前连接的 ComfyUI 实例，核实本机已安装的自定义节点类型、必填与可选输入参数、可用模型与 LoRA 文件名以及输出槽位序号。
- **自动接入模板节点与调优拓扑** —— 可直接要求 AI 基于现有 API 格式工作流克隆新副本、插入 `%lora_name%` 动态串联模板节点、依据本机节点接入 `%ref_image%` 或 `%ref_image_1%` 参考图槽位，以及调整采样、放大参数与自定义占位符映射。
- **草稿测试生成与差异撤销** —— AI 可直接将工作流草稿发送至 ComfyUI 执行测试生成并在预览栏展示结果，节点报错时自动根据异常信息修正连线。所有节点级变更均汇入**改动清单**供逐项勾选应用，应用后可在**改动记录**中一键撤销。

## 在工作台中模拟提示词

在[工作台](/zh-CN/features/workbench)的 **AI 迭代**中选择**图像生成**，可在应用改动前直接测试尚未保存的插图与角色建档提示词：

- **插图与角色建档模拟** —— 迭代 AI 可基于当前草稿在隔离沙箱中执行正文插图、后台角色探索或对话式角色建档，并打开**模拟回顾**弹窗展示生成结果、候选图片、完整提示词与工具调用轨迹。
- **批注与重新生成闭环** —— 开启**批注模式**可在输出与轨迹文本上划词批注，点击**重新生成**可基于原始输入快照发起全新尝试；点击**提交并继续**后将审阅文本与批注发回迭代 AI 供后续修改，关闭模拟回顾时自动清理临时图片。
