# 编排 AI 迭代

**工作台 → AI 迭代 → 编排**是定制多 Agent 编排方案的主要入口。无需手写阶段图、调度提示词或自定义工具代码，只需用自然语言描述目标，在**改动清单**中逐条审阅差异并应用。Spec、Agenda、Loop 和 Director 模式共用同一个工作区。

::: tip 优先用 AI 迭代
先用自然语言让 AI 搭建或调整方案；需要精细微调时，随时在**工作台 → 编排**（**流程** / **准备阶段**）中直接修改。
:::

## 打开入口

1. 打开**工作台**（快捷键 `Alt+W`、魔杖菜单 → **工作台**或右下角入口）→ **AI 迭代** → **编排**。
2. 或在**工作台 → 编排**顶栏点击 **AI** 按钮（也可在**准备阶段**点 AI 按钮）。
3. 排查单次运行或性能瓶颈时，在**运行面板**点击**结果不满意？AI 诊断**，或在**编排 → 运行**点击**诊断这次运行**、在**统计**中点击**根据统计诊断**。

![迭代视图](/images/orchestrator/orch-iteration-studio.png)

在顶部选择编辑范围：**全局**修改所有角色共用的方案，**角色单独的**修改当前角色卡的专属方案（Agenda 模式下还可编辑当前聊天专用方案）。

## 描述你的需求

在输入框中写一句具体要求：

> 例：*「我希望 AI 在每次回复前先回顾近期重要事件、保持人设一致性，并且不要轻易破规出戏。」*

![输入框带示例](/images/orchestrator/orch-iter-input.png)

发送后，AI 会读取当前编排方案，按需查阅世界书或技能，并通过工具调用生成改动。只要这一轮调用了工具，AI 就会自动继续下一轮，直到给出纯文本总结时停止。

## 审阅与应用

AI 提出的修改会进入**改动清单**，支持查看逐行差异对比。勾选需要保留的改动并点击**应用所选**，或点击**全部放弃**。开启**自动应用**后会即时写入，每条已应用的改动均可在**工作台 → 改动记录**中单独撤销。

![待审批的改动](/images/orchestrator/orch-iter-diff-inline.png)

![并排差异详情](/images/orchestrator/orch-iter-diff-side.png)

## 主要能力

- **全模式编辑**：增删或调整 Spec 的阶段与节点；调整 Agenda 的调度员提示词与助手池；重写 Loop 的系统提示词、工具开关与上限；修改 Director 的主笔与子助手团队。
- **运行与统计诊断**：直接读取失败或耗时过长的运行详情，定位问题节点并给出或应用修改。
- **模拟测试**：基于当前聊天上下文与世界书激活状态试跑一次编排（不写入真实聊天），并在模拟回顾弹窗中标注问题片段做根因修复。
- **角色卡世界书协同**：在角色作用域下检查绑定世界书中干扰工具调用的格式强制条目，并以待审改动的形式提出温和改写。
- **编写技能与自定义工具**：起草并挂载 `SKILL.md` 技能，或在沙箱试运行后创建自定义工具。
- **会话保存**：不同目标与作用域的对话各自独立保存，随时可回来继续调整。

## 典型迭代过程（Spec 示例）

> **你：** *「AI 不要轻易出戏。」*
> **AI：**「在约束阶段加一个检查节点，拦截角色偏离和元评论，并启用文风检查。」你勾选并应用改动。
>
> **你：** *「让它读世界书，这样它知道世界规则。」*
> **AI：**「在约束阶段加一个世界书读取节点，让检查节点看到当前激活的世界规则。」你勾选并应用改动。
>
> **你：** *「模拟一个明显出戏的输入，看检查节点真能拦住吗？」*
> **AI：** 执行一次模拟运行，并返回检查节点的判定输出。

## 角色卡世界书冲突处理

在角色卡作用域下调整编排时，AI 会对照该角色卡绑定的世界书，区分两类格式规则：

- **过程强制类** —— 强制规定模型每轮必须按固定模板思考或输出前缀，会干扰工具调用流程。AI 会剥离强制格式，保留作者原本关心的人设、话题或场景意图。
- **最终输出形态类** —— 规定最终回复的格式或标签（如结尾状态栏、特定排版），AI 会明确限定其只作用于最终提交的正文，避免影响中间规划与工具调用阶段。

所有世界书调整同样进入**改动清单**，由你勾选确认后才会写入。全局作用域不会修改世界书。

## 用 AI 迭代编写 Skill {#用工作台编写-skill}

直接描述需要的写作规范以及希望谁看到它：

> 帮我写一条 skill，让导演避开翻译腔。别让角色对话出现「当 X 的时候」这种句式，不要用「——」破折号分隔短句，「是吗？」改成「是吧？」这种更本地化的语气词。让导演模式下所有 agent 都看到。

AI 会起草 `SKILL.md`、生成安装提案，并在同一份改动清单里把该技能添加到对应助手的可见列表。

![工作台执行完成并安装](/images/skills/iter-studio-05-after-llm-round.png)

完整步骤见[《用 skills 调教 RP 输出》](/zh-CN/recipes/rp-skills-walkthrough)。
