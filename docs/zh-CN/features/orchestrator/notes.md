# 笔记

笔记让 Agent 记录它打算在以后兑现的剧情线索：已经埋下的伏笔、角色做出的承诺、提前写好的章节大纲、推理剧情里在调查之前就定好的真相。每条笔记属于当前聊天。

## 与记忆图的区别

| | 记忆图 | 笔记 |
| --- | --- | --- |
| 回答什么 | 已经发生了什么：角色、地点、事件的客观记录 | Agent 接下来想让什么发生：已埋下但尚未兑现的线索 |
| 谁来写 | 自动提取，用户也可以整理 | Agent 在运行中自行开启和关闭 |
| 何时使用 | 需要回忆既有事实 | 需要记住未来的承诺与伏笔 |

## 谁来维护

Agent 在运行中开启和关闭笔记。你可以在笔记面板查看、编辑、关闭或永久删除，但主要作者是 Agent。

想加入自己的剧情方向，用世界书条目或记忆图的持久注入节点。笔记是 Agent 自己的工作台账，不适合当作玩家侧提示词。

## 维护原则

笔记是真正的承诺，不是回合日记。未结清的笔记会一直占用 Agent 的上下文；被琐事污染的列表会分散它的注意力。

开启要克制，关闭要积极。Director 的默认流程在起草前挑选本回合该兑现的笔记，起草后只关闭有明确文本证据的条目；没有证据时不做任何操作。

## 笔记面板

面板位于编排器扩展中，作用域是当前聊天，分为两个标签页：

- **未结清**：当前活跃的线索，每行可以关闭、编辑或删除。
- **已关闭**：归档记录，保留关闭原因。

| 操作 | 效果 |
| --- | --- |
| 关闭 | 填写关闭原因，条目移入已关闭。 |
| 编辑 | 修改文本，状态和编号保持不变。 |
| 永久删除 | 从存储中删除，需要二次确认。与关闭不同，删除不会留下档案。 |

Agent 开启或关闭笔记时，面板会实时刷新；你在面板上的修改也会影响 Agent 下一回合看到的内容。

## 常见问题

### 可以手动开启笔记，给 Agent 加剧情提示吗

不推荐。需要设定剧情方向时，用世界书条目或记忆图的持久注入节点。笔记留给 Agent 自己管理。

### 笔记跨聊天共享吗

不共享。每个聊天有独立的笔记，切换聊天后看到的是该聊天自己的列表。
