# 预设分组

预设数量较多时，扁平下拉列表难以查找。预设分组将预设归入命名分组，在下拉中以分组标题与成员展示。

![预设分组](/images/presets/preset-groups.png)

## 管理分组

在预设下拉里右键：

- **新建预设分组**：输入组名，选中的预设直接进组。
- **移入分组**：把当前预设挪到某个分组。
- **从预设分组移出**：回到未分组状态。

分组标题上有新建子分组、重命名、删除三个按钮。删除分组后，成员回到未分组状态。分组可以嵌套，子分组缩进在父分组下面。

分组按 API 类型分开保存。切换 API 类型时，下拉显示该类型的分组。

预设改名后，分组里的名字跟着变；预设删除后，自动从分组移除。

## 显示

点分组标题折叠或展开分组。未分组预设留在列表顶层。
