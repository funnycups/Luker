# 从零写一个 CardApp

CardApp Studio 根据一段自然语言描述构建完整角色卡：你说明想要的效果，Studio 逐项提案，确认后写入。两个示例都产出一张可直接对话的角色卡，涵盖记忆图、多 Agent 编排、角色卡专用世界书，以及随对话更新的面板。

| 示例 | 题材 | 建立什么 | 适合 |
| --- | --- | --- | --- |
| [异世界生存日志](/zh-CN/features/card-editor/walkthrough/isekai) | 西式低魔异世界生存 RP | 记录日期、体力、饥饿与心情的顶部状态栏，附带世界书和可选场景插画 | 快速完成一个 CardApp |
| [维多利亚案宗](/zh-CN/features/card-editor/walkthrough/victorian) | 1888 伦敦侦探卡 | 记忆图节点类型、多 Agent 编排、角色卡专用世界书、由案件状态条目驱动的面板 | 了解记忆图与编排如何配合 |

两个示例采用相同流程：Studio 提案、你确认、Studio 写入，每项修改都会显示改动内容。维多利亚案宗还会用到记忆图与多 Agent 编排。
