# 记忆图

长对话里，上下文窗口会被截断，早期发生的事、关系变化和世界规则逐渐丢失，角色开始「失忆」。记忆图在后台把对话中的关键信息整理成记忆节点，在需要时召回并注入提示词，让角色在几百轮后仍能记得同一件事。

记忆图适合长篇角色扮演、连载剧情和需要稳定设定的世界。短对话或一次性场景不必开启。

## 工作原理

记忆图在后台做三件事。

**提取**：AI 回复后，记忆图检查本轮对话，把值得保留的信息构建为节点。默认覆盖四类内容：角色的身份、关系、目标与随身物品，地点的控制者与危险程度，发生过的重要事件，以及持续推进的主线。类型与字段可以按角色卡调整。

**召回**：你发送消息后，记忆图从已有节点中选出与当前场景相关的内容，注入提示词。默认由 LLM 判断相关性，也可以改用向量检索。

**压缩**：事件积累过多时，旧事件向上合并为更高层的总结，细节保留在图中，可以展开查看，也会在相关时再次被召回。

提取可以内置运行，也可以交给多 Agent 编排中的记忆整理 agent。

## 开始使用

1. 打开 **扩展 → 记忆**，启用记忆图。
2. 在同一面板选择召回与提取使用的 API 连接和聊天补全预设。预设下拉框旁的问号按钮说明该槽位需要什么类型的预设，并可以一键导入内置预设。记忆图不必与主对话共用模型，提取属于结构化整理，小模型即可胜任。
3. 正常聊天。经过若干轮对话后打开记忆面板查看结果。

面板有三个视图：图视图显示节点与关系，节点视图按类型列出内容，召回视图显示最近一次注入提示词的内容。

## 查看与修改记忆

节点视图可以直接编辑字段、标题和关系，改动保存在当前聊天中。

需要批量修正时，使用 AI 改图。入口有两处：

- 图查看器工具栏的机器人按钮
- 记忆面板 → **高级** → **AI 改图**

用自然语言说明问题，例如「Eileen 和 Elena 是同一个人，合并重复节点」「主角已经离开北境，更新地点状态」。工作台会读取当前记忆图，必要时查阅聊天记录和世界书，再把改动作为可审阅的卡片列出。批准后写入，拒绝则丢弃，已应用的改动可以回退。会话按聊天保存，关闭后再打开可继续。

首次使用前，在**高级**区域选择迭代 AI 的 API 连接与提示词预设。想替换内置指令，编辑**图修改提示词**。

## 让记忆图适配你的世界

默认类型覆盖常见角色扮演，奇幻、科幻、悬疑等题材通常需要自己的结构。在记忆面板的**高级**区域点**打开记忆图配置**，可以添加类型与字段。

例如：

- 魔法体系：名称、来源、限制
- 派系：名称、领袖、目标
- 案件线索：线索内容、指向对象、可信度

自定义类型随角色卡保存和导出。每种类型可以写提取指令，说明这类信息该怎么记录；也可以设置提取频率，让变化缓慢的类型隔若干轮更新一次。

也可以用自然语言让 AI 配置。打开 **高级** → **AI 配置记忆图**，描述想要的类型、字段或提取规则，工作台会列出可改项并逐项确认。

### 让规则始终留在提示词里

世界法则、角色不可违背的设定、叙事禁忌不该依赖召回。把对应类型设为**持久注入**后，这类节点每轮都会出现在提示词中。持久注入的节点不再进入召回池，避免重复占用上下文。

## 常见问题

### 记忆出现错误或重复

把问题描述给 AI 改图，由它合并重复节点、删除条目、修改字段与关系。

### 编辑或删除消息后，记忆会怎样

记忆图会随聊天历史回滚。编辑、删除消息或切换 swipe 时，记忆回到受影响消息之前的状态。

### 换设备或分享给他人

在记忆面板导出 JSON，再在目标聊天导入。导入时可以选择保留原楼层号、绑定到最新楼层或指定楼层。把长期对话的记忆导入一个空聊天，可以从第 0 楼继续使用既有的世界观与人物关系。

### 同一楼层重新生成会重复召回吗

不会。同一楼层的 swipe 与重新生成会复用上次召回结果，保持上下文一致，也避免重复调用。

## 配置

设置面板按用途分组：

- **提取**：启用、提取间隔、提取使用的模型。提取间隔设为 2 表示每两次 AI 回复提取一次，成本减半。
- **召回**：LLM 召回或 RAG 召回、召回数量、注入位置与深度。RAG 召回需要先配置嵌入档案；启用重排或查询改写可以提升效果，但会增加调用与延迟。
- **压缩**：自动压缩开关与压缩频率。事件较多时开启。
- **持久注入**：按节点类型设置。适合世界规则与角色核心设定。
- **高级**：AI 改图与 AI 配置使用的预设、导入导出、向量索引重建。

RAG 召回使用向量检索。启用前需要准备嵌入配置：在 API 连接配置面板的「嵌入」选项卡新建配置，选择嵌入模型与连接，然后回到记忆面板选中该配置并建立向量索引。索引完成后即可切换到 RAG 召回。
