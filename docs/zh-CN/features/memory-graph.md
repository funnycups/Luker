# 记忆图

长对话里，早期发生的事、关系变化和世界规则会逐渐落出上下文窗口。记忆图在后台把对话中的关键事实整理成带类型的记忆节点，并在需要时召回注入提示词，让角色在数百轮后依然保持连贯记忆。

记忆图适合长篇角色扮演、连载剧情和需要稳定设定的世界。

## 工作原理

记忆图在后台执行三项工作。

**提取**：AI 回复后，记忆图检查本轮对话，把值得保留的事实记录为节点。默认涵盖四类内容：角色（身份、关系、目标、关键物品）、地点（控制者、危险程度、状态）、事件与剧情线。类型与记录项可以全局或按角色卡定制。

**召回**：发送消息后，记忆图从已有节点中选出与当前场景相关的内容注入提示词。默认由模型判断相关性，也可以改用 RAG 向量召回。

**压缩**：事件积累较多时，旧事件自动合并为更高层的摘要。细节保留在图谱中，可以展开查看，也会在相关时再次被召回。

提取可以内置运行，也可以交给[多 Agent 编排](/zh-CN/features/orchestrator/)中的记忆整理助手。

## 开始使用

1. 打开**工作台**（魔杖菜单 → **工作台**、右下角入口、快捷键 `Alt+W`，或**扩展 → 记忆 → 在工作台中打开**），切换到左侧的**记忆图**标签页。
2. 在**记忆图 → 设置**中启用记忆图。
3. 选择提取和召回使用的连接配置与聊天补全预设；字段下方的操作可导入内置的 `plugin-only` 示例，或打开预设工作台从现有预设派生。提取属于结构化整理，小模型即可胜任。
4. 正常聊天，之后在工作台的**记忆图**标签页中查看生成结果。

## 工作台中的视图

工作台内的**记忆图**工作区提供五个视图：

- **图谱** —— 提供关系网与时间轴两种交互布局，支持节点与关系筛选、查看注入文本与节点详情栏。
- **时间线** —— 按摘要层级组织的故事时间线视图。
- **数据表** —— 按表列出节点，支持行内双击直接修改字段。
- **记忆结构** —— 编辑记忆类型、记录项、提取规则、常驻注入开关、内置模板、导入导出，以及**标签过滤**（在提取和召回读取 AI 回复前剥离思维链、状态栏等块）。
- **设置** —— 配置提取节奏与旧楼层隐藏快捷策略及实时动画预览、LLM 或 RAG 向量召回、自动合并压缩、token 统计追踪与迭代 AI 预设。

### 提取节奏与楼层隐藏

在**记忆图 → 设置**的**提取节奏与楼层隐藏**区域，可以统一选择更新频率与旧楼层隐藏策略。默认启用**均衡 · 推荐**策略：每 2 条 AI 回复提取一次，每次处理 2 条回复，创作时隐藏 5 楼外消息，保留最近 2 轮对话与最新用户输入原文，更早对话由记忆图提供。

需要调整节奏时，可直接切换**逐次更新**、**节省请求**、**长上下文**或**不隐藏楼层**，也可以点击**自定义…**在弹窗中手动调整数值与提取模式，并通过实时动画预览与断档提示确认生效逻辑。

## 查看与用 AI 修改

在**数据表**或**图谱**详情栏中可以直接修改字段、标题和关系，改动保存于当前聊天。

需要批量修正时，切换到**工作台 → AI 迭代**并选择：

- **记忆图** —— 用自然语言修复当前聊天的图谱，例如合并重复角色节点、修正过时的地点状态、补充节点间关系。
- **记忆结构** —— 用自然语言增删或调整记忆类型、记录项、提取规则与注入设置，支持全局或仅当前角色生效。

AI 提出的修改会进入**改动清单**展示前后差异，勾选后应用，并在**改动记录**中支持逐步撤销。

![使用 AI 迭代修复记忆图节点](/images/memory-graph/memory-ai-revise-proposal.png)

## 让记忆结构适配你的世界

在**记忆图 → 记忆结构**或 **AI 迭代 → 记忆结构**中，可以按题材添加自定义类型和记录项（例如魔法体系、势力、案件线索），或直接套用内置模板。

![记忆结构编辑器](/images/memory-graph/memory-schema-editor.png)

自定义结构可以设为所有角色共用，也可以仅对当前角色卡生效并随角色卡导出。每种类型都可以配置专属的提取说明与提取间隔。

### 常驻注入

世界法则、核心角色设定和重要主线需要每轮都出现在提示词中。为对应类型开启**一直让 AI 看到**后，其节点会随每轮回复常驻注入。设置常驻注入最大回溯楼层数后，更早的节点会退回按需召回候选池。

## 常见问题

### 记忆出现错误或重复

在**工作台 → AI 迭代 → 记忆图**中用自然语言描述问题，由 AI 合并重复节点、删除条目或调整关系。

### 编辑或删除消息后，记忆会怎样

记忆图随聊天历史同步回退。编辑、删除消息或切换分支时，记忆自动回到受影响消息之前的状态。

### 换设备或分享给他人

在**记忆图 → 设置**中导出 JSON，再在目标聊天导入。导入时可选择保留原楼层号、绑定到最新楼层或绑定到指定楼层。

### 同一楼层重新生成会重复召回吗

同一楼层的分支切换与重新生成会复用上一次召回结果，保持上下文一致并避免重复调用模型。

## RAG 向量召回

RAG 召回使用向量检索。先在 API 连接面板的「嵌入」选项卡创建嵌入配置并选择模型与连接，再回到**记忆图 → 设置**选中该配置并构建向量索引，随后即可切换到 RAG 召回。
