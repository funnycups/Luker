# 世界书激活链路追踪

世界书激活链路追踪是 Luker 引入的调试功能，帮助你理解世界书条目为什么被激活（或没有被激活）。

## 解决的问题

当世界书配置变得复杂时（大量条目、多层关键词、不同的扫描深度），用户经常遇到这样的困惑：

- 为什么某个条目没有被激活？
- 是哪个关键词触发了这个条目？
- 条目是在哪条消息中被匹配到的？
- 扫描深度设置是否合理？

激活链路追踪记录了每个条目从匹配到注入的完整过程，让这些问题一目了然。

## 追踪信息

对于每个被激活的世界书条目，追踪记录包含：

- **触发关键词**：哪个关键词（或关键词组合）触发了激活
- **匹配位置**：在哪条消息中匹配到了关键词
- **扫描深度**：当前的扫描深度设置
- **激活方式**：关键词匹配、constant（始终激活）、概率激活等
- **注入位置**：条目最终被注入到提示词的哪个位置

## 使用方式

在世界书面板中查看激活链路信息。当 AI 生成回复后，你可以检查哪些条目被激活了、为什么被激活，从而优化世界书的关键词和扫描深度配置。
