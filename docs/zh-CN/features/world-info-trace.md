# 世界书激活链路追踪

记录世界书条目从匹配到注入的过程，用来查条目为什么被激活，或者为什么没被激活。

## 记录什么

- **触发关键词** —— 触发激活的关键词或关键词组合。
- **匹配位置** —— 匹配到关键词的消息。
- **扫描深度** —— 当时生效的扫描深度。
- **激活方式** —— 关键词匹配、常驻、概率激活等。
- **注入位置** —— 条目最终进入提示词的位置。

## 查看

世界书编辑器中，每个条目右上角有一个追踪图标，点击后显示该条目最近一次扫描的过程：

![世界书激活追踪弹窗](/images/world-info-trace/wi-trace-popup.png)

弹窗顶部是条目的范围、最近激活时间和原因。下面按时间倒序列出扫描记录，激活的标红，未激活的标灰。据此调整关键词或扫描深度。
