# 日志系统

Luker 记录服务端与浏览器端的日志，在**用户设置 → 日志**中查看。

## 后端日志

服务启动后，Luker 收集服务端的控制台输出，保存在固定大小的内存缓冲区中，写满后丢弃最旧的条目。每条记录带时间戳与级别。

在日志管理器中把来源切到**后端**，即可按时间或条数筛选、搜索、复制与清空。服务端日志对管理员可见。

缓冲区位于内存，服务重启后清空。需要长期保留时，把控制台输出重定向到文件。

## 前端日志

浏览器端同样收集控制台输出，未处理的错误与 Promise 拒绝也会记录。

默认只有 `error` 级别输出到浏览器控制台。在**诊断**菜单启用**前端调试日志**后，所有级别都会输出。该开关控制浏览器控制台的输出范围，日志管理器始终记录所有级别。

## 导出

在**诊断**菜单选择**导出调试日志**，下载包含前端日志、性能标记、设备与视口信息、服务端日志和请求检查器记录的 JSON 文件。报告问题时附带该文件。

::: warning
日志和请求检查器记录可能包含 API 密钥等敏感内容。分享前检查。
:::

## 常见排查

- **API 连接失败** —— 后端日志中有错误信息；检查地址和密钥。
- **生成中断** —— 前端日志，或[请求检查器](/zh-CN/improvements/request-inspector)中的请求生命周期。
- **扩展报错** —— 前端日志记录扩展运行时的错误。
