# 角色卡编辑助手

角色卡编辑助手是 Luker 内置的 AI 辅助编辑工具，让你可以用自然语言指令来修改角色卡设定和世界书条目。每次 AI 做出的修改都会以差异对比的形式展示，由你逐项审批后才会生效——确保角色卡始终在你的掌控之中。

## 两种编辑方式

### 普通编辑弹窗

在角色卡编辑界面中，你可以直接编辑角色卡的各个字段（描述、性格、场景设定等）。这是最基础的编辑方式，适合快速的手动修改。

你可以编辑的字段包括：

- **角色名称** — 角色的显示名称
- **角色描述** — 角色的外貌、背景、身份等详细描述
- **性格摘要** — 角色性格特征的简要概括
- **场景设定** — 故事发生的场景和背景
- **首条消息** — 角色的开场白
- **示例对话** — 展示角色说话风格的示例
- **系统提示词** — 角色卡级别的系统指令
- **越权提示词（Jailbreak）** — 角色卡级别的越权指令
- **创作者备注** — 给其他用户的使用说明
- **备选首条消息** — 多个可选的开场白

### Studio 面板

Studio 是角色卡编辑助手的核心功能——一个独立于主聊天区域的 AI 对话面板，专门用于角色卡编辑。你可以像和 AI 聊天一样，用自然语言描述你想要的修改，AI 会理解你的意图并自动执行。

**典型使用流程：**

1. 在角色卡编辑界面打开 Studio 面板
2. 用自然语言描述你想要的修改，例如：
   - 「把角色的性格改得更内向一些」
   - 「添加一个关于角色家乡的世界书条目」
   - 「把首条消息改成在雨天的咖啡馆相遇」
   - 「给角色增加一个宠物猫的设定」
3. AI 解析你的指令并执行修改
4. 系统展示修改前后的差异对比，等待你审批
5. 确认后修改生效

**会话管理：**

- Studio 支持多个编辑会话，你可以创建、切换和删除会话
- 每个角色最多保留 **24** 个会话，超出后最早的会话将被自动清理
- 会话内容会持久化保存，关闭面板后重新打开不会丢失

## Studio 的编辑能力

Studio AI 可以通过以下 7 种操作来编辑角色卡和世界书：

| 操作 | 说明 |
|------|------|
| 修改角色设定 | 更新角色卡的文本字段：名称、描述、性格、场景、首条消息、示例对话、系统提示词、越权提示词、创作者备注、备选首条消息 |
| 设置主世界书 | 设置或清除角色卡绑定的主世界书，可自动创建不存在的世界书 |
| 创建/更新世界书条目 | 创建新的世界书条目或更新已有条目的内容、关键词、注入位置等属性 |
| 删除世界书条目 | 删除指定的世界书条目 |
| 列出世界书条目 | 查看当前角色卡关联世界书的所有条目概览 |
| 查询世界书条目 | 按条件查询世界书条目，获取符合条件的条目详情 |
| 模拟提示词组装 | 模拟当前角色卡配置下的提示词组装结果，帮助 AI 理解各字段在最终提示词中的实际效果 |

::: tip 模拟提示词组装
「模拟提示词组装」是一个特别实用的功能。AI 可以通过它查看角色卡各字段在最终发送给 LLM 的提示词中的实际位置和效果，从而做出更精准的编辑建议。例如，AI 可以发现某个设定被放在了不太理想的位置，并建议调整。
:::

## 修改审批

每次 AI 执行修改后，系统会生成修改前后的行级差异对比视图，清晰展示哪些内容被添加、删除或修改。

- **逐条审批**：你可以逐一审查每个修改操作
- **批准或拒绝**：对每个修改独立决定是否接受
- 拒绝的修改会被撤销，不会影响角色卡数据

这个机制确保 AI 的所有修改都在你的控制之下，不会出现意外的数据变更。

## 操作历史与回滚

每次成功执行的操作都会被记录到操作日志中，包含以下信息：

- 唯一操作 ID
- 操作类型（如修改角色字段、创建/更新/删除世界书条目、设置主世界书等）
- 完整的操作参数
- 来源标记（AI 工具调用或手动操作）
- 时间戳

日志上限为 **120 条**，超出后最早的记录将被自动裁剪。

你可以在操作历史中对任意一条记录执行回滚，将角色卡或世界书恢复到该操作之前的状态。

**回滚限制：**

- 回滚操作本身也会被记录为一条日志
- 不支持对回滚记录再次回滚（即不能「撤销回滚」）
- 你也可以删除单条历史记录，或清空所有历史

## 与搜索插件的集成

角色卡编辑助手会自动检测[搜索插件](/zh-CN/features/search-tools)是否可用。如果搜索插件已启用，Studio AI 会额外获得联网搜索和网页访问能力——你可以让 AI 搜索相关资料来辅助角色卡编辑，例如「帮我搜索一下中世纪骑士的装备，然后更新角色描述」。

这意味着 AI 在编辑角色卡时可以：

- 搜索网络获取角色相关的参考资料
- 访问网页提取详细信息
- 基于搜索结果完善角色设定

例如，你可以告诉 AI「搜索一下维多利亚时代的服饰风格，然后更新角色的外貌描述」，AI 会先搜索相关资料，再据此修改角色卡。

如果搜索插件不可用，编辑助手会正常工作，只是不具备网络搜索能力。

## 世界书同步

当你替换或更新角色卡时，角色卡关联的世界书可能也需要相应更新。角色卡编辑助手提供了智能的世界书同步机制：

- 系统会在角色卡被替换时自动检测世界书变更
- 同步过程可以配置独立的 LLM 预设和 API 预设
- 通过 `replaceLorebookSyncEnabled` 配置项控制是否启用同步功能

::: tip 配置建议
如果你经常从外部导入更新版本的角色卡，建议开启世界书同步功能，避免世界书数据与角色卡版本不一致。
:::
