# 同步

通过配对的局域网设备或加密的 S3 存储同步 Luker 数据。按后端选择同步类别，使用统一的冲突处理、恢复与同步计划。

## 打开同步与选择后端

打开**用户设置 → 帐户 → 备份与恢复 → 同步 → 打开同步**。选择**同步后端**，查看连接、设备名称与同步计划。

![同步后端为空，显示设备名称与同步计划](/images/sync/01-panel-empty.png)

| 连接方式 | 配置指南 |
| --- | --- |
| 直接连接能够相互访问的 Luker 服务端 | [局域网同步](./lan-sync)。同步前升级两端。 |
| 通过不同网络均可访问的加密存储同步 | [S3 同步](./s3-sync)。设备使用相同的存储桶、前缀与加密口令。 |

如需将数据迁移到新安装的环境，参阅[迁移指南](/zh-CN/guide/migration)。

**同步后端**显示后端名称、LAN 或 S3 类型、上次同步时间与错误。通过对应后端的**立即同步**、**撤销上次同步**、**编辑**或**移除**执行操作。S3 后端还提供**解锁**，用于修复已存储的密钥。

![已配对的局域网后端，显示上次同步时间与操作](/images/sync/06-backends-after-pair.png)

![同步面板同时显示局域网与 S3 后端](/images/sync/backend-list.png)

后端名称用于在当前安装中识别连接。**当前设备名称**用于标记后续修改的来源，显示在版本卡片与聊天通知中。修改后选择**保存设备名称**；留空时使用主机名或个人资料名称。修改名称不会改变已有版本的来源标签。历史版本或通用来源显示为 **Luker Sync**。

## 自动同步与计划

Luker 服务端会在以下情况下启动同步：

- 服务端启动。
- 本地写入停止并达到设定的等待时间。
- 达到设定的轮询间隔，接收其他设备的修改。
- 收到已配对局域网设备的变更通知。
- 选择**立即同步**。

在**同步计划**中填写**最后一次编辑后等待多久同步，单位为秒**与**检查其他设备变更的间隔，单位为秒**，然后选择**保存同步计划**。默认在编辑停止后等待 **60 秒**，后端轮询间隔为 **300 秒**。填写正数。

只要 Luker 服务端仍在运行，关闭浏览器后仍会执行同步。关闭应用并停止其服务端后，同步也会停止。设备离线或存储服务不可用时，后续正常触发会再次尝试；实际同步时间取决于连接与服务端运行状态。

可见的浏览器标签页会在加载时及使用期间检查当前 Luker 服务端的状态。这些检查用于更新界面，不会轮询远端后端或启动同步。

### 活动与检查

同步状态入口显示正在同步的后端名称与不定进度条。点击入口即可打开**同步**。成功且没有待处理事项时，入口收起；发生错误、状态未知或存在未处理事项时，保留入口供用户检查。

![同步状态入口显示 Shared archive，下面显示聊天与输入框](/images/sync/sync-activity.png)

该入口不显示百分比或耗时估计。观察后台状态不会自动打开同步面板。使用面板中的**检查同步问题**重新查看待处理选择与通知。独立的自动提醒仍会在加载页面时显示待处理事项，并在使用期间发现新事项时打开同步问题页。

## 待处理的选择

不兼容的修改需要用户选择时，同步会暂时保留可用版本，并在**同步问题**中列出文件。暂存的数据可以继续使用，但该选择仍处于待处理状态。来自不同后端的相同路径会合并显示，已应用的选择会通过报告该路径的后端传播。

![同步警告提示文件需要选择版本](/images/sync/07-conflict-banner.png)

根据变更树与**来自 … 的版本**判断来源，不要根据卡片位置判断本地或远端。文件按区块列出修改，展开区块可查看条目或字段，打开字段后加载修改前后的值。预设分为参数、提示词、提示词顺序与扩展。世界书按注释或内容首行列出条目。角色卡分为资料、内嵌世界书与扩展。聊天分为元数据与消息。条目顺序变化会标记为移动。值按需加载，超出首屏后使用**加载更多**继续。密钥文件只显示条目标签与保留末尾四位的遮蔽值。与另一版本完全相同的版本会标记**与 … 相同**。只有来源版本与暂时保留的内容完全相同时，才会标记**正在使用**。合并后的版本可以与来源版本均不相同，因此冲突不一定带有此标记。**当前版本**不会显示该标记。

![同步问题页显示来源版本、变更树与当前版本](/images/sync/08-conflict-popup.png)

选择**使用此版本**或**保留当前版本**，然后点击**应用选择**。需要选择时，以整个文件为单位处理。缺少的一侧会标记为删除，选择后会删除该文件。只要仍有待处理事项，加载页面时就会再次提醒，直至完成选择或关闭相应通知。

![解决世界书冲突后显示同步成功](/images/sync/09-resolved-success.png)

### 冲突后的修改

文件在冲突发生后再次修改时，同步问题页会比较当前数据与冲突发生时使用的版本，并显示覆盖警告。**保留当前版本**会保留后续修改。选择其他版本时，需要确认**覆盖**；选择**取消**会保留当前数据与待处理选择。被覆盖的版本仍保存在同步历史中。

![过期冲突显示后续修改的当前内容与覆盖警告](/images/sync/conflict-stale.png)

![覆盖确认对话框，显示覆盖与取消操作](/images/sync/conflict-stale-confirm.png)

其他设备已解决的状态，需要通过成功读取确认。后端无法读取时，对应选择会保持未知状态。如果出现**无法读取部分待处理同步记录。**，检查受影响的后端，恢复连接或有效数据后再次检查。读取结果不完整时，缺少条目不代表已经解决。

**没能更新的文件**仍需处理。检查列出的路径、存储访问权限与目标目录结构，修正提示的问题后选择**立即同步**。

### 自动合并

Luker 自动合并角色统计、群组与角色卡中兼容的最近聊天和日期记录，以及兼容的图片文件夹元数据。不兼容的内容或文件夹修改仍需选择版本。聊天的替代版本按照下文保存为分支，不会全部转为文件选择卡片。

默认启用**设置**，冲突时仍需选择整个文件。在不同设备上进行细小的配置修改也会产生冲突。按顺序修改配置，同步后再修改另一台设备。

## 聊天分支与恢复的聊天

并发聊天修改产生替代版本时，Luker 会保存聊天分支并显示来源设备。点击**打开分支**检查内容，通过常规[聊天管理](/zh-CN/basics/chat-management)保留、合并或删除所需内容。通知上的**关闭**仅关闭通知，不会删除已保存的分支。

![角色聊天通知，显示打开分支与关闭](/images/sync/chat-fork-notice.png)

![群聊分支通知，显示来源设备](/images/sync/group-chat-fork-notice.png)

设备删除聊天，而其他设备仍在编辑时，同步会恢复被保留的角色聊天或群聊，必要时同时恢复所属群组。点击**打开聊天**检查保留的内容。如需继续删除，先停止其他设备的相关编辑，再通过聊天或群组管理删除，然后再次同步。

![恢复角色聊天的通知，显示删除与保留内容的设备](/images/sync/chat-restored-notice.png)

![恢复群聊的通知，显示打开聊天与关闭](/images/sync/group-chat-restored-notice.png)

打开操作要求目标角色或群组以及聊天仍然存在。目标缺失时，操作会被禁用或提示打开失败。关闭恢复通知不会删除已恢复的内容。

## 类别与敏感数据

添加后端时选择类别，通过**编辑**调整。下表使用界面中的实际类别名称。

| 选择状态 | 类别 |
| --- | --- |
| 默认启用 | **角色卡**、**聊天与群组**、**世界书（Lorebook）**、**卡片应用**、**技能（Skills）** |
| 默认启用 | **OpenAI 预设**、**NovelAI 预设**、**KoboldAI 预设**、**文本补全预设**、**指令模板**、**上下文模板**、**系统提示词**、**推理模板** |
| 默认启用 | **主题**、**可移动界面布局**、**快速回复**、**素材**、**背景**、**用户设定头像**、**用户上传文件**、**ComfyUI 工作流** |
| 默认启用 | **用户图片**、**图片元数据索引**、**向量缓存**、**角色统计**、**设置** |
| 按需启用 | **API 密钥与凭据**、**扩展插件** |

**聊天与群组**包含角色聊天、群聊与群组。同时选择**用户图片**与**图片元数据索引**，保留图片的文件夹归属。**设置**存在上述整个文件冲突风险。启用**扩展插件**前，检查设备之间的插件代码与版本差异。

默认关闭**API 密钥与凭据**。局域网连接未使用 TLS 时，传输的数据及所选密钥会以明文通过网络。S3 会在存储前加密同步内容，但 HTTP 仍会暴露传输中的端点凭据。使用可信连接并优先选择 HTTPS；存储桶内容加密不能替代传输安全。

缩略图、本地图片缓存、自动聊天备份、存储迁移归档、运行日志、服务端 cookie 密钥与同步的本地状态不属于同步类别。

## 撤销与恢复

在对应后端选择**撤销上次同步**，还原上次同步引入的修改。撤销会创建新的同步修改，其他设备也会接收，同步历史继续保留。同步后再次编辑的文件会保留较新的数据，并在结果中列出。

撤销无法应用到本地时会提示错误；传播失败不代表其他设备已经还原。恢复后端可用状态后，选择**立即同步**传播已提交但尚未传出的撤销。已提交的撤销会消耗其撤销点，不应依赖相同撤销点继续保留。

重大数据修改前，可以单独创建[完整 ZIP 备份](/zh-CN/features/user-settings-additions#备份、迁移与存储)，用于恢复。

### 读取与存储错误

提示「无法刷新同步后端。当前显示上次加载的配置。」时，会继续显示此前加载的后端。提示「无法读取同步状态。请检查连接后重试。」时，会保留已知待处理数据，并标记状态不确定。恢复连接、重新打开同步或再次检查后，再根据这些条目进行选择。

错误指出私有同步配置无法读取或已损坏时，请管理员恢复读取权限，或使用有效备份恢复提示的文件，然后再修改同步设置。损坏的配置会提示错误，不会作为空白配置重新初始化。

目标文件系统无法区分报告的名称，或类别路径经过符号链接时，请管理员在保留原始数据的前提下修正名称或存储目录结构。同步不会自动重命名或删除源数据。目标兼容后再次尝试；恢复需要有效的保留副本或备份。

## 存储模式与管理员策略

支持**文件存储、SQLite、MySQL 与 PostgreSQL**，也支持不同存储模式之间同步。数据库数据按资源或记录同步，不会复制整个数据库。数据库连接由所属 Luker 实例使用，对端不需要直接访问该数据库服务端。

局域网同步要求服务端能够相互访问。S3 设备只需访问相同的存储服务，不要求位于同一局域网。

多用户安装默认限制非管理员帐户向私有、环回与链路本地地址发起局域网或 S3 连接。管理员及未启用帐户的单用户模式不受此限制。私有端点被阻止时，请管理员检查[私有地址策略](/zh-CN/guide/configuration#sync-private-addresses)。
