# S3 同步

S3 同步把 Luker 数据存入共享的加密存储桶，让不同网络中的设备使用同一份数据。同步内容在上传前完成加密。

同步计划、类别、冲突选择、聊天分支与撤销操作参阅[同步概览](./sync)。

## 准备条件

- 升级所有要共享数据的 Luker 安装。
- 在存储服务中创建存储桶，记录端点、地区与路径样式要求。
- 凭据需要能读写所选位置，并能删除配置检查产生的临时对象。存储服务需支持条件写入，避免并发修改互相覆盖。
- 加入同步的设备使用相同存储桶与规范化前缀。无关数据使用独立位置。
- 浏览器到 Luker、Luker 到存储服务的连接均优先使用 HTTPS。多用户安装连接私有端点时，还需管理员允许[私有地址访问](/zh-CN/guide/configuration#sync-private-addresses)。

## 添加存储

打开**用户设置 → 帐户 → 备份与恢复 → 同步 → 打开同步**，选择**添加 S3 后端**。

| 字段 | 填写内容 |
| --- | --- |
| **后端名称** | 当前连接的名称，例如 Shared archive。 |
| **要同步的类别** | 要共享的数据，参阅[类别与敏感数据](./sync#类别与敏感数据)。 |
| **S3 端点** | 服务提供方的 HTTP 或 HTTPS 端点。优先使用 HTTPS，不要在 URL 中填写凭据。 |
| **地区** | 存储服务要求的地区。 |
| **存储桶** | 已存在的存储桶名称。 |
| **前缀** | 存储桶内的位置，例如 `seraphina/`；留空时使用桶根。 |
| **使用路径样式请求** | 按存储服务的地址要求设置。 |
| **发送不带引号的 ETag** | 服务支持条件写入但拒绝 If-Match 中带引号的 ETag 时启用。 |
| **访问密钥 ID**、**秘密访问密钥** | 可访问该位置的凭据组合。 |
| **加密口令** | 新建同步位置时设置的口令，或加入已有位置时使用的原口令。 |

**前缀**开头与结尾的斜杠会被忽略，`/seraphina/` 与 `seraphina` 表示同一位置。允许空前缀。内部空路径段、`.` 或 `..` 路径段、反斜杠与控制字符会被拒绝。

![添加 S3 后端表单，显示连接字段、类别与隐藏的敏感值](/images/sync/s3-form.png)

点击**保存**。配置期间会用临时对象检查条件写入支持；忽略必要写入条件的服务无法使用。配置还会检查 If-Match 中的当前 ETag 能否被接受；服务只拒绝带引号的 ETag 时，错误提示会指向「发送不带引号的 ETag」。认证失败、存储桶不存在与连接失败会分别提示，不会被误判为兼容性问题。

配置完成后，后端出现在**同步后端**中并开始同步。状态与待处理事项见[活动与检查](./sync#活动与检查)。

## 从其他设备加入

在加入的设备上选择**添加 S3 后端**，填写已有的端点、地区、存储桶、规范化前缀、凭据与**相同的加密口令**。选择要共享的类别后点击**保存**。加入时使用表单中的口令字段，不会另外弹出口令窗口。口令错误会被拒绝，修正后再次保存即可。

![加入设备的添加 S3 表单，使用已有存储位置与口令字段](/images/sync/s3-second-device-passphrase.png)

妥善保存口令。没有口令时，新安装无法恢复存储桶中的加密数据。无法恢复时，从设备上仍可获得的数据出发，使用全新且为空的存储桶或前缀。移除后端或改用其他位置不会解密旧数据，已有加密数据应保持不变。

## 加密与凭据

配置时，浏览器把凭据与口令发送到你自己的 Luker 服务端。服务端在上传前加密同步数据，存储桶中只有加密内容，以及一份不含口令的公开元数据。

服务端保存解锁自动同步所需的密钥材料，不保存口令，因此常规同步不会反复要求输入。后端列表与状态响应不会向浏览器返回凭据或密钥材料。

存储桶加密不能保护通过 HTTP 传输的端点凭据。浏览器到 Luker、Luker 到存储服务的连接均应在可用时使用 HTTPS。

## 编辑、移除与解锁

### 编辑连接设置

在后端条目上点击**编辑**。凭据字段与**加密口令**均留空时，保留已存储的凭据与密钥。替换凭据时需同时填写访问密钥 ID 与秘密访问密钥，缺少内容会被拒绝。

修改端点、地区、路径样式、ETag 引号选项或凭据后，Luker 会确认新设置仍能访问原有的加密数据，再保存。端点仍需指向同一加密位置。填写口令只用于验证该位置的原口令，不会更改保护数据的口令。

**存储桶**与**前缀**为只读。如需使用其他位置，先**移除**后端，再重新添加。这会创建独立的后端与同步历史，不会迁移旧后端。**移除**不会改变存储桶数据或其他设备。

### 修复已存储的密钥

提示需要口令时，选择**解锁**。仅当本地密钥记录有效且与远端数据匹配时，解锁才能修复已存储的密钥。

本地记录缺失、损坏，或远端数据已经更换加密身份时，按提示**移除**并重新添加后端。解锁无法改用其他身份，也无法更换加密密钥。加密元数据缺失或损坏时，应从有效副本恢复，不要删除或覆盖后强行配置。

## 故障处理

| 提示的问题 | 处理方式 |
| --- | --- |
| 口令与存储桶及前缀不匹配 | 检查存储位置，并使用原口令。 |
| 认证失败 | 检查凭据组合与存储桶权限。 |
| 找不到存储桶 | 确认配置的端点中存在该存储桶。 |
| 无法访问端点 | 恢复网络或存储服务，检查端点与地区。 |
| 服务不支持条件写入 | 使用兼容的存储服务。 |
| 服务拒绝 If-Match 中带引号的 ETag | 启用**发送不带引号的 ETag**后重新保存。 |
| 禁止连接私有地址 | 请管理员检查[私有地址策略](/zh-CN/guide/configuration#sync-private-addresses)。 |
| 不支持加密格式 | 更新 Luker 后再次同步。 |
| 同步数据缺失或无效 | 从有效副本恢复存储桶中的同步数据，再同步；参阅[恢复说明](./sync#撤销与恢复)。 |

S3 同步支持桌面端、Android 与 HarmonyOS。保持 Luker 服务端运行并能访问存储服务。自动重试遵循[正常同步触发条件](./sync#自动同步与计划)。

不支持修改加密口令、更换密钥或自动压缩同步历史。首次同步会下载已存储的历史，存储桶用量随历史积累增长。
