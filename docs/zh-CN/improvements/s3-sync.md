# S3 同步

使用兼容 S3 的存储桶作为加密同步中心，设备可以通过不同网络连接。同步计划、类别、待处理选择、聊天分支与撤销操作参阅[同步概览](./sync)。

## 准备条件

- 升级准备共享数据的 Luker 安装。
- 添加后端前，在存储服务中创建存储桶，准备兼容的端点、地区与路径样式设置。
- 允许凭据读取、写入所选位置的对象，并删除配置检查产生的临时对象。存储服务必须支持条件写入。
- 加入同步的设备使用相同存储桶与规范化前缀。不相关的数据使用独立的存储位置。
- 优先通过 HTTPS 访问 Luker 服务端与存储服务。多用户安装中的私有端点还需要管理员允许[私有地址访问](/zh-CN/guide/configuration#sync-private-addresses)。

## 添加存储

打开**用户设置 → 帐户 → 备份与恢复 → 同步 → 打开同步**，选择**添加 S3 后端**。

| 字段 | 填写内容 |
| --- | --- |
| **后端名称** | 当前连接的名称，例如 Shared archive。 |
| **要同步的类别：** | 共享的数据，参阅[类别与敏感数据](./sync#类别与敏感数据)。 |
| **S3 端点** | 服务提供方的 HTTP 或 HTTPS 端点。优先使用 HTTPS，不要在 URL 中填写凭据。 |
| **地区：** | 存储服务要求的地区。 |
| **存储桶** | 已存在的存储桶名称。 |
| **前缀** | 存储桶内的独立位置，例如 `seraphina/`；留空时使用存储桶根位置。 |
| **使用路径样式请求** | 根据存储服务的地址要求设置。 |
| **发送不带引号的 ETag** | 服务支持条件写入但拒绝 If-Match 中带引号的 ETag 时启用。 |
| **访问密钥 ID**、**秘密访问密钥** | 可以访问该位置的凭据组合。 |
| **加密口令** | 新建同步位置时使用的口令，或加入已有位置时使用的原口令。 |

**前缀**会移除开头与结尾的斜杠，`/seraphina/` 与 `seraphina` 表示相同位置。允许空前缀。内部空路径段、`.` 或 `..` 路径段、反斜杠与控制字符会被拒绝。

![添加 S3 后端表单，显示连接字段、类别与隐藏的敏感值](/images/sync/s3-form.png)

点击**保存**。配置期间会通过临时对象检查条件写入兼容性。忽略必要写入条件的服务不受支持。配置还会检查 If-Match 中的当前 ETag 能否被接受；服务只拒绝带引号的 ETag 时，错误提示会指向「发送不带引号的 ETag」。认证失败、存储桶不存在与连接失败会分别提示，不视为不支持条件写入。

配置完成后，后端显示在**同步后端**中，并启动同步。[活动与检查](./sync#活动与检查)说明了如何查看同步状态与待处理事项。

## 从其他设备加入

在准备加入的设备上选择**添加 S3 后端**，填写已有的端点、地区、存储桶、规范化前缀、凭据与**相同的加密口令**。选择所需类别后点击**保存**。加入时使用该表单的口令字段，不会另外自动弹出口令窗口。口令错误时会提示失败，修正表单后再次保存。

![加入设备的添加 S3 表单，使用已有存储位置与口令字段](/images/sync/s3-second-device-passphrase.png)

妥善保存口令。丢失口令后，新配置无法恢复存储桶中的加密数据。无法恢复时，使用设备上仍可获得的本地数据，在全新且为空的存储桶或前缀下开始同步。移除后端或使用其他存储位置不会解密旧数据；保留已有加密元数据。

## 加密与凭据

配置时，浏览器会将填写的凭据与口令发送到**自己的 Luker 服务端**。服务端在上传前加密同步数据。存储桶中的 `head` 与 `packs/` 内容经过加密，`keyinfo.json` 保存公开的加密元数据，不包含口令。

服务端保存派生密钥以供自动同步，不保存口令，因此常规同步不会反复要求输入。后端列表与状态响应不会向浏览器返回已存储的凭据或派生密钥。

存储桶内容加密不能保护通过 HTTP 传输的端点凭据。优先通过 HTTPS 保护浏览器到 Luker、Luker 到存储服务的连接。

## 编辑、移除与解锁

### 编辑连接设置

在后端条目上点击**编辑**。凭据字段与**加密口令**均留空时，保留已存储的凭据与加密密钥。替换凭据时需同时填写访问密钥 ID 与秘密访问密钥，缺少内容会被拒绝。

修改端点、地区、路径样式、ETag 引号选项或凭据后，Luker 会验证能否访问原有的远端加密身份，再保存设置。修改端点仍需连接相同的加密存储位置。填写口令仅验证该位置的原口令，不会修改保护数据的口令。

**存储桶**与**前缀**为只读。如需使用其他位置，先**移除**后端，再**添加 S3 后端**。此操作会创建不同的本地后端与同步历史，不会迁移旧后端。**移除**不会改变远端存储桶数据或其他设备。

### 修复已存储的密钥

错误提示需要使用口令解锁时，选择**解锁**。仅当已有本地密钥标识有效且与远端匹配时，解锁才能修复已存储的加密密钥。

本地标识缺失、无效或远端标识已经改变时，按照错误提示**移除**并**添加 S3 后端**。解锁不能接受其他身份或轮换加密密钥。加密元数据缺失或无效时，需要使用有效副本恢复，不要通过删除或覆盖元数据强制配置。

## 故障处理与平台支持

| 提示的问题 | 处理方式 |
| --- | --- |
| 口令与存储桶及前缀不匹配 | 检查存储位置，并使用原口令。 |
| 认证失败 | 检查凭据组合与存储桶权限。 |
| 找不到存储桶 | 确认配置的端点中存在该存储桶。 |
| 无法访问端点 | 恢复网络或存储服务，检查端点与地区。 |
| 服务不支持条件写入 | 使用兼容的存储服务。 |
| 服务拒绝 If-Match 中带引号的 ETag | 启用**发送不带引号的 ETag**后重新保存。 |
| 禁止连接私有地址 | 请管理员检查[私有地址策略](/zh-CN/guide/configuration#sync-private-addresses)。 |
| 不支持加密格式 | 更新 Luker 后再次同步。 |
| 同步数据缺失或无效 | 使用有效副本恢复存储桶同步数据后再次同步，参阅[恢复说明](./sync#撤销与恢复)。 |

支持在桌面端、Android 与 HarmonyOS 使用 S3 同步。保持 Luker 服务端运行并能够访问存储服务。自动重试遵循[正常同步触发条件](./sync#自动同步与计划)。

不支持修改加密口令、轮换密钥或自动压缩同步历史。首次同步会下载已存储的历史，存储桶用量会随历史积累增长。
