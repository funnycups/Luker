# 预设关联世界书

预设关联世界书是 Luker 引入的改进，允许你将特定的世界书与预设绑定。切换预设时，关联的世界书会自动激活。

## 使用场景

不同的角色扮演场景往往需要不同的预设参数和世界观设定。例如：

- **奇幻场景**：高温度 + 奇幻世界书（魔法体系、种族设定等）
- **现代都市**：中等温度 + 现代世界书（城市地标、社会规则等）
- **科幻场景**：低温度 + 科幻世界书（星际设定、科技体系等）

通过预设关联世界书，你可以将这些组合打包——切换预设时，对应的世界书自动激活，无需手动切换。

## 如何使用

1. 在预设编辑界面中，找到「关联世界书」设置
2. 选择要与当前预设绑定的世界书
3. 保存预设

之后每次切换到这个预设时，关联的世界书会自动激活。切换到其他预设时，不会全局自动停用你手动启用的世界书。

::: tip
预设关联世界书不会影响角色卡自带的世界书。角色卡的世界书始终生效，预设关联的世界书是额外叠加的。
:::

## 与手动激活的区别

世界书有两种激活方式：手动激活和预设关联激活。

- **手动激活**的世界书始终保持激活状态，不受预设切换影响
- **预设关联激活**的世界书会在选中对应预设时自动激活

两种方式互不干扰。如果你希望某个世界书在所有预设下都生效，直接手动激活即可；如果只想在特定场景下使用，通过预设关联更为方便。

## 与其他功能的配合

- **[角色卡绑定预设](/zh-CN/improvements/card-bound-presets)**：角色卡可以推荐预设，预设又关联世界书，形成「角色卡 → 预设 → 世界书」的完整链路
- **[预设解耦](/zh-CN/improvements/preset-decoupling)**：预设关联世界书建立在预设解耦的基础上，连接配置和预设独立管理
