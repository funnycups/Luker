# 局域网同步

配对能够相互访问的 Luker 服务端，直接同步数据。自动同步、类别、版本选择、聊天分支与撤销操作参阅[同步概览](./sync)。通过共享存储跨网络同步，参阅 [S3 同步](./s3-sync)。

## 准备条件

- 同步前**升级两端**，旧协议不再受支持。有效的已有配对会在升级时迁移，无需重新配对。
- 保持 Luker 服务端运行，并允许相互访问。浏览器可以访问对端，不代表反向服务端连接也已畅通。
- 在两端启用局域网监听，并通过防火墙与 IP 白名单放行服务端端口。`listen`、监听地址与访问保护参阅[基础配置](/zh-CN/guide/configuration)。
- 在安装环境中使用相同的帐户标识。显示名称不是帐户标识。
- 使用多用户服务端的非管理员帐户时，请管理员通过[私有地址策略](/zh-CN/guide/configuration#sync-private-addresses)允许访问私有目标。

使用对端能够访问的地址，不要使用 `localhost` 或 `127.0.0.1`。未使用 TLS 时，传输的数据在网络中不加密；使用可信网络或 HTTPS 连接。

## 生成配对链接

在分享链接的设备上，打开**用户设置 → 帐户 → 备份与恢复 → 同步 → 打开同步**，然后选择**配对新设备**。

填写对端标签，勾选**要同步的类别：**，点击**生成配对链接**。默认类别与敏感数据选项参阅[类别说明](./sync#类别与敏感数据)。

![配对新设备表单，填写 Tablet 并选择类别](/images/sync/02-pair-new-form-filled.png)

在**另一台设备将使用的地址**中选择可访问的地址。存在非环回地址时，Luker 会优先选择；服务端连接不同网络时，可以改选其他地址。点击**复制链接**，私下发送给准备配对的设备。

![已生成的链接，显示地址选择与凭据存储说明](/images/sync/03-pair-link-generated.png)

链接包含有效期为 **10 分钟**的一次性配对码。过期后点击**重新生成**，生成新链接。反向连接检查失败后，修正连接仍可使用尚未过期的原链接。

## 接受配对链接

在接收链接的设备上，打开相同的同步面板，选择**与已有设备配对**，粘贴**配对链接**。检查**另一台设备的基础 URL**、**另一台设备给出的标识符**、**另一台设备的标签**与所选类别。将标签设为该连接实际访问的设备，例如 Desk。

仅在对端要求基本认证时，填写对端要求的用户名与密码，否则留空。配对后，填写的凭据会保存在当前接收设备的 Luker 服务端，用于后续同步。通过当前设备后端条目上的**清除凭据**移除。

![已粘贴配对链接，显示对端字段、可选凭据与配对并同步](/images/sync/04-pair-existing-pasted.png)

点击**配对并同步**。设备会交换所选数据，成功横幅显示已配对后端的名称。警告横幅表示存在需要检查的事项，处理方式参阅[同步概览](./sync#待处理的选择)。

![配对后成功与 Desk 同步](/images/sync/05-pair-success-banner.png)

保存的连接显示在**同步后端**中。后续按正常触发条件自动同步，也可按需选择**立即同步**。

## 配对与连接问题

| 结果 | 处理方式 |
| --- | --- |
| `PEER_CALLBACK_UNREACHABLE`：对端无法反向连接 | 在接收链接的设备上启用局域网监听，检查防火墙，再次使用仍有效的原链接。该错误表示配对失败，不代表成功保存配对。 |
| 提示已经配对，但首次同步失败 | 连接已保存。修正提示的原因后，在该后端选择**立即同步**。 |
| `NO_BASE_URL`：尚不知道对端地址 | 从另一端发起同步，使其提供可访问的地址。 |
| `PEER_PROTOCOL_OUTDATED` | 升级对端 Luker 服务端，然后再次同步。 |
| `PEER_FORGOTTEN`，或旧配对标识无效 | 移除受影响的本地连接，然后重新配对。有效配对的正常升级迁移不需要此操作。 |
| 认证失败 | 配对时检查对端要求的基本认证凭据。已保存连接的凭据变更后，按照错误提示移除并重新配对。 |
| 帐户标识不匹配 | 登录相同标识的帐户后，再接受链接。 |
| 私有地址被阻止 | 请管理员检查[私有地址策略](/zh-CN/guide/configuration#sync-private-addresses)。监听与防火墙访问仍需单独配置。 |
| `SYNC_BACKEND_MAINTENANCE` | 对端正在修改同步设置。等待完成后选择**立即同步**，或等待后续正常触发。 |
| 其他连接错误 | 检查服务端、所选地址、端口、路由、防火墙与白名单，然后再次同步。 |
